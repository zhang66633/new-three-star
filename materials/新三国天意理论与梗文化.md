# 新三国"天意"理论与世界观解读素材

来源：知乎多个回答（折棒R9视频体系 + 知乎讨论）
采集时间：2026-07-24

## 天意系统核心设定

### 天意 = 克苏鲁古神
- 新三国是正儿八经的克苏鲁世界设定
- 天意就是古神，天意决定一切，渺小的人类不管怎么挣扎最后事件的发展都会按照天意进行
- 天意是笼罩在新三世界之上看不见的大手，祂钉死了历史发展的关键节点
- 在折棒的天意理论加持下，新三国克苏鲁世界观已经自洽了

### 天意侵蚀
- 天意可以被窥探，但窥探天意会反遭天意侵蚀
- 直面天意的曹操被同化
- 灵魂锁链是刘备沟通天意的唯一枢纽，关张死了刘备就是失去天意的无头苍蝇
- 甚至最终沦为天意的傀儡

### 天意修正之力
- 无论你说什么话、做什么事，天意都会把历史修正回正轨
- 如果当地的战斗结果预计不符合史实，则破坏结果者获得"未经计划的攻势"debuff
- 天意在某些时候会直接干预（如甘露寺天意突然发力让孙小妹看上刘备）

### 多天意TRPG理论
- 新三国可能是多个天意进行的TRPG游戏
- 除了统一天下之外每个人都有一条隐藏胜利条件
- 他们不是明确知道"这么做会赢"，而是被天意推着走
- 天意爷自己都会疯掉，"乌角鲨""黄金起义"这些奇怪的东西已经是天意爷神智出现问题的征兆

### 被污染的游戏世界理论
- 新三国是一个被污染吞噬的世界
- 里面的人物会无限轮回，重复三国人物的生平事迹
- 你可以理解为这些人在玩一个大型RPG游戏，天意就是游戏的管理员系统

## 战争底层逻辑

- 胜兵必骄 → 骄兵必败 → 败兵必哀 → 哀兵必胜（循环）
- 水镜先生发现并总结了这一新三国战争底层逻辑
- 因为孙坚虽然英勇，但是求胜心切，孤军深入，已成骄兵，而骄兵必败

## 人物与天意的关系

### 曹操
- 直面天意并被同化
- "天意如此，不必难过"
- 知错改错不认错 = 人主之道 = 对抗天意的方式

### 刘备
- 灵魂锁链（关张）= 沟通天意的枢纽
- 关张死后失去天意连接
- "自刎归天" = 试图回归天意的仪式
- 仁义 = 天意赋予的武器（"它还是杀人的利器"）

### 诸葛亮
- 窥探天意最深处的人
- 因此遭受最严重的天意侵蚀
- "好火啊比夷陵之火还好" = 天意侵蚀后的认知扭曲

### 司马懿
- "王是一口井，天子则是一口深井" = 理解天意的层级结构
- 最终被天意完全同化（篡魏）

### 新三国 vs 老三国
- 老三国胜在厚重，新三国赢在鲜活
- 老三国适合细品，新三国适合反复刷名场面玩梗
- 老三国强调礼法、气度、古典叙事和群像秩序
- 新三国更像一部现代权谋剧，人物说话更直接，节奏更快，冲突更密集
- 新三国能十几年持续保持热度，靠的就是造梗能力

### 人物刻画特点
- 新三国平等地把曹刘孙都黑了
- 曹操：随地小便（魏武挥鞭）、嗜酒暴力狂
- 刘备：虚伪阴险小人嘴脸、"刘跑跑"
- 诸葛亮：老被张飞欺负、被刘备甩锅的受气包
- 孙权：受大都督制约的可怜主公
- 但仅从人物塑造来说，新三国比老三国更优秀更进步（精简人物、深化性格）

## 补充机制（规则怪谈方向，2026-07-24追加）

来源：知乎"新三国除了灵魂锁链还有什么机制"等讨论

### 已确认的新三国机制列表
1. **天意** — 克苏鲁式世界意志，钉死历史关键节点，修正一切偏离
2. **灵魂锁链** — 刘备下线触发关张下线；刘备任务=合理自刎归天，关张为自保百般阻止刘备
3. **传国玉玺** — 天意的实体化形，蕴含天意之力，持有者可称帝，但导致严重天意侵蚀
4. **酒** — 新三国最为高贵的存在（酒是至高无上的）
5. **事不过三** — 同一事件最多发生三次，第三次必触发天意修正
6. **哀兵必胜** — 胜→骄→败→哀→胜循环的战争底层逻辑
7. **孙家轮流当主** — 东吴继承机制（孙策→孙权→孙亮...循环）
8. **曹操玉玺融合** — 曹操与天意的融合/同化过程
9. **中立伏兵** — 战场上突然出现的不属于任何阵营的兵力（天意的直接干预）
10. **新三国道** — 整个新三国世界运行的总规则体系
11. **窥探天意反噬** — 能窥探天意者才是顶级存在，但也必定被天意反噬
12. **天意贯穿现在过去未来** — 天意不受时间线限制
13. **被污染的世界/无限轮回** — 人物会无限轮回重复三国生平
14. **隐藏胜利条件** — 每人除统一天下外还有天意分配的隐藏目标（TRPG理论）
15. **天意爷的神圣规划** — 不影响规划则给予庇护，试图窥探凡人权柄则毫不犹豫修正

- 新三国提供的名场面和素材多到说不完
