# 崩坏纪元（game_world）完整世界观 v2

> 核心隐喻：新三国 = 一个世界意志被污染的三国游戏世界。角色 = 觉醒的NPC。
> 独特视角：所有异常现象都是"游戏机制"——地图设计、脚本修正、随机刷怪、快速旅行、数据绑定。
> 对标作品：《道诡异仙》（凌小千原话："新三国的世界观和道诡高度类似"）
> 情感基调：恐惧、癫狂、无奈——游戏角色发现真相后的存在主义绝望
> 来源：知乎'凌小千'(6027赞,2025-05-26) + 知乎'水是熔融态的冰'(930赞,游戏设计文档式整理) + 素材库A部分机制 + B站二创生态

## 一、机制层（游戏系统的客观规则）

### 公设1：世界意志被污染
这个游戏世界的管理员系统（天意）已经被污染/崩溃。它不再正常维护世界，而是：
- 在关键节点**强行修正脚本**（角色突然前言不搭后语 = 被系统临时接管）
- 拒绝与任何其他"管理员"并列（于吉、张鲁、笮融被抹除 = 系统不允许第二个admin）
- 让一件事成就一定成，没有任何因素能改变（= 脚本锁定，不可skip）

### 公设2：角色是觉醒的NPC
- 角色有自我意识，**以为自己是三国人物**，按"人设"演出
- 他们不知道自己是游戏角色（除了极少数觉醒者）
- 被系统接管时，本人毫无察觉（"我刚才说了什么？"）
- 曹操 = 最终BOSS，**首先觉醒又首先被完全污染** → 所以行为前后矛盾（觉醒时的清醒 vs 被污染后的精神病）
- 刘备 = **发现真相的人**，知道一切都是游戏，知道关张"只是三组数据"

### 公设3：地图是设计出来的（不是真实地理）
- 袁术在徐州东面（= 海上）→ 因为游戏地图这么设计的
- 小沛**环绕徐州公转**（有进徐点/远徐点）→ 卫星城机制
- 冀州"早就归于北方" → 地图板块漂移/未加载
- 徐州是"中原第一雄关" → 关卡设计
- 白马/南阳/当阳之间存在传送门 → 快速旅行点

### 公设4：传送门 = 快速旅行
- "新三国道"连接各州，两端为传送门，可瞬移
- 星夜赶路移速+50%~1000% → 夜间快速旅行加成
- 曹操战袁绍仅备百日之粮 → 因为传送门很快
- 这解释了为什么军队能"突然出现"在任何地方

### 公设5：野生伏兵 = 随机刷新怪物
- 山谷/道路随机刷新中立伏兵，不分阵营见人就打
- 固定刷新点：洛阳-长安间、长江旁
- 不是任何势力的军队 → 是游戏地图的随机遭遇战（random encounter）
- "300人马兵分600路" → 刷怪数量bug

### 公设6：脚本修正（世界意志强行扳回剧情）
- 角色在关键节点被系统接管 → 说出/做出不符合本人逻辑的事
- 表现为：前言不搭后语、突然降智、行为180度转弯
- 博望坡悖论：诸葛亮设计了一个"完全不能运行的计划"，但天意修正后它完美运行了 → 脚本覆写了游戏逻辑
- 甘露寺：天意突然发力让孙小妹看上刘备 → 强制触发剧情事件
- 如果战斗结果不符合"史实"，破坏者获得"未经计划的攻势"debuff

### 公设7：数据绑定（灵魂锁链 = 代码级关联）
- 刘关张三人是**数据层面绑定**的（不是情感绑定）
- 上位能带死下位，反之不然（关羽<<刘备<<张飞）→ 优先级队列
- 三人**本质不熟** → 只是被系统编到同一组的NPC
- 关羽张飞的存在意义 = 阻止刘备触发"退出游戏"条件
- 关羽死后发动"亡语"（= 死亡触发脚本）继续阻止刘备

### 公设8：酒 = 系统最高权限
- 酒是"至高存在，不可悖逆" → 游戏里的最高级道具/指令
- 任何事一转"换大盏" → 酒可以override任何当前状态
- 酒可暂免天意侵蚀 → 使用酒后暂时脱离系统控制
- 但酒后精神失常 → 副作用：脱离控制后NPC行为紊乱

## 二、角色层（NPC的游戏身份）

| 角色 | 游戏身份 | 核心机制 | "游戏化"解释 |
|------|----------|----------|-------------|
| 刘备 | 发现真相的觉醒者 | 自刎归天（=试图退出游戏）；心灵控制；仁义双剑（专武） | 唯一知道"这是游戏"的NPC，一直在找logout按钮 |
| 曹操 | 最终BOSS（被污染） | 首先觉醒→被系统重新污染→精神病行为；头风病=系统争夺控制权 | 觉醒后被admin重新写入脚本，偶尔清醒（头风）偶尔疯（被控制） |
| 关羽 | 系统傀儡（数据绑定） | 摸须一刀斩（无敌技能）；一气化三清（多形态切换）；亡语 | 被系统派来锁住刘备的进程，死后还留了个daemon继续跑 |
| 张飞 | 系统傀儡（数据绑定） | 酿制美酒；始终狂怒 | 另一个锁住刘备的进程，情绪参数被锁定在MAX |
| 诸葛亮 | 觉醒辅助NPC | 人体炼成（钱粮→士兵）；无端忧虑（收到系统提示但智力不够解读） | 收到了admin的debug日志但看不懂，只能靠直觉行动 |
| 司马懿 | 系统本身（天意本意） | 化骨绵掌；默认其他人全是NPC；想怎么剧透就怎么剧透 | 他不是NPC，他是**GM账号**。所以无所谓，随便玩 |
| 孙权 | 隔离策略执行者 | 设大都督职位转移"江东之主"debuff | 发现"江东之主"是个被诅咒的title，赶紧创建子账号（大都督）来扛 |
| 周瑜 | 被诅咒title的承受者 | 水火无敌（需暴怒发动，生命-75%） | 第一个扛"大都督"debuff的号，扛不住死了 |
| 鲁肃 | 净化派/抵抗者 | 精神抵抗侵蚀但肉体不行 | 防火墙，拼命拦截系统对荆州的入侵请求 |
| 荀彧 | 觉醒者（曹魏方） | 发现貂蝉的侵蚀流程并打断 | 曹魏阵营里唯一看懂了代码的人 |
| 陈宫 | 觉醒者（早期） | 发现曹操是污染源→离开→后来配合刘备 | 早期看到曹操的debug日志，意识到不对劲 |
| 董卓 | 守门进程 | 死守天意侵蚀的防线；大汉忠臣 | 被误解为病毒的杀毒软件，其实是在保护系统 |
| 袁术 | 地图bug受害者 | 东海龙王（在海上发展势力） | 因为地图设计被放到了海里，索性发展了水下DLC |
| 吕布 | 被覆写的守门进程 | 率真男儿（武力+100%，智力-250%） | 原本也是杀毒软件，被貂蝉（恶意补丁）覆写了 |
| 的卢马 | 智能道具 | 妨主（想活→妨死，想死→妨活） | 一个读取玩家意图然后反向执行的bug道具 |

### 原文行为证据（凌小千原文）

**曹操被污染后的具体表现：**
- 当着董卓的士兵大喊"国贼董卓"（= 被污染后不在乎暴露，正常觉醒者不会这么蠢）
- 刺董时**主动要求士兵搜身**（= 系统控制下的自毁行为）
- 每次出征**倾巢而出，许昌完全不留一兵一卒**（= 正常统帅不会这么做，是被污染后的决策）
- 官渡之战七万打七十万 = **世界意志发力**（不只是"太阳刺眼"之计，是系统直接介入）
- 行为前后矛盾 = 觉醒时的清醒 vs 被重新写入脚本后的精神病

**刘备发现真相后的具体表现：**
- "从出场开始就表现得**生无可恋**"（= 知道一切都是游戏后的存在主义绝望）
- "总是念叨着'天意'"（= 他知道天意在控制一切，但无力改变）
- "就算自己什么都不做也无所谓，反正最后世界意志会进行修正"（= 放弃抵抗）
- 与关张"实则不熟"（= 他知道自己不是刘备，关张也不是关张，**三个人只是三组数据**）
- "对关张也没有任何感情可言"（= 数据之间不存在真正的兄弟情）
- 无论怎么做，最后的结局都无可更改（= 脚本锁定，NPC无法改变主线）

## 三、事件层（游戏进程中的关键节点）

### 第一幕：系统启动与污染扩散
1. **黄金起义** = 游戏开服时的第一个版本事件（"苍天已死"= 旧admin下线）
2. **王允寿宴+七星刀** = 恶意程序（王允）通过道具（七星刀）感染了曹操进程
3. **桃园结义** = 系统把三个不相关的NPC数据绑定到一组（灵魂锁链初始化）
4. **三英战吕布** = 刘备试图借吕布（守门进程）删掉关张（锁定进程），失败
5. **孙坚得玉玺** = 第二个恶意程序（玉玺）上线，孙坚进程被感染
6. **貂蝉连环计** = 王允用恶意补丁（貂蝉）覆写了吕布（守门进程）

### 第二幕：觉醒者集结
7. **刘备败袁术得玉玺** = 觉醒者拿到恶意程序但免疫感染（归天之人=有root权限）
8. **官渡之战** = 袁绍试图删除被感染的曹操进程（失败，许攸被反向感染）
9. **三顾茅庐** = 刘备找到一个能读懂部分代码的辅助NPC（诸葛亮）
10. **博望坡** = 诸葛亮写了一个自毁脚本想帮刘备logout，被系统修正为正常运行
11. **赤壁之战** = 觉醒者联盟（刘备+孙权+鲁肃）成功抵挡了系统的大规模脚本修正

### 第三幕：系统反击
12. **华容道** = 刘备/诸葛亮/鲁肃合力想删除关羽进程（断锁链），失败
13. **司马懿出场** = 系统紧急部署了新的admin账号（第三污染源）
14. **曹丕毒曹冲** = 曹操验证哪个子进程是纯净的（曹冲=被感染的备份）
15. **大都督更替** = "江东之主"debuff在多个账号间转移（周瑜→鲁肃→吕蒙）
16. **荆州之战** = 系统同时操控三个进程（关羽/吕蒙/曹操）发动协同攻击
17. **关羽之死+亡语** = 关羽进程被终止，但留了一个后台daemon继续阻止刘备logout
18. **荀彧自刎** = 曹魏方觉醒者主动终止自己，化为监控进程盯着曹操不称帝

### 第四幕：游戏结束
19. **夷陵之战** = 刘备最后一次尝试触发logout（听到"生擒"= 系统要阻止他死 → 他偏要死 → 被手下救回 → 病死=退出方式错误，logout失败）
20. **曹操之死** = "死是凉爽的夏夜，可供人无忧的安眠"（被感染的BOSS终于被终止）
21. **上方谷** = 诸葛亮最后一次尝试删除司马懿（新admin）→ "比夷陵之火还好" = 最接近成功的一次 → 失败（系统下雨修正）
22. **诸葛亮死** = 最后一个觉醒辅助NPC下线；新三诸葛亮不提"苍天" = 他知道苍天（旧admin）早就不在了
23. **高平陵之变** = 司马懿（admin账号）夺权 = 系统彻底控制了游戏
24. **司马炎称帝** = 恶意程序成为天子 = 病毒获得了root权限，游戏彻底沦陷

## 五、核心结论

**新三国是一个被污染的游戏世界，角色是觉醒的NPC。整部剧 = 游戏角色的恐惧、癫狂和无奈。**

最恐怖的不是"天意在控制你"，而是"你以为你在做选择，其实脚本早就写好了"。刘备是唯一看清真相的人——他知道关张只是三组数据，知道自刎归天是唯一的logout方式——但他永远登不出去。

这不是一个关于"英雄对抗命运"的故事。这是一个关于**NPC试图退出游戏但系统不允许**的故事。

凌小千原话："整部《新三国》，表现的就是在被污染游戏世界之中，所有游戏角色的恐惧、癫狂和无奈。这么一看，这岂不是一部无与伦比的中式克苏鲁巨作？"

## 六、附录：游戏设计文档式整理（来源：知乎'水是熔融态的冰'）

该回答将新三国所有机制整理为RPG游戏说明书格式，包括：
- **物品效果一览**：酒（抵御天意侵蚀但损害精神）、玉玺（天意实体化形）、仁义之剑（刘备专武，做仁义事充能）、七星刀（有刀魂，铜镜加持射激光）、蛐蛐罐（增加情义值降低智力）等
- **技能一览**：窥探天意、人体炼成、黑暗兵法、自刎归天、水火无敌、化骨绵掌、魏武挥鞭（撒尿触发随机事件）、擎天柱（陆逊=赛博坦人）等60+技能
- **传奇生物**：笑面虎、乌角鲨、蛐蛐（有情有义）、赤兔马、占卜之龟等
- **特殊场地**：博望坡（悖论之地）、上方谷（会引发下雨）、汉中（禁魔领域）、陈留（精神病院）等

此文档可作为证据墙"游戏化解读"的直接素材——每条技能/物品都是一张证据卡片。
