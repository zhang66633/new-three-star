> 版本: v1.0 | 日期: 2026-07-24

## 一、产品定位

用2010版电视剧《三国》（新三国）的荒诞"世界观规则"解读现实生活事件。用户输入一件日常小事，系统随机分配一个世界观框架，以"一本正经说荒诞"的学术口吻输出解读判决卡，并可展开为完整世界观文档。

核心差异化：不是简单的"AI写段子"，而是一个有完整知识体系支撑的"平行世界解释引擎"——9 套世界观框架（cthulhu/game_world/murder_mystery/pokemon/philosophy/cultivation/zhangjiao/trpg/elo）× 8 大类底层机制，组合出近乎无限的解读可能。

社区背景：折棒290期新三国吐槽（4.5亿播放，2026.5.22完结）留下巨大内容真空，B站新三国二创社区活跃度极高。

## 二、核心玩法：亲身经历名场面（目标机制）

> 目标机制（方案定稿）：玩家的游戏目标不再是自由漂流，而是按时、就位，亲身站到三国名场面的正中央。

### 玩家目标：亲身经历名场面

- 玩家核心目标：亲身经历关键名场面（fame_moment）——曹操献刀、捉放曹、屠族等经典桥段，玩家不是旁观者，而是在场者。
- 主线结构：保留现有场景骨架作为名场面链（非开放世界），场景叙事即名场面演出，每章由关键名场面串联推进。

### 目标可见：章首揭示

- 章首向玩家揭示本章时间轴与名场面链：每个名场面的时节、就位条件、剩余时间一目了然。
- 玩家明确"要赶什么"，目标全程可见，不靠摸索。

### 世界时钟：每章一条时间轴

- 每章一条时间轴（如 189 年春夏秋冬），名场面锚定具体时节。
- 玩家在准备期的行动消耗世界时间，时钟随之推进；名场面时节一到即触发就位判定。

### 准备期自由行动（行动盘）

- 名场面之间为准备期：玩家从行动盘选择准备行动（投靠 / 乔装 / 买情报 / 赶路等），自由安排。
- 每个行动消耗时间，并积累就位条件（qualifications）；不同名场面要求不同的就位条件组合（如"在曹操身边"）。

### 就位判定与失败

- 名场面时节到时：就位条件满足 → 触发名场面，进入现有场景叙事；就位条件不满足 → 错过关键名场面 → 游戏失败。
- 失败粒度：仅"错过关键名场面"判负；普通场景错过不失败。

### 存档与读档

- 服务端持久化存档：关键名场面开始前自动存档；失败后读档回到上一个名场面重打，"历史可以重来"。

### 核心循环

```
章首揭示 → 准备期行动盘自由行动（消耗时间 + 积累就位条件）
        → 世界时钟推进 → 名场面时节到
            ├─ 就位条件满足 → 触发名场面（现有场景叙事）
            └─ 就位条件不满足 → 错过关键名场面 → 失败
        → 名场面开始前自动存档，失败读档重打
```

### 产品卖点：名场面即核心玩法

| 卖点 | 说明 |
|------|------|
| 从看客到在场者 | 玩家亲自站在历史转折点中央（献刀、捉放曹、屠族），名场面即游戏高潮 |
| 双重经营 | 不仅要"赶到"，还要"就位"——时间与准备行动的取舍权衡 |
| 时间压力制造张力 | 每章倒计时，赶不赶得上由玩家自己的选择决定，而非自动推进 |
| 目标可见不迷路 | 章首揭示时间轴 + 名场面链（时节 / 就位条件 / 剩余时间），玩家始终明确要赶什么 |
| 失败可重打 | 错过关键名场面即败，但关键节点自动存档，读档重打带来"历史可重来"的安心感 |

## 三、核心功能（MVP）

### F1. 日常事件解读（判决卡）

- 输入：用户描述一件日常事件（一句话到一段话）
- 处理：系统随机抽取一个世界观框架，结合机制库生成解读
- 输出：判决卡（150-300字），包含：
  - 事件定性（用该世界观的术语重新定义这件事）
  - 机制引用（引用1-3条具体机制作为"依据"）
  - 最终判决（一本正经的结论/建议）
- 交互：点击"重新解读"可换框架再来一次

### F2. 完整世界观展开

- 触发：判决卡下方"展开完整世界观"按钮
- 输出：六段式结构文档（流式输出）
  1. 核心隐喻：这个世界观的一句话本质
  2. 天意本质：最高机制在该框架下的解释
  3. 机制解释：选取3-5条机制，用该框架逻辑自洽地解释
  4. 角色定位：主要人物在该世界观中的身份/职业/功能
  5. 名场面重释：用该框架重新解读1-2个经典桥段
  6. 自洽性论证：论证该世界观为何"逻辑上成立"

### F3. 自定义世界观输入

- 输入：用户输入一个世界观关键词/描述（如"如果新三国是赛博朋克世界"）
- 处理：AI基于机制库 + 已有框架的few-shot，生成全新世界观
- 输出：同F2的六段式结构
- 意义：这是核心差异化——AI不只是套用模板，而是"创造"新世界观

## 四、调性规范

### 总原则：一本正经说荒诞

- 格式上：学术论文/官方文件/法律文书的严谨结构
- 内容上：完全荒诞的结论和推理
- 态度上：零反讽、零自嘲、零"这很荒谬"的暗示。叙述者完全相信自己在说真话
- 禁止：网络流行语、emoji、"哈哈哈"、打破第四面墙

### 文风参考

- 知乎"如何评价新三国"高赞回答的学术腔
- 折棒视频的吐槽逻辑（但去掉口语化，保留推理链）
- 伪纪录片旁白的庄重感

### 示例语气

> 经考证，"迟到"这一现象在新三国宇宙中属于典型的"星夜加成"副作用。当事人试图以星夜赶路模式通勤，但目的地并非军事目标，导致加成系数从+500%衰减至-30%。天意判定此为"非战争行为滥用超自然移动"，处罚为：全天运气-90%，且必然在电梯口遭遇领导。

## 五、视觉设计

### 风格关键词

深色艺术展 × 古卷质感 × 仪式感

### 色彩体系

- 背景：近黑偏暖褐（#1a1714 ~ #0d0b09），带宣纸/古卷纹理叠加
- 主文字：暖白（#f0e8d8）
- 强调色：朱砂红（#c04030）用于标题/印章/判决结论
- 辅助色：青铜绿（#5a7a6a）用于机制引用/注释
- 卡片底色：略浅于背景的深褐（#2a2420），带微弱内发光

### 排版

- 标题：大字号衬线体（思源宋体/Noto Serif SC），字间距略宽
- 正文：中等字号，行高1.8，阅读舒适
- 判决卡：居中展示，类似"展品铭牌"，有边框和微妙阴影
- 留白充足，内容区块间有呼吸感

### 动效

- 判决卡生成：从模糊到清晰的"显影"效果（像古卷上浮现文字）
- 世界观展开：逐段流式输出，带打字机光标
- 框架切换：卡片翻转/淡出淡入
- 整体克制，不花哨

### 参考

- mobanwang 摄影艺术模板22924的深色展览感
- 但内容驱动（文字为主），非图片驱动

## 六、UX流程

```
首页
├── 输入区（事件描述输入框 + "解读"按钮）
├── 判决卡展示区
│   ├── 框架名称标签（如"克苏鲁世界观"）
│   ├── 判决内容（150-300字）
│   ├── [重新解读] 按钮（换框架）
│   └── [展开完整世界观] 按钮
├── 世界观展开区（六段式，流式输出）
└── 自定义世界观入口
    ├── 输入框（"如果新三国是____世界"）
    └── 生成按钮 → 六段式输出
```

单页应用，无路由跳转。所有交互在同一页面内完成，通过滚动和展开切换视图。

## 八、MVP边界

### 包含

- 事件输入 → 随机框架 → 判决卡生成
- 判决卡 → 展开完整世界观（六段式）
- 自定义世界观输入 → 生成新世界观
- SSE流式输出
- 深色古卷视觉风格
- 移动端基本适配（响应式）

### 不包含（后续迭代）

- 用户账号/登录
- 历史记录保存
- 框架稀有度/抽卡机制
- 社交分享（生成图片/链接）
- 用户投稿世界观
- 多轮对话/追问
- 语音输入
