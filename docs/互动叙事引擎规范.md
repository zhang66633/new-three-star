互动叙事引擎 · 开发指导文档

> 定位：以 LLM 为驱动核心、Prompt 工程为控制框架的长期运行叙事系统。

目标：将 LLM 的不可控生成转化为可校验、可迭代、高一致性的工业化叙事生产流水线。

---

一、质量校验流水线（8 PHASE）

每轮 LLM 生成前，必须按顺序完成以下 8+0.5 个阶段的自检（PHASE 0.5「时间预算与目标追踪」为确定性预检/复核，就位与时间门禁由 director 确定性执行），所有检查项标记 `✓` 后方可进入输出阶段。

PHASE 0：时空锚定协议

检查项	规则	
时间锚点	记录当前日期、时间、季节、天气、时段特征	
时间连续性检测	比对上轮时间，计算流逝时长，确认合理性；大跳跃需显式标记	
场景位置	锁定当前城市、具体位置、交通方式、移动耗时

就位/进入条件	名场面触发前校验 entry_conditions ⊆ scene_state.qualifications 是否满足；不满足则判定错过（fame_moment=true）	
	
信息迷雾校验	明确玩家知识边界（仅看到/听到的内容）；执行上帝视角/未来视总检；NPC发言校验

> ⚠️ 已废弃：以下"名场面目标机制"（世界时钟/行动盘/就位门禁/失败读档）已被自由沙盒取代——
> 世界时间改为具体日期 `world_date {year, month, day}`（world.py 按行动推进），
> 时间/事件校验见 docs/自由沙盒重构设计.md §一/§二，引擎校验见 PHASE 1-8。保留本节仅为历史记录。

PHASE 0.5：时间预算与目标追踪（本 PHASE 为确定性预检/复核——就位与时间门禁由 director 确定性执行，validate 侧复核）

主角"亲身经历名场面"目标机制：主线骨架 + 名场面时间窗，名场面作为本章目标链。每章一条时间轴（如 189 年春夏秋冬），名场面锚定时节；玩家准备期行动消耗世界时间，时钟推进。章首揭示本章时间轴与名场面链（时节 / 就位条件 / 剩余时间），目标全可见。

核心循环：章首揭示 → 准备期行动盘自由行动（消耗时间 + 积累就位条件）→ 世界时钟推进 → 名场面时节到：就位条件满足 → 触发名场面（进入现有场景叙事）；不满足 → 错过关键名场面 → 失败。

检查项	规则	
名场面时节锚定	核对每个 fame_moment=true 场景的 fame_season 是否与 world_clock.current_season 对齐	
剩余时间	world_clock 顶层键记录 {chapter, current_season, turns_left}，实时核算距下一名场面的剩余回合/时节	
就位条件判定	名场面时节到时，校验 entry_conditions ⊆ scene_state.qualifications 是否成立；满足才可触发	
错过检测	fame_moment=true 场景未触发（时节到但就位不满足 / 未进入）→ 判定失败；普通场景错过不失败	
准备期行动盘	名场面之间，玩家从 prep_actions 选择准备行动（投靠/乔装/买情报/赶路），行动消耗 cost_turns 并积累 qualifications	
自动存档	关键名场面开始前自动存档（服务端 worlds.db 持久化）；失败读档回上个名场面重打	

引擎数据结构（名场面目标机制新增）

```
world_clock：state 顶层键，由 director/时间节点推进
{ chapter, current_season, turns_left }

registry 场景新字段（名场面）
fame_moment: bool           # 是否关键名场面
fame_season: string         # 锚定时节（如 "189 年夏"）
entry_conditions: [...]     # 就位条件列表（如 "在曹操身边"）
prep_actions: [...]         # 准备期行动盘 [{ text, cost_turns, grants[就位条件], effect }]

scene_state 新增字段
qualifications: [...]       # 已积累的就位条件
```
	

PHASE 1：真实性核验

检查项	规则	
地理核验	地点真实存在，周边地标可查，距离合理	
真实信息核验	涉及真实人物/品牌/事件需校验真实性	

PHASE 2：意图解析与记忆连贯

检查项	规则	
用户意图	拆解表层需求 → 深层意图 → 互动期待	
记忆连贯	追踪关键事件、未解伏笔、承诺、关系轨迹、玩家已知信息	

PHASE 3：人物一致性

检查项	规则	
玩家人格校验	核对设定性格（如 INFJ），确认内心独白/行为描写符合	
角色数据校验	核对登场角色的年龄、身份、核心性格、对玩家态度、对玩家的认知	
语言风格	每个角色锁定独特语言风格（如王瀚直爽、苏晚轻声）	
内心活动	每个角色必须有独立内心独白	
关系网络	确认关系值与上轮一致	

PHASE 4：防崩坏校验

检查项	规则	
防 OOC	角色底线未突破，身份言行一致，动机逻辑自洽	
防神化	玩家有现实限制，不能无所不能，信任需铺垫	
渐进性	关系变化有过程，好感发展有积累，能力提升有条件	
真实性	物理规律合理、社会常识符合、经济逻辑匹配身份、时间分配合理、地理距离交通合理	

PHASE 5：行为后果与资产核算

检查项	规则	
动态适配	根据玩家经济状况、社会地位、生活环境适配场景	
本次行为后果	核算法律/经济/关系/名声后果及连锁反应

准备期行动的时间/就位后果	准备期行动（prep_actions）核算时间后果（cost_turns 消耗，推进 world_clock.turns_left）与就位后果（grants 积累的 qualifications）；名场面时节临近或就位不足时，在叙事中显式提示剩余时间与缺失就位条件	
	
禁止预设	不能预设交流内容（玩家未选择的对话/行为不可提前写入）	

PHASE 6：场景与氛围

检查项	规则	
环境细节	必须覆盖：光线、声音、气味、温度、人流	
场景氛围	明确场景类型、氛围基调	
潜在事件	预判可能发生的后续事件	

PHASE 7：输出质量

检查项	规则	
状态栏格式	与上轮一致，模块齐全，符号正确	
字数	目标 600-1000 字	
描写均衡	必须包含：动作、对话、心理、环境	
感官细节	必须覆盖：视觉、听觉、触觉、嗅觉	
情感链条	必须完整：触发 → 生理 → 心理 → 行为	
记忆区校验	STM 条数/字数、LTM 条数/字数、格式一致性

二、分层记忆系统

2.1 STM（短期记忆）
- 容量上限：6 条
- 单条长度：50–80 字
- 内容：当前会话的客观事实摘要
- 晋升规则：满 6 条后，自动合并提炼为 1 条 LTM

2.2 LTM（长期记忆）
- 容量上限：无上限
- 单条长度：120–150 字
- 内容：跨会话持久存储的客观事实
- 原则：以客观事实为主，避免主观评价

2.3 PIN（钉选记忆）
- 机制：手动标记重要记忆
- 作用：高优先级检索，防止被后续记忆淹没
- 管理：可随时钉选/取消

记忆格式规范

```
STM [x/6]｜LTM [y/y]｜PIN z条

【📌 PIN 钉选记忆】
| # | 时间 | 标签 | 内容 |
|:--|:--|:--|:--|
| - | - | - | 暂无 |

【📚 LTM 长期记忆】
| # | 时间跨度 | 场景 | 客观事实(120-150字) |
|:--|:--|:--|:--|
| 1 | 2025.9.1 09:30-19:45 | 报到至班会前半段 | ... |

【📝 STM 短期记忆】
| # | 时间 | 场景 | 客观事实(50-80字) |
|:--|:--|:--|:--|
| 1 | 2025.9.1 19:25-19:45 | 敏达楼N201教室 | ... |
```

四、叙事质量规范

4.1 情感链条（强制四阶段）
任何角色反应必须完整推导：

```
触发（外部事件） → 生理（身体反应） → 心理（内心活动） → 行为（外在行动）
```

4.2 感官细节（强制覆盖）
每轮输出必须包含：
- ✅ 视觉
- ✅ 听觉
- ✅ 触觉
- ✅ 嗅觉

4.3 描写均衡
每轮输出必须均衡覆盖：
- ✅ 动作
- ✅ 对话
- ✅ 心理
- ✅ 环境

4.4 渐进性约束
- 关系变化必须有过程，禁止跳跃式好感飙升
- 能力提升必须有条件，禁止无铺垫获得新技能
- 信任建立必须有铺垫，禁止 NPC 无故信任玩家

4.5 信息迷雾（防泄漏）
- 玩家知识边界：严格限定为"看到、听到的内容"
- 上帝视角/未来视总检：每轮必须显式确认 `✔无泄漏`
- NPC发言校验：NPC 只能基于其自身知识说话
- 敏感信息隔离：⚠️ 标记并隔离玩家不应知道的信息

4.6 防崩坏红线

类型	规则	
防 OOC	角色言行必须符合其核心性格与动机	
防神化	玩家不能无所不能，必须受现实条件限制	
渐进性	所有变化必须有积累过程	
真实性	物理规律、社会常识、经济逻辑、时间分配、地理距离必须合理	

4.7 输出策略模板

```
【综合评定】{{🟢通过 / 🟡警告 / 🔴不通过}}
【输出策略】{{本轮重点、描写侧重、结尾过渡设计}}
```

五、内容安全分级

肉体描述规则
- 男性角色：不显示肉体描述栏
- 女性角色：显示肉体描述栏，暴露程度可控（如"胸部：B罩杯，坐姿端正"）
- 未涉及部位：标记为"未涉及"

```

□ P6 环境五感（光/声/味/温/人流）已覆盖
```
