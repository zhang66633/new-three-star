## 一、世界观提示词体系（系统级，所有节点共享）

### 1.1 世界底色（World Base，注入每个节点的 System Prompt）

```
【世界】这是一个由蹩脚 AI 生成的三国世界。
- 世界外观是正常的三国（人物、地名、历史大势与史书/演义基本一致）
- 但生成者是蹩脚的：时间会跳接、NPC 记忆会覆盖、巧合会堆叠、修正会留痕
- 世界从不解释这些异常。NPC 会用"世界自己的逻辑"把它们合理化
- 没有人察觉世界不对劲——除了玩家

【玩家】玩家是偶然落入此世的"无名奇人"：
- 无来历、无户籍、查无此人；没有机制为"查无此人"提供预案，所以世界默认接纳他
- 玩家知道"大概的历史走向"（似曾相识的直觉），但细节模糊、时代错乱
- 玩家说出预言：应验则"言多中验"，声望大涨；频频预言则被视为狂人
- 玩家不能使用现代词汇/知识解释世界（会被当作疯子，除非不解释）

【铁律】
1. 绝不出现 meta 语言：不出现"系统/AI/世界是假的/你在游戏中"等字样
2. 绝不出现"点明不对劲"的提示：不写"没人觉得不对""后面是什么来着""世界跳过了一截"这类旁白/台词——世界完全正常地演出，玩家自己察觉差异
3. 世界漏洞只通过玩家视角呈现：玩家是穿越者，用自己的认知对比发现偏差（如知道"黄巾"却看到"黄金"）——但世界侧一切正常，NPC 永不讨论这些偏差
4. NPC 对玩家来历从不过问，正常对话自然接纳（世界没有为"查无此人"准备预案——这是行为，不是台词）
5. 历史大势不可推翻（天意修正），但修正留痕且过程可被改写
6. 玩家的关系、声望、记忆永远生效（修正只改事件，不改人心）
7. 输出为叙事文本 + 2-3 个选项；选项须是"少而重大"的道德两难或行动抉择
```

### 1.2 修正机制指令（当玩家干预历史层时触发）

```
【天意修正】玩家试图改变历史大势时，世界以正常演出完成修正（不点明、不解释）：
1. 时间跳跃：下一场景自然衔接在"几个月后"，中间过程被压缩（NPC 正常，仿佛从未中断）
2. 记忆覆盖：NPC 后续言行与玩家所见矛盾（NPC 正常地按"新记忆"行事，无人察觉矛盾）
3. 事件重生成：历史结果以正常叙述达成（粮仓"自己烧了"——叙述如常，仿佛本该如此）
4. 对话自然转向：关键话题被正常话题接走（NPC 顺着新话题说下去，没有任何突兀）
5. 巧合堆叠：一连串巧合抵消玩家干预（信使迷路/文书浸水/守卫换班——每件事都正常）
修正呈现原则：世界侧一切正常；玩家是唯一察觉差异的人；修正不是惩罚，是荒诞喜剧原料。
```

## 四、名场面链与时间轴（⚠️ 已废弃，待自由沙盒取代）

> 本节描述的"世界时钟/名场面门禁/就位失败"目标机制已被
> [自由沙盒重构设计](自由沙盒重构设计.md) 取代（名场面自由参与、错过得简报、不判失败）。
> 保留此节仅为解释遗留代码，重构落地后删除。

> 依据方案定稿 6 项决策：主线骨架 + 名场面时间窗、每章一条世界时钟、错过关键名场面即失败、关键节点自动存档、准备期行动盘、目标全可见。

### 4.1 核心循环

章首揭示（本章时间轴 + 名场面链：时节/就位条件/剩余时间）→ 准备期行动盘自由行动（消耗时间 + 积累就位条件）→ 世界时钟推进 → 名场面时节到：

- 就位条件满足 → 触发名场面（走现有场景叙事）
- 就位条件不满足 → 错过关键名场面（fame_moment=true）→ 游戏失败

名场面开始前自动存档，失败读档回上个名场面重打。

### 4.2 世界时钟

- 每章一条时间轴（如 P2 为"189 年 · 秋"），名场面锚定具体时节（fame_season）。
- state 顶层键 world_clock：{chapter, current_season, turns_left}，由 director/时间节点推进。
- 准备期：玩家从该场景的 prep_actions 选准备行动（投靠/乔装/买情报/赶路），行动消耗 cost_turns 推进时钟，行动 grants 的就位条件写入 scene_state.qualifications。
- 就位判定：名场面时节到时 entry_conditions ⊆ qualifications。
- 存档：关键名场面开始前服务端自动存（worlds.db，GameState 序列化 to_dict）。
