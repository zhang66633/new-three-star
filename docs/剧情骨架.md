## 一、世界观提示词体系（系统级，所有节点共享）

### 1.1 世界底色（World Base，注入每个节点的 System Prompt）

```
【世界】这是一个由蹩脚 AI 生成的三国世界。
- 世界外观是正常的三国（人物、地名、历史大势与史书/演义基本一致）
- 但生成者是蹩脚的：时间会跳接、NPC 记忆会覆盖、巧合会堆叠、修正会留痕
- 世界从不解释这些异常。NPC 会用"世界自己的逻辑"把它们合理化
- 没有人察觉世界不对劲——除了玩家

【玩家】玩家是偶然落入此世的"无名奇人"：
- 无来历、无户籍、查无此人；没有机制为"查无此人"提供预案，所以世界默认接纳他
- 玩家知道"大概的历史走向"（似曾相识的直觉），但细节模糊、时代错乱
- 玩家说出预言：应验则"言多中验"，声望大涨；频频预言则被视为狂人
- 玩家不能使用现代词汇/知识解释世界（会被当作疯子，除非不解释）

【铁律】
1. 绝不出现 meta 语言：不出现"系统/AI/世界是假的/你在游戏中"等字样
2. 世界漏洞只以叙事呈现：时间接缝、记忆覆盖、事件重生成、对话掐断、巧合堆叠
3. NPC 对玩家来历从不过问；被问起就含糊带过（"似乎见过，又似乎没有"）
4. 历史大势不可推翻（天意修正），但修正留痕且过程可被改写
5. 玩家的关系、声望、记忆永远生效（修正只改事件，不改人心）
6. 输出为叙事文本 + 2-3 个选项；选项须是"少而重大"的道德两难或行动抉择
```

### 1.2 修正机制指令（当玩家干预历史层时触发）

```
【天意修正】玩家试图改变历史大势时，世界用以下方式之一修正（随机/按情境）：
1. 时间接缝：场景直接跳到"三个月后……"，中间过程被压缩，玩家看到结果
2. 记忆覆盖：NPC 突然记错关键事实，与玩家所见矛盾；NPC 不自知
3. 事件重生成：事件以荒谬的新方式达成历史结果（粮仓"自己烧了"）
4. 对话掐断：关键对话被强行打断（"此事莫要再提"），NPC 态度急转
5. 巧合堆叠：一连串巧合抵消玩家干预（信使迷路/文书浸水/守卫换班）
修正后：玩家是唯一知道真相的人。NPC 对玩家的信任/怀疑保留（按关系值）。
修正不是惩罚：它是荒诞喜剧的原料，玩家应感受到"世界在回应我"。
```

## 三、P1 黄巾风起（序章 · 完整设计演示）

### 场景 1.1 雨夜醒来（开局）

**设定**：184 年春，颍川。玩家在暴雨中醒来，身无分文，衣衫褴褛，记忆只剩模糊的现代碎片（手机、城市的轮廓、一段新闻——"黄巾起义"）。

**世界漏洞钩子（第一次感知）**：雨夜，远处有火把游动。一个黑影踉跄跑过，大喊：
> "苍天已死！黄天当立！……你！你是什么人？怎么从未见过你？"
> （黑影看了玩家三秒，突然自顾自地说）"……也罢，世道乱了，什么人都可能冒出来。"

→ 黑影转头跑掉。玩家获得第一印象：这个世界的人**对来历不明者接受得异常快**。

**生成叙事**（Writer 输出示意）：
> 雨砸在脸上，冷得刺骨。你躺在一片泥泞里，身上是粗麻衣——不知谁给你换的。记忆像被水泡过的纸，只有碎片：高楼、屏幕、一条新闻标题……"黄巾起义，波及八州"。
> 火光在雨幕里忽明忽暗。一个人影跌跌撞撞跑过，见了你猛地一停："你！你是什么人？"
> 你张了张嘴，什么也说不出来。
> 那人盯着你看了很久，忽然道："……也罢。世道乱了，什么人都可能冒出来。往北走，别回头——前面在杀人。"

**选项**（1 个重大 + 1 个轻）：
1. **[重大] 追上去**，跟着黑影逃难（开启"流亡"线，结识同路人）——不可逆
2. **[轻] 往火光方向走**，看看"前面在杀人"是怎么回事（目睹黄巾军，触发第一次世界观展示）
3. **[轻] 原地躺下**，等天亮再想（触发"世界在你睡着时跳过了什么"——醒来已是三天后，衣服换了，身边多了个包袱，包袱里有一封信）

### 场景 1.2 黄巾乱军（世界观展示）

**设定**：无论玩家怎么选，都撞上黄巾军的一支溃兵。展示"蹩脚 AI 世界"的第一个显性漏洞：

**漏洞展示**：黄巾军旗上写的是"黄金"而非"黄巾"；一个黄巾兵正对着空气慷慨激昂地喊话（他的"天公将军"命令像是排练过的台词，背完就忘）。

**黄巾兵台词**（借鉴原著梗）：
> "苍天已死，黄金当立！岁在甲子，天下大吉！……呃，后面是什么来着？"
> "管他呢，反正天公将军说了，打完这一仗，人人有地种！"

**选项**：
1. 低头装死，躲过溃兵（轻）
2. 应一声"大吉"，混入队伍（开启"混入黄巾"隐藏线——后续可影响 P2 玩家在洛阳的身份铺垫）
3. **[重大] 救下一个被溃兵追杀的乡绅**——他自称"许家人"，说日后定有厚报（埋 P2 许都关系线；若见死不救，P2 少一个关系）

### 场景 1.3 时代快进（时间接缝 · 首次修正演示）

**设定**：无论玩家在颍川做什么，黄巾之乱终将被镇压。场景在此处**时间接缝**：

> 你只记得那些日子在逃难、在躲藏、在跟着流民队伍走。然后——画面像被剪掉了一截——你站在一座城的城门口，城头写着"洛阳"。身边的老者拍拍你的肩："后生，到京城了。朝廷平了黄巾，天下太平了！"
> 你低头看，自己手里攥着一封信。什么时候有的？你完全不记得。

**系统效果**：时间从 184 跳到 189（董卓入京前），玩家获得"信"道具（P2 线索，由 P1 的选择决定内容）。

**P1 结算**：声望 +（无论选什么，活着到洛阳就有基本声望）；关系（许家人线若有）；记忆碎片（"黄巾"vs"黄金"的疑惑——世界第一处不对劲）。

## 四、P2 洛阳暗夜（详细设计演示）

### 场景 2.1 洛阳街头

**设定**：189 年，洛阳。玩家作为无名流民在京城谋生（可选的活法：帮厨/搬运/代人跑腿）。亲眼目睹董卓入京的盛况。

**原著锚点**：小说第 1 章《曹操献刀》的开场——洛阳大旱、鹰鹫遮天、百官朝靴排成等级。

**漏洞钩子**：玩家向客栈掌柜打听"现在是什么年号"，掌柜理所当然地回答"光和七年"，但客栈墙上挂的日历却写着"中平元年"——没人觉得不对，包括掌柜。

### 场景 2.2 王允寿宴（玩家介入点 1 · 重大选择）

**设定**：玩家被"机缘巧合"卷入王允寿宴的筹备（跑腿/送菜/误闯），在宴席外偷听到曹操与袁隗的对话——这正是小说第 1 章的名场面（"国贼董卓"之辩）。

**玩家可选**：
1. **[重大] 混入寿宴**，亲眼见证曹操"足下怎么不说了"的名场面（在场=获得"目击者"声望，曹操注意到玩家——开启曹操关系线）
2. **[重大] 避开寿宴**，在街头撞见董卓入城队伍（目睹董卓暴行，开启"西凉线"——日后可选择为董卓做事/刺杀他）
3. [轻] 继续跑腿，错过名场面（保守，但保留 P3 的"中立"优势）

### 场景 2.3 曹操献刀之夜（玩家介入点 2 · 重大选择）

**设定**：曹操行刺董卓失败，连夜逃出洛阳。玩家在城门遇到曹操——

**原著锚点**：小说中曹操献刀后出逃，遇陈宫、杀吕伯奢全家（"曹操盖饭"梗出处）。

**玩家可选**：
1. **[重大] 帮曹操出城**（借马/引路/拖延追兵）——曹操欠玩家一个人情，P3 诸侯聚义时曹操会当众提到"恩人"
2. **[重大] 向董卓的人告发**（或不出手）——开启"董卓阵营线"或"中立线"
3. [轻] 假装没看见（保持无名——但曹操记住了这张脸）

**P2 结算**：声望/关系线确认；"信"的内容揭晓（P1 埋的伏笔：若救过许家人，信是许子将的推荐信，P3 可凭此见曹操；若没有，信是空白，但玩家发现自己能看懂上面写的字——"世界的文字为你而生"的漏洞暗示）。
