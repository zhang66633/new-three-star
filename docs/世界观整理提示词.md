# 世界观整理提示词（给另一个 AI 用）

> 用途：让另一个 AI 从折棒吐槽 + 新三国原著整理"历史事件时间线"，作为自由沙盒世界的世界事件数据源。
> 使用：把本提示词 + 相关素材文件发给另一个 AI，让其按**分片**产出 `history_timeline_*.json`。
> 版本 v1.1（防偷懒 + 可索引加固）。

---

## 一、防偷懒与可索引原则（先看这个）

> 给另 AI 前，先向它声明以下硬约束——这些是为了防止它偷懒、防止产出引擎难解析。

1. **分片产出**：不产出一个大文件。按年代分 4 片，每片独立文件、独立交差：
   - `history_timeline_1.json`：184-190 年（≤12 事件）
   - `history_timeline_2.json`：191-200 年（≤12 事件）
   - `history_timeline_3.json`：201-210 年（≤12 事件）
   - `history_timeline_4.json`：211-220 年（≤12 事件）
2. **必须覆盖锚点**：每片开头列"必须覆盖的事件锚点"，一条都不能跳，全部对号入座
3. **交互不写空话**：`player_interactions.desc` 必须含具体动作名词，给出正/反例
4. **封闭枚举**：`type` 只能用 5 个值，`related_to_player` 只能用 2 个值
5. **规范化字段**：地点用注册表地名、人名用已知名单，不得自造变体
6. **产出自检**：AI 产出后自行核对清单，不达标重做

---

## 二、可索引字段规范（引擎硬要求）

| 字段 | 规范 | 例 |
|---|---|---|
| `event_id` | 唯一：`e_{年}_{月}_{英文slug}` | `e_184_02_huangjin` |
| `date` | **可排序格式** `"年-月"`（两位月）| `"184-02"` |
| `type` | **封闭枚举** `observe\|participate\|influence\|trade\|conflict` | `participate` |
| `related_to_player` | **封闭枚举** `strong\|weak` | `strong` |
| `locations` | 用注册表地名（见下），数组 | `["颍川"]` |
| `key_npcs` | 用 KNOWN_NAMES 名单（见下），数组 | `["曹操"]` |
| `achievement` | 可选，成就名（自动注册）| `"亲历黄巾溃兵"` |
| `title` | 可选，称号名（事件授予）| `"乱世见证者"` |

**注册表地名**（用这些，不要自造）：`颍川`、`洛阳`、`中牟`、`成皋`、`许都`、`陈留`、`徐州`、`小沛`、`冀州`、`官渡`、`赤壁`、`汉中`、`荆州`、`益州`、`长安`、`宛城`、`麦城`、`成都`、`南郡`、`合肥`

**KNOWN_NAMES 名单**（人名用这些全名）：曹操、刘备、关羽、张飞、诸葛亮、司马懿、吕布、董卓、袁绍、袁术、孙权、周瑜、陈宫、王允、貂蝉、赵云、马超、黄忠、魏延、庞统、姜维、鲁肃、吕蒙、陆逊、张角、张宝、张梁、华雄、颜良、文丑、邢道荣、许攸、蔡瑁、徐庶、法正、孙坚、孙策、吕伯奢、汉献帝

## 三、提示词正文（复制下面整段发给另一个 AI）

```
你是一位熟悉《新三国》电视剧与《三国演义》的剧情研究专家，正在为一个"自由沙盒三国游戏"
整理世界观与历史事件时间线。游戏设定：世界按真实历史时间线独立推进，玩家是自由参与者，
可改局部细节、不可改历史大势。你的产出将作为游戏的"世界事件数据源"。

## 背景素材
- 新三国原著/台词：materials/script_ocr/full_script.txt、materials/字幕台词/
- 折棒吐槽（285 期锐评）：materials/电视剧吐槽/
- 已有世界观机制库：materials/新三国世界观素材库.md
- 已有梗文化：materials/新三国天意理论与梗文化.md

## 硬约束（必须遵守，违反即重做）
1. 【分片】本片只整理 {START}-{END} 年，最多 12 个事件。不要跨片、不要合并成一个大文件。
2. 【锚点全覆盖】本片必须覆盖以下锚点事件（一条都不能跳，逐一对号入座）：
   {MUST_COVER}
   如果锚点中有你觉得"不该算事件"的，也要写出来（写 1 条 observe 交互即可）。
3. 【交互不空话】player_interactions.desc 必须含具体动作名词，如：
   ✅ "混入黄金军队伍，套取颍川防线情报"
   ❌ "可旁观" / "可参与" / "能互动"
   至少 2 条交互，每条必须具体到"做了什么、能得到什么"。
4. 【封闭枚举】type 只能用：observe / participate / influence / trade / conflict
   related_to_player 只能用：strong / weak
5. 【规范化】locations 用注册表地名；key_npcs 用 KNOWN_NAMES 名单。
6. 【自检】产出后核对：事件数达标？锚点全覆盖？交互≥2且具体？字段规范？不达标重做。

## 本片时间范围
{START}-{END} 年
```

## 五、产出后接入

另 AI 产出 `history_timeline_1~4.json` 后：
1. 放入 `backend/knowledge/history_timeline/` 目录
2. `events.py` 读取全部 4 片，按 `date` 排序建索引（引擎按日期触发）
3. `achievement`/`title` 字段自动注册成就与称号
4. 用 jsonschema 校验（schema 见 docs/历史事件.schema.json）
