# 世界常态设定提示词

> 用途：让另一个 AI 产出《世界常态设定》——势力/地点/人物"平时怎么运转"的底色，填补历史时间线的事件空档（玩家日常游荡时的内容来源）。
> 使用：把本提示词 + 相关素材发给另一个 AI，按**分片**产出 `world_normal_*.json`。
> 版本 v1.0（复用防偷懒 + 可索引方法论）。

---

## 一、防偷懒与可索引原则

1. **分片产出**：按 6 个阶段分 6 个文件，每片独立交差，杜绝截断
2. **锚点全覆盖**：每片列"必须覆盖的势力/人物"，逐一对号入座，不能跳
3. **封闭枚举**：`type`/`tone` 等只能用规定值
4. **规范化字段**：地点用注册表地名、人名用 KNOWN_NAMES 名单
5. **产出自检**：AI 产出后核对清单，不达标重做

## 四、可索引字段规范

| `type`（location）| 封闭枚举 `rural\|city\|capital\|mountain\|river` |
| `tone`（atmosphere）| 封闭枚举 `chaotic\|oppressive\|hopeful\|fatalistic\|epic` |
| `player_relation_default` | 封闭枚举 `strong\|weak` |

## 五、提示词正文

```
你是一位熟悉《新三国》电视剧与《三国演义》的剧情研究专家，正在为一个"自由沙盒三国游戏"
整理【世界常态设定】——不是历史事件，而是世界"平时怎么运转"的底色（势力/地点/人物日常状态）。

游戏设定：世界按真实历史时间线独立推进，玩家是自由参与者。历史时间线已整理（大事件骨架），
你负责补充事件之间的"日常世界"——玩家在某个时间阶段、某个地点游荡时，会撞见什么、各势力
人物在干什么。

## 背景素材
- 新三国原著/台词：materials/script_ocr/full_script.txt、materials/字幕台词/
- 折棒吐槽（285 期）：materials/电视剧吐槽/
- 世界观机制库：materials/新三国世界观素材库.md
- 历史事件时间线（已完成，你产出的）：backend/knowledge/history_timeline/history_timeline_*.json

## 硬约束（必须遵守，违反即重做）
1. 【分片】本片只做 {PHASE} 阶段（{TIME_RANGE}），只输出该阶段的常态设定。
2. 【锚点全覆盖】本片必须覆盖以下势力与人物（不能跳）：
   {MUST_COVER}
3. 【五维完整】每片必须含 world / factions / locations / characters / atmosphere 五维。
4. 【封闭枚举】location.type 用 rural/city/capital/mountain/river；atmosphere.tone 用 chaotic/oppressive/hopeful/fatalistic/epic。
5. 【规范化】地点用注册表地名；人物用 KNOWN_NAMES 名单。
6. 【自检】产出后核对：五维完整？锚点全覆盖？枚举规范？不达标重做。

## 本片阶段
{PHASE}（{TIME_RANGE}）
```

## 七、产出后接入

另 AI 产出 `world_normal_1~6.json` 后：
1. 放入 `backend/knowledge/world_normal/` 目录
2. `events.py` 按玩家当前 `world_date` 判断所处阶段，把对应阶段常态注入 writer 提示（"当前世界背景"）
3. 玩家日常叙事（非时间线事件时）由 LLM 基于该阶段常态即兴生成
