# 新三国 星空 · 场景开发协议

> v1.0 ｜ 2026-08-08 ｜ 每个场景四步确认，不跳步。

## 前置：折棒吐槽文风提炼

在开发场景前，先从 285 期折棒锐评中提炼核心文风特征作为生成基调。

### 文风七要素

| # | 要素 | 描述 | 示例 |
|---|------|------|------|
| 1 | **原著锚定** | 每吐槽必引原著对比，指出"新三国的XX和原著完全不同" | "三国演义原著曹操是说自己的马瘦弱跑不快，新三国却说马快被饿死了……" |
| 2 | **逻辑归谬** | 顺着编剧的荒谬逻辑推到极端，让漏洞自行暴露 | "你说加不起油，他送你法拉利——那不是更加不起油吗？" |
| 3 | **梗化命名** | 给角色/现象起浓缩外号，易于传播 | "乌角鲨"、"虫系宝可梦大师陈宫"、"死亡抗性II" |
| 4 | **口语代入** | 用"咱们"、"你"、"这"拉近距离，像朋友吐槽 | "你想想看"、"这就很没道理"、"那可不成啊" |
| 5 | **知识降维** | 用现代日常事物类比古代，消解严肃感 | "编剧的脑回路"、"NPC"、"RPG游戏"、"管理员系统" |
| 6 | **弹幕节奏** | 长吐槽中穿插超短金句，一针见血 | "仗着看过剧本"、"不是没人性是没脑子" |
| 7 | **天意统摄** | 所有荒谬最终归因到"天意"框架，形成自洽世界观 | "天意爷自己都疯掉了"、"被天意推着走" |

### 文风在叙事中的落点

- **世界侧**（NPC/环境）：正常演出，不调侃
- **玩家视角**（内心/差异笔记）：允许折棒式吐槽——"你记得史书上写的是黄巾，可眼前旗上分明是黄金"
- **选项effect**：微带梗味——"曹操可能会'不小心'记住你"、"获得debuff：未经计划的攻势"
- **不出现的位置**：锁定台词（原剧台词）、场景设定正文、质量检查面板

## 场景开发四步流程

### Step 0：确认场景范围

**产出**：场景卡片

| 字段 | 说明 |
|------|------|
| 场景ID | P{n}_{s}{m}_{slug} |
| 篇章 | P1 黄金风起 / P2 洛阳暗夜 / ... |
| 原著锚点 | 三国演义第X回 / 对应剧情 |
| 字幕锚点 | 折棒第X-Y期 |
| 涉及角色 | 登场NPC列表 |
| 历史节点 | 该场景在史实时间线上的位置 |

→ **确认点**：场景范围是否正确？是否有遗漏的关联剧情？

---

### Step 1：读原著 → 提取"原本应该发生的"

**操作**：
1. 读取 `materials/script_ocr/full_script.txt` 对应段落的原著
2. 提取关键事实：时间、地点、人物、事件、台词

**产出**：原著事实清单
```
时间：光和七年（184年）春
地点：颍川荒野
人物：玩家（无名旅人）、黑影（逃难路人）
事件：主角雨夜醒来，身无分文，记忆破碎
原著对照：黄巾起义前夕，颍川为黄巾军活动区域
关键台词：（无——开场为原创引入场景）
```

→ **确认点**：原著事实是否有遗漏或错误？

---

### Step 2：读吐槽字幕 → 提取"新三国的荒谬"和梗

**操作**：
1. 读取 `materials/电视剧吐槽/` 中对应期数的折棒吐槽
2. 提取三个层次：
   - **L1 事实错误**：新三国在这里怎么乱改的？
   - **L2 逻辑漏洞**：为什么改完之后更荒谬了？
   - **L3 可用梗**：折棒怎么吐槽的？哪些梗可以融入叙事？

**产出**：梗素材卡片
```
关联期数：02-05期（董卓/曹操/陈宫线 — 前期风格锚定）
可用梗：
  - "人物智商处于混沌状态" → 世界侧 NPC 偶尔犯蠢的底色
  - "仗着看过剧本" → 玩家穿越者的直觉来源
  - "加不起油送法拉利" → 董卓式逻辑（后续场景可用）
  - "不是没人性是没脑子" → 世界 AI 生成不合理的底层解释
文风参考：理性拆解 + 口语吐槽 + 原著对比节奏
```

→ **确认点**：哪些梗适合融进这个场景？哪些留给后续？

---

### Step 3：设计剧情 → 生成场景文件

**操作**：基于 Step 1 的原著事实 + Step 2 的梗素材，设计：

1. **场景骨架**（`registry.json` 条目）：
   - scene_id、chapter、year、season、location
   - title、setting、atmo（氛围标签，须命中 `frontend/src/assets/atmo/atmo_map.json`）
   - music（可选，目前仅 `"guanyu"` 触发关羽之歌，默认缺省）
   - world_normal（世界侧正常演出）
   - player_pov（玩家视角差异/可用的梗）
   - locked_lines（必须出现的台词，来自原著或吐槽）
   - aftermath.flow（岔路逻辑：字符串=线性推进；字典=按 flags/tension 分支）

2. **叙事基调**：
   - 世界侧：正常三国演出，NPC 不察觉异常
   - 玩家侧：折棒式内心吐槽 + 差异发现
   - 选项：2-3 个，带 tension + 微梗 effect

**产出**：
- `backend/engine/scenes/registry.json` 新条目
- `docs/scenes/{场景ID}_{标题}.md` 详细设计文档

→ **确认点**：剧情走向、关键选择、锁定台词是否合理？

---

### Step 4：验证 → 冒烟测试

**操作**：
1. `python -c "from engine.director import load_registry; r = load_registry(); assert '{scene_id}' in r"`
2. 手动跑一轮 → 看叙事是否流式、校验是否通过、记忆是否正确追加
3. 检查：五感覆盖？描写均衡？情感链条？角色不OOC？

→ **确认点**：场景可玩？有需要调参的地方？

