# P4_s7 吕布之命·白门楼

> 场景开发协议五步流程 · P4_s7（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第19回（下邳城曹操鏖兵 / 白门楼吕布殒命）
> 字幕锚点：折棒 55-58 期（三姓家奴谢幕 / 魏武挥鞭天气控制器）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P5）：**救 vs 送**。陈登献徐州吕布退守下邳，陈宫献内外犄角之计，吕布因貂蝉病危拒不出城；曹操"天公助我"水淹下邳，部将叛变（"你有赤兔马，还有美妾貂蝉"）。白门楼上刘备一句"可还记得丁原和董卓"送他上路。玩家是一句话把吕布钉上绝路，还是反着替他求情？

**设计原则**：
- **名场面开场即现场**：玩家入场即在下邳城，亲历"陈宫献策 → 水淹下邳 → 部将叛变 → 白门楼"全链。这是 `见证者_吕布之命` 的触发点，非可选。
- **字幕锚定**：曹操"天公助我"、陈宫"做水中鱼虾还是开城投降"、部将"你有赤兔马，还有美妾貂蝉"、曹操"绑虎不得不紧"、刘备"可还记得丁原和董卓"、吕布"大耳贼，你忘恩负义"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是方天画戟，是"三姓家奴四个爹都因他而死"；最讽刺的是叛变理由"得把貂蝉拉出来犒赏三军才叫待你们不薄"。
- **时间边界**：198 年冬，下邳。献策 → 殒命（一场内）。袁术败亡留 P4_s8。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：曹操"天公助我"水淹下邳。

- **场景**：徐州·下邳城白门楼。泗水灌城、部将反叛、白门楼问斩。
- **锁定台词（必须逐字出现）**：
  - 曹操："天公助我！"
  - 陈宫："曹军掘开河堤，把下邳灌成了一片汪洋。上将军，你有两种选择，一是做水中鱼虾，二是开城投降。"
  - 部将："你有赤兔马，渡水如履平地，你还有美妾貂蝉。"
  - 曹操："奉先啊，绑虎不得不紧啊。"
  - 刘备："孟德可还记得丁原和董卓吗？"
  - 吕布："大耳贼，你忘恩负义！"
- **世界侧**：下邳城防坚实、屯粮充足，城外泗水湍急绕城；将军府内吕布与貂蝉饮酒抚琴，陈宫昼夜巡城、军士按部操练；集市商贩照常往来，百姓不知大祸将至。正值寒冬腊月，家家备御冬棉衣——曹营谋士却掐着表喊"雨季快到了"。
- **玩家视角（乐子人）**："三姓家奴谢幕：吕布前后四个爹都因他而死，谁做他义父谁就不得好死——大灾星认证。"
- **必然结果**：玩家成为名场面亲历者 → `flags_add: ["见证者_吕布之命"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **陈登献徐州** → 吕布退守下邳，陈宫献策（过渡铺垫）
2. **陈宫献策被拒** → "貂蝉是我至爱，万一她有不测，我活得还有什么意思"，陈宫"死无葬身之地"
3. **水淹下邳** → 曹操"天公助我"，泗水灌城（乐子人高潮）
4. **部将叛变** → "你有赤兔马，还有美妾貂蝉"，私看曹操赏格被打五十军棍
5. **白门楼殒命** → 刘备"可还记得丁原和董卓"，吕布"大耳贼忘恩负义"；陈宫"死则死"

## 五、骨架选项（自由行动方向，非剧情分支）

1. **围观曹操猛吹吕布"人中吕布马中赤兔"、拿骂人的话当夸人的话**（tension 5）→ 数曹操自创了几个官职（observe）
2. **学"吕布四个爹都因他而死"一句话把吕布钉上绝路**（tension 45）→ 成就"一言送走吕奉先"、称号"白门楼送葬人"（influence）
3. **抢在曹操招大水前捣鼓泗水河堤，看大水能否改道**（tension 40）→ 跟曹操比谁的召唤术猛（conflict）
4. **大水灌城后趁乱下水捞"过河钱"，捡被冲晕的名人**（tension 25）→ 浑水摸鱼（participate）
5. **陈宫临刑前直播曹操杀吕伯奢黑历史，你在场吃瓜或递一坛断头酒**（tension 30）→ 看曹操乐呵呵说"纲常伦理庸俗不堪"（observe）

## 六、文风落点（乐子人版）

- **世界侧**（NPC/环境）：正常演出，不调侃——曹操正常水淹、吕布正常被擒、陈宫正常赴死
- **玩家视角**（内心/差异笔记）：折棒式吐槽——"叛变理由'赤兔+貂蝉'，得把貂蝉拉出来犒赏三军才叫待你们不薄"、"水淹下邳是走过场动画，第二天水全退光"、"魏武挥鞭是天气控制器，挥鞭引雷召来大洪水"
- **选项 effect**：微带梗味——"成就'一言送走吕奉先'"
- **不出现**：袁术败亡（P4_s8）、煮酒论英雄（P4_s9）、官渡之战等后续
