# P5_s14 单刀赴会

> 场景开发协议五步流程 · P5_s14（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第66回（关云长单刀赴会）
> 字幕锚点：折棒 205-208 期（主客颠倒 / 换大盏换大杯）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P5）：**讨三郡 vs 拒交**。孙权与病重的鲁肃议定讨荆州，诸葛瑾赴成都哭诉，刘备松口"先将长沙、零陵、桂阳三郡归还吴侯"。关羽却把手令拍在案上："荆州每寸土地，都是我将士拼着性命从曹操手里夺来的，岂能拱手让人！"——"将在外，君命有所不受。我哥好说话，我可不好说话！"诸葛瑾被轰走，东吴震怒水师逼境却又后撤二十里。关羽只带周仓单刀过江——"来，换大盏！"。玩家是递杯顺走舆图、偷听鲁肃战略，还是把联盟推向破裂？

**设计原则**：
- **名场面开场即现场**：玩家入场即在长江渡口，亲历"讨三郡 → 拒交 → 单刀过江 → 席间对峙 → 挟鲁肃 → 送三郡"全链。这是 `见证者_单刀赴会` 的触发点，非可选。
- **字幕锚定**：关羽"荆州每寸土地都是我将士拼着性命从曹操手里夺来的岂能拱手让人"、关羽"将在外君命有所不受，我哥好说话我可不好说话"、关羽"我只带周仓一人过江"、关羽"和子敬兄饮酒我当然不客气，来换大盏"、周仓"天下土地有德者居之绝非江东囊中物"、鲁肃"我不是救你，是救孙刘联盟"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是青龙刀，是"无论如何也不能是关羽邀请鲁肃、提议自己在路口等着吧——史实鲁肃设局 vs 剧版主客颠倒"；最讽刺的是"不是换大盏了吗，这也没换啊，就换了个大杯"。
- **时间边界**：215 年秋，长江。讨三郡 → 送三郡（一场内）。逍遥津留 P5_s15。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：东吴水师逼境，关羽单刀过江。

- **场景**：南郡·长江渡口。讨三郡、单刀过江、席间对峙。
- **锁定台词（必须逐字出现）**：关羽"荆州每寸土地都是我将士拼着性命从曹操手里夺来的，岂能拱手让人"；关羽"将在外君命有所不受。我哥好说话，我可不好说话"；关羽"昔日我在千枪万刃之中匹马纵横如入无人之境，今日又何惧江东群鼠，我只带周仓一人过江"；关羽"和子敬兄饮酒我当然不客气。来，换大盏"；周仓"天下土地有德者居之！绝非江东囊中物"；鲁肃"我不是救你，是救孙刘联盟"。
- **世界侧**：一艘小船摇过江面，船头绣"关"字红旗招展，关羽青巾绿袍坐船首，周仓执长刀立于身旁；东吴诸将沿江惊呼"关羽单刀赴会太不把我东吴将士放在眼里"。吕蒙领仪仗静候只吐一字"请！"将关羽引入大帐，帐中鲁肃脸色惨白病体又重了几分。
- **玩家视角（乐子人）**："无论如何也不能是关羽邀请鲁肃、提议自己在路口等着吧——史实鲁肃设局 vs 剧版主客颠倒。"
- **必然结果**：`flags_add: ["见证者_单刀赴会"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **议定讨荆州** → 诸葛瑾赴成都哭诉，刘备松口三郡（过渡铺垫）
2. **关羽拒交** → "荆州每寸土地岂能拱手让人"，"将在外君命有所不受"
3. **水师逼境** → 东吴震怒，又无故后撤二十里
4. **单刀过江** → 只带周仓，"来换大盏"（乐子人高潮）
5. **送三郡** → 鲁肃"我不是救你，是救孙刘联盟"，"派人来拿去吧"

## 五、骨架选项（自由行动方向，非剧情分支）

1. **混入随从队把"换大盏"巨盏塞给周仓，递杯+顺走三郡舆图残卷**（tension 25）→ 成就"换大盏递杯手"（participate）
2. **藏屏风后偷听鲁肃"刘强曹弱"战略，抄卖曹操细作**（tension 15）→ 成就"东吴底牌抄录者"（observe）
3. **把孙权两头押注的"诈骗计"密信塞进吕蒙衣袖**（tension 30）→ 成就"诈骗计搬运工"（influence）
4. **在东吴后撤20里的空水寨点三堆疑火，逼关羽拔刀掀桌**（tension 40）→ 成就"联盟破裂推手"（conflict）
5. **截胡刘备给关羽的军令，先卖东吴换五百金再慢半拍送达**（tension 20）→ 成就"军令截胡客"（trade）

## 六、文风落点（乐子人版）

- **世界侧**：正常演出——关羽正常赴会、鲁肃正常设局、孙权正常讨债

- **不出现**：逍遥津（P5_s15）、汉中之战（P5_s16）等后续
