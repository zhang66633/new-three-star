# P5_s4 华容道

> P5_s4（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第50回（关云长义释曹操）
> 字幕锚点：折棒 126-130 期（三笑三打脸 / 刘关张叩拜鲁肃）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P6）：**放 vs 义**。赤壁火起，曹操只剩二十七骑，三笑三打脸——笑周郎无谋招来赵云、再笑招来张飞、华容道大笑招来关羽。曹操打感情牌"云长你忘了昔日之情吗"，关羽念过五关之恩"散开一条路来"义释曹操。玩家是白嫖诸葛亮伏兵直播、亲手放曹操过华容道，还是冒充探马用"虚者实之"骗曹操走华容道？

**设计原则**：
- **名场面开场即现场**：玩家入场即在华容道，亲历"三笑三伏兵 → 义释 → 问斩闹剧"全链。这是 `见证者_华容道` 的触发点，非可选。
- **字幕锚定**：曹操"单笑周郎无谋诸葛愚蠢，此地山势险峻乃兵家生死之地"、赵云"赵子龙奉军师将令在此等候多时"、曹操"云长你难道忘了昔日之情吗"、关羽"我已斩颜良诛文丑报答过丞相"、曹操"过五关斩六将的事将军还记得"、关羽"散开一条路来"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是青龙刀，是"三笑三打脸堪称笑召唤术，笑一次中一次伏"；最讽刺的是"刘关张桃园三结义拜的其实是鲁肃"。
- **时间边界**：208 年冬，华容道。三笑三伏兵 → 义释（一场内）。南郡借荆州留 P5_s5。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：曹操二十七骑残兵走华容道。

- **场景**：赤壁·华容道。三笑三伏兵、义释曹操。
- **锁定台词（必须逐字出现）**：曹操"我不笑别人单笑周郎无谋诸葛愚蠢，此地山势险峻乃兵家生死之地，如果诸葛亮预先在这里伏下一支兵马我等插翅难飞"；赵云"赵子龙奉军师将令在此等候多时"；曹操"云长，你难道忘了我们的昔日之情吗"；关羽"我已斩颜良诛文丑报答过丞相了，今日不敢以私废公"；曹操"过五关斩六将的事将军还记得？你杀了我那么多守将我却传令放你过江"；关羽"散开一条路来"。
- **世界侧**：乌林之西荒草齐腰的谷地，一条窄道蜿蜒向西北。曹操二十七骑人困马乏，远处赤壁火光映红天际、浓烟遮住半片天空。华容道两侧山坡静寂无声，岔路口大道平坦、小道崎岖。
- **玩家视角（乐子人）**："演义是三笑变三哭，新三是三笑三打脸——笑声一落伏兵必现，堪称'笑召唤术'。"
- **必然结果**：`flags_add: ["见证者_华容道"]`（flags_on_enter 锚定）
