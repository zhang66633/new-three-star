# P3_s3 三英战吕布

> 场景开发协议五步流程 · P3_s3（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第5回（虎牢关三英战吕布）
> 字幕锚点：折棒 13 期（一人包围五十万 / 三姓家奴幼儿园）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P3）：**围观 vs 掺和**。吕布在虎牢关前叫阵，韩勇/刘三刀/王冲三合送头，吕布射断十八面将旗——玩家挤在城楼上看这场"一人包围五十万"的名场面，是跟着张飞喊"三姓家奴"起哄，还是打探、甚至不知死活想出城？

**设计原则**：
- **名场面开场即现场**：玩家入场就在虎牢关城楼，亲历刘三刀送头 → 吕布射旗 → 张飞骂"三姓家奴" → 刘关张车轮战吕布。这是 `见证者_三英战吕布` 的触发点，非可选。
- **字幕锚定**：刘三刀"三刀之内必斩吕布"、吕布"吕奉先送你们十八箭"、张飞"三姓家奴休狂，燕人张翼德在此！"、吕布"我堂堂吕布，为何成了三姓家奴？"、张飞科普三姓家奴、曹操"因为你战不过他"——锁定台词逐字出现。
- **乐子人基调**：名场面最响的不是战鼓，是张飞给吕布起的外号；最荒诞的是吕布被骂了还要问为什么（幼儿园水平）。
- **时间边界**：190 年夏，虎牢关前。吕布叫阵 → 三英车轮战 → 吕布金盔被劈败走（一场内）。董卓迁都/连环计留 P4（长安）。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：吕布在关前叫阵，第一波送头的（韩勇/刘三刀/王冲）已经三合落地。

- **场景**：虎牢关前·联军城楼。吕布一人一骑，策马挺戟；关前战鼓，诸侯齐聚。
- **锁定台词（必须逐字出现）**：
  - 刘三刀："我部悍将刘三刀，有万夫不当之勇。三刀之内，必斩吕布于马下。"
  - 吕布："关内诸侯们听着，你们不是有十八镇吗？今日，吕奉先送你们十八箭！"
  - 张飞："三姓家奴休狂，燕人张翼德在此！"
  - 吕布："我堂堂吕布，为何成了三姓家奴？"
  - 张飞："你小子姓吕不是？可你先拜丁原将军做义父。后来董卓用一匹赤兔马把你收买过去……如此算来，你小子不是三姓家奴是什么？"
  - 曹操："因为你战不过他。"（压住请战的曹仁）
- **世界侧**：诸侯正常应对——袁绍求计、曹操压曹仁、袁术黑脸；吕布正常叫阵射旗，城上军士挨个报旗号喝彩。世界照常运转。
- **玩家视角（乐子人）**："刘三刀三刀之内必斩吕布？三合，三颗人头——你刀还没出鞘呢。"
- **必然结果**：玩家成为名场面亲历者 → `flags_add: ["见证者_三英战吕布"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **三将送头** → 韩勇/刘三刀/王冲三合被斩（刘三刀"三刀之内必斩吕布"的梗）
2. **吕布射旗** → "吕奉先送你们十八箭"，十八面将旗挨个腰折（名场面）
3. **张飞骂阵** → "三姓家奴休狂"，吕布问"为何成了三姓家奴"（幼儿园科普）
4. **三英车轮战** → 刘关张齐上，吕布金盔被劈、败走（名场面高潮）

## 五、骨架选项（自由行动方向，非剧情分支）

1. **挤在城关上，看吕布射断十八面将旗**（tension 10）→ 亲历"吕奉先送十八箭"，看清吕布神射与诸侯怯战
2. **跟着张飞喊"三姓家奴"起哄**（tension 25）→ 成为城楼围观起哄者——这梗传千年有你一份
3. **趁乱打探吕布与西凉军虚实**（tension 30）→ 摸清吕布先锋人马与虎牢关守备（情报线）
4. **想出城掺和一脚**（tension 50）→ 连兵器都没摸到就被城卫拦下——"哪儿来的闲杂人等"（乐子人拒绝，不真送死）

## 六、文风落点（乐子人版）

- **世界侧**（NPC/环境）：正常演出，不调侃——诸侯正常怯战、吕布正常叫阵、军士正常喝彩
- **玩家视角**（内心/差异笔记）：折棒式吐槽——"刘三刀三刀之内必斩吕布？三合三颗人头"、"吕布一人包围五十万，这账咋算的"、"被骂了还要问为什么，幼儿园水平"
- **选项 effect**：微带梗味——"这梗传千年有你一份"
- **不出现**：董卓迁都、连环计/貂蝉（P4）、孙坚被击溃后的下落提前揭穿
