# P5_s2 长坂坡·携民渡路

> 场景开发协议五步流程 · P5_s2（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第41-42回（刘玄德携民渡江 / 赵子龙单骑救主）
> 字幕锚点：折棒 107-109 期（曹操告白赵子龙 / 阿斗脑浆晃匀）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P5）：**携民渡路 vs 铁骑追杀**。曹操五十万大军南下，蔡瑁献荆州，刘备携十八万百姓南撤——诸葛亮力劝"携民远行必致玉石俱焚"，刘备"百姓可以弃我而去，而我绝不抛弃百姓"。曹军铁骑衔尾追杀，赵云乱军中七进七出救阿斗，张飞当阳桥头"燕人张翼德在此"喝断桥。玩家是随赵云七进七出、当阳桥头吃瓜，还是把曹操再敲失忆一次？

**设计原则**：
- **名场面开场即现场**：玩家入场即在长坂坡，亲历"携民渡路 → 子龙七进七出 → 阿斗晃匀 → 张飞喝断桥"全链。这是 `见证者_长坂坡` 的触发点，非可选。
- **字幕锚定**：诸葛亮"携民远行是万万不可的"、刘备"百姓可以弃我而去"、糜芳"子龙他也降曹了"、刘备"子龙心如铁石绝对不可能"、刘备"为了一个孺子几乎坏我一员大将"、张飞"燕人张翼德在此尔等快来与我决一死战"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是长坂桥，是曹操一边嗑零食一边对赵云"我爱死他了"；最讽刺的是阿斗"脑浆子都给晃晕了"。
- **时间边界**：208 年秋，长坂坡。携民渡路 → 喝断桥（一场内）。赤壁之战留 P5_s3。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：十八万百姓扶老携幼南撤，曹军铁骑衔尾追杀。

- **场景**：南郡·长坂坡至当阳桥。携民渡路、七进七出、喝断桥。
- **锁定台词（必须逐字出现）**：诸葛亮"携民远行是万万不可的，此去江夏足有二百八十多里，十八万百姓每日能行不到三十里"；刘备"百姓可以弃我而去，而我绝不抛弃百姓"；糜芳"子龙……他也降曹了"；刘备"子龙与我患难相交，心如铁石，富贵岂能让他动摇？绝对不可能"；刘备"为了一个孺子，几乎坏我一员大将"；张飞"燕人张翼德在此，尔等快来与我决一死战！……战又不战，退又不退，想干什么？！"
- **世界侧**：新野至江夏官道上，十八万百姓绵延数十里：牛车、独轮车、肩挑背扛，队伍缓缓向江津渡挪动；糜夫人抱着阿斗坐在车驾中，赵云按剑护卫在侧；秋日旷野路边村庄十室九空。
- **玩家视角（乐子人）**："曹操打仗像喝茶看戏，一边嗑零食一边对赵云直白告白'我爱死他了'——这是用膝盖写出来的台词吗。"
- **必然结果**：`flags_add: ["见证者_长坂坡"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **蔡瑁献荆州** → 曹操五十万大军南下（过渡铺垫）
2. **携民渡路** → 诸葛亮力劝"玉石俱焚"，刘备"绝不抛弃百姓"
3. **子龙救主** → 七进七出，"夫人快上马"，阿斗脑浆晃匀（乐子人高潮）
4. **糜夫人跳井** → "子龙啊，你把阿斗带上，务必交给主公"
5. **喝断桥** → 张飞"燕人张翼德在此"，夏侯杰被狮吼功震吐血

## 五、骨架选项（自由行动方向，非剧情分支）

1. **乱军中随赵云七进七出冲阵，抱着阿斗并肩无双**（tension 40）→ 成就"七进七出的挂件"、称号"长坂坡无双见证人"（participate）
2. **当阳桥头吃瓜，张飞和小兵隔十里围观赵云七进七出"直播"**（tension 5）→ 成就"三国第一吃瓜群众"（observe）
3. **提醒"丞相你忘了赵云了吧"，或劝改"生擒"为"射杀"**（tension 30）→ 成就"把曹操再敲失忆一次"（influence）
4. **假扮奸细行刺刘备被赵云一声"站住"定住**（tension 25）→ 成就"最菜细作"（conflict）
5. **捡夏侯恩青钢剑，或抢在张飞断桥前谈"桥板拆迁费"**（tension 20）→ 成就"长坂坡第一捡漏王"（trade）

## 六、文风落点（乐子人版）

- **世界侧**：正常演出——刘备正常仁义、赵云正常救主、张飞正常断桥
- **玩家视角**：折棒式吐槽——"曹操告白赵子龙"、"阿斗脑浆晃匀"、"糜夫人跳井时机匪夷所思"、"狮吼功震吐血"
- **选项 effect**：微带梗味——"把曹操再敲失忆一次"
- **不出现**：赤壁之战（P5_s3）、华容道（P5_s4）等后续
