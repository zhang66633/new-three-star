# P5_s9 周瑜之死·既生瑜何生亮

> 场景开发协议五步流程 · P5_s9（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第56-57回（柴桑口卧龙吊丧 / 既生瑜何生亮）
> 字幕锚点：折棒 173 期（既生瑜何生亮 / 祭文发错小抄）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P7）：**既生瑜 vs 何生亮**。周瑜假途灭虢、借"西征取川"之名偷袭荆州——"传我将令，拿下荆州"话音未落，关张赵三路伏兵从平原"刷新"杀出，金疮迸裂撤回江东。小丘回望"见不到东吴战旗插上荆州城头"、临终传位"鲁子敬"、望天三问"既生瑜，何生亮！"。玩家是躲在屏风后看吕蒙空欢喜、随关张赵杀败东吴，还是倒卖那篇发错的祭文？

**设计原则**：
- **名场面开场即现场**：玩家入场即在柴桑都督府，亲历"假道灭虢翻车 → 小丘回望 → 临终托孤 → 既生瑜何生亮 → 灵堂"全链。这是 `见证者_周瑜之死` 的触发点，非可选。
- **字幕锚定**：周瑜"传我将令拿下荆州"、周瑜"这是我平生遭遇的第一次也是最后一次大败"、周瑜"鲁子敬可为江东柱石"、周瑜"既生瑜，何生亮！"、诸葛亮"公瑾呀老天为何如此绝情，赤壁一战全仗兄谋"、庞统"棺中此人器量狭小难成大事，是我庞统的连环计决定了胜负"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是灵堂，是"既生瑜何生亮气的其实是臆想出来的假想敌"；最讽刺的是"诸葛亮吊丧念的祭文正文整段是曹操遗书——天意发小抄时发错了"。
- **时间边界**：210 年冬，柴桑。假途灭虢 → 灵堂（一场内）。张松献图留 P5_s10。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：周瑜临终榻边，孙权问继任者。

- **场景**：南郡·柴桑都督府。假途灭虢、小丘回望、既生瑜何生亮、灵堂。
- **锁定台词（必须逐字出现）**：周瑜"传我将令，拿下荆州"；周瑜"这是我平生遭遇的第一次也是最后一次大败，只怕我见不到东吴战旗插上荆州城头了"；周瑜"有一个人比我识大体才胜于我德高于我可为江东柱石。……鲁子敬"；周瑜"既生瑜，何生亮！"；诸葛亮"公瑾呀老天为何如此绝情，你是天授奇才世无其匹，赤壁一战全仗兄谋"；庞统"棺中此人器量狭小难成大事，赤壁之战也不是他的功劳，是我庞统的连环计决定了胜负"。
- **世界侧**：荆州城外山丘上，周瑜在吕蒙搀扶下艰难下马远眺荆州城墙，身后三军跪倒泣不成声；柴桑都督府病榻弥留，孙权握着他的手问继任者，满室将官屏息，唯有角落里的吕蒙眼中燃着光。
- **玩家视角（乐子人）**："周瑜喊的'既生瑜何生亮'，气的不是真正的诸葛亮，而是天意扭曲下臆测出来的假想敌——然而其实根本不是那么回事儿。"
- **必然结果**：`flags_add: ["见证者_周瑜之死"]`（flags_on_enter 锚定）
