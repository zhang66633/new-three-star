# P4_s8 袁术败亡·蜜水还是血水

> 场景开发协议五步流程 · P4_s8（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第21回（袁公路败死 / 玉玺归刘备）
> 字幕锚点：折棒 65 期（献祭流召唤师曹操 / 亡灵天灾骷髅王）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P5）：**截击 vs 放行**。袁术称帝后众叛亲离、兵败寿春，携玉玺投奔袁绍；刘备主动请命截击，曹操假意拨五万兵却让朱灵路昭掌权、又派张辽许褚五百铁骑追回。破庙里袁术"渴死朕了"、侍从"只有血水"，玉玺落刘备手。玩家是端蜜水换玉玺、混进追兵队，还是抢先截杀骷髅王抢功？

**设计原则**：
- **名场面开场即现场**：玩家入场即在破庙外，亲历"截击 → 追兵 → 蜜水血水 → 玉玺易主"全链。这是 `见证者_袁术败亡` 的触发点，非可选。
- **字幕锚定**：张辽"将在外君命有所不受"、袁术"怎么还不取蜜水来"、侍从"现在哪里还有蜜水？只有血水"、刘备"多少英雄豪杰被这块石头害死了"、赵云"左将军刘备，有书呈袁公路将军"、曹操"丢了五万兵马，换来这块石头"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是玉玺，是"亡灵天灾骷髅王连口蜜水都喝不上"；最讽刺的是"献祭流召唤师曹操献祭两万士兵召唤火焰流星雨"。
- **时间边界**：199 年夏，破庙。截击 → 玉玺易主（一场内）。煮酒论英雄留 P4_s9。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：破庙里袁术攥着玉玺喊渴，庙外刘备军旗猎猎。

- **场景**：徐州·破落古庙。断粮断水、蜜水血水、玉玺易主。
- **锁定台词（必须逐字出现）**：
  - 张辽："将在外，君命有所不受。何况现在袁术兵马已动，军情如火！"
  - 袁术："我渴死了，怎么还不取蜜水来？"
  - 侍从："主公，外面全是刘备的军士，现在哪里还有蜜水？只有血水！"
  - 刘备："古往今来，多少英雄豪杰被这块石头害死了……"
  - 赵云："左将军刘备，有书呈袁公路将军！"
  - 曹操："丢了五万兵马，换来这块石头！我要它何用？"
- **世界侧**：旷野血流成河、尸横遍野，战场一角破落古庙被军士围得密不透风；庙内袁术浑身是血、呆坐土炕攥着玉玺，身边十几位残兵败将断粮断水；庙外刘备军旗猎猎，赵云从容入庙呈书。
- **玩家视角（乐子人）**："亡灵天灾的骷髅王，排面像在拍《魔兽》主线，结果本尊连口蜜水都喝不上。"
- **必然结果**：玩家成为名场面亲历者 → `flags_add: ["见证者_袁术败亡"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **袁术携玺投袁绍** → 称帝众叛亲离、兵败寿春（过渡铺垫）
2. **刘备截击** → 曹操假意拨五万兵却让朱灵路昭掌权，张辽许褚五百铁骑追回
3. **"将在外"劝退** → 刘备一句"君命有所不受"劝退追兵（乐子人高潮）
4. **蜜水血水** → 袁术"渴死朕了"，侍从"只有血水"，气绝
5. **玉玺易主** → 刘备"这块石头害死了多少英雄豪杰"，玉玺落刘备手

## 五、骨架选项（自由行动方向，非剧情分支）

1. **在庙外看亡灵天灾最后一幕，围观刘备派赵云送手书的忠厚人表演**（tension 5）→ 亲历"蜜水血水"（observe）
2. **混进张辽许褚五百铁骑追兵队，亲历"将在外君命有所不受"**（tension 25）→ 看刘备扣下曹操五万兵（participate）
3. **端一壶蜜水进庙，赌袁术临终拿什么换——玉玺祸水论下这可是世界修正道具**（tension 35）→ 敢不敢接盘看手气（trade）
4. **趁刘备夺玺空档横跳，赌自己能否抢先借用玉玺的洗脑功能**（tension 50）→ 与世界修正道具过招（influence）
5. **火焰流星雨后拦路截杀溃兵抢功，抢在刘备生擒之前收下人头**（tension 45）→ 成就"捡漏骷髅王"（conflict）

## 六、文风落点（乐子人版）

- **世界侧**（NPC/环境）：正常演出，不调侃——袁术正常渴死、刘备正常劝死、曹操正常嫌玺
- **玩家视角**（内心/差异笔记）：折棒式吐槽——"献祭流召唤师曹操，献祭两万士兵召唤火焰流星雨一波清屏"、"玉玺是心灵控制道具，刘备抢到手后洗脑曹操五万大军"、"忠厚人借机扣下曹操五万兵，演都不演了"
- **选项 effect**：微带梗味——"端一壶蜜水进庙，赌袁术临终拿什么换"
- **不出现**：煮酒论英雄（P4_s9）、官渡之战、三顾茅庐等后续
