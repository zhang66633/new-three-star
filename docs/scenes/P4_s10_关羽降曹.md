# P4_s10 关羽降曹·斩颜良诛文丑

> 场景开发协议五步流程 · P4_s10（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第25-27回（屯土山关公约三事 / 美髯公千里走单骑）
> 字幕锚点：折棒 66-77 期（曹关言情剧 / 过四关斩三将版）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P5）：**降 vs 忠**。曹操破徐州、下邳失守，关羽孤城出降——张辽"三罪三便"说降，关羽立三约"只降汉帝不降曹操"；白马坡斩颜良"插标卖首"、诛文丑，挂印封金过五关投刘备去。玩家是蹲武英阁看曹操关羽拍言情剧、给关羽当报点随从，还是帮夏侯惇数人头拆穿"无中生有的部将"？

**设计原则**：
- **名场面开场即现场**：玩家入场即在许都武英阁至官渡，亲历"三约归曹 → 斩颜良 → 诛文丑 → 过五关 → 辞曹"全链。这是 `见证者_关羽降曹` 的触发点，非可选。
- **字幕锚定**：关羽"只降汉帝不降曹操"三约、曹操"我得关云长胜过十万雄兵"、关羽"颜良正在插标卖首"、关羽"看我武艺如何"、关羽"一日间便可相会"、曹操"财富不能动其心"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是青龙偃月刀，是曹操一餐两次送鹿肉"拍言情剧"；最讽刺的是过五关斩六将打折成"过四关斩三将"。
- **时间边界**：200 年夏，许都至官渡。三约归曹 → 辞曹（一场内）。官渡之战留 P4_s11。

---

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：下邳已失，关羽三约归曹。

- **场景**：许都·武英阁至官渡。三约、斩将、过五关。
- **锁定台词（必须逐字出现）**：
  - 关羽："第一，我只降汉帝，不降曹操；第二，请曹丞相善待两位嫂嫂；第三，关某一旦得知刘备下落，无论他在天涯海角，我都会立刻投他而去。以上三约，缺了任何一条，我万万不降！"
  - 曹操："我得关云长，胜过十万雄兵！"
  - 关羽："在我眼里，颜良正在插标卖首！"
  - 关羽："张辽、徐晃请退，看我武艺如何！"
  - 关羽："赤兔马日行千里，末将有了它，一旦得知兄长下落，一日间便可相会了！"
  - 曹操："财富不能动其心，爵禄不能改其志，生死不能阻其行——别说我曹操，天奈其何？"
- **世界侧**：徐州既陷，曹操坐镇中原，武英阁金玉满堂、鹿肉美酒日日不绝；关羽挂印封金携嫂嫂车驾北行，沿途关隘森严、驿道车马络绎，守将听闻"汉寿亭侯借道"莫不敬畏；袁绍雄踞冀青幽并，厉兵秣马欲与曹操一决。
- **玩家视角（乐子人）**："曹操吃饭一半送鹿肉、关羽提刘备曹操当场头风发作'痛太痛了'——我在新三国里还能看见曹操和关羽拍言情剧。"
- **必然结果**：玩家成为名场面亲历者 → `flags_add: ["见证者_关羽降曹"]`（flags_on_enter 锚定）

## 六、文风落点（乐子人版）

- **世界侧**（NPC/环境）：正常演出，不调侃——曹操正常爱才、关羽正常忠义、袁绍正常备战
- **玩家视角**（内心/差异笔记）：折棒式吐槽——"曹关拍言情剧"、"抓稀有宝可梦"、"过四关斩三将，秦琪被世界意志斩杀"
- **选项 effect**：微带梗味——"报错了被骂'比夏侯惇还瞎'"
- **不出现**：官渡之战（P4_s11）、袁绍败亡（P4_s12）、赤壁等后续
