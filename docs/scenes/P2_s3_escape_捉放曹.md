## 一、场景设计总述

**核心矛盾**（剧情骨架 P2）：**目睹 vs 参与**。公堂段为目睹（虫系宝可梦大师陈宫审钦犯），夜牢段为参与点（陈宫放曹——玩家可选择 望风/远观/离开）。

**设计原则**：
- **关键节点开场即现场**：玩家一入场景就在中牟城门/公堂，目睹曹操化名"皇甫章"被审，认出昨夜官道之辩的义士（`知情者_曹操身份` 联动）。
- **锁定台词交付**：公堂 4 条（皇甫章/记仇数落/蛐蛐儿/押下去）为公开审案，玩家在围观人群合理可闻；夜牢 4 条（燕雀/鸿之志/父母妻子孩子/顾不得许多）在牢房半公开空间交付——借折棒re05原话"这个大牢实际上是个公开场合"：玩家跟进（世界对无名者无预案），陈宫摔罐清场、瞥见角落里的玩家、照旧行事（NPC 知情，非偷听）。
- **字幕锚定**：割须断袍、画像通缉令（"骁骑校尉曹操身高六尺"）在**中牟**（原著 312-315）——本场景正是 P2_s2 审查确认的归属地。
- **乐子人基调**：虫系宝可梦大师陈宫、仗着看过剧本的曹操、向蛐蛐告罪——折棒04核心梗全落位。

**时间边界**：白昼公堂 → 深夜夜审 → 破晓出城北上（次日清晨）。"新三国国道"、袁绍/成皋寨讨论、屠族留 **P2_s4**。

## 二、关键节点 · 陈宫放曹（必须亲历）

**开场即现场**（认出曹操），关键节点（放曹）在场景尾段待临。

- **公堂戏（白昼·目睹）**：
  - 曹操化名"皇甫章"，陈宫逗蛐蛐审案
  - 锁定台词（逐字出现）：曹操"在下是沛国客商，复姓皇甫，名章。" → 陈宫"两年前我到京师求官…京官不做也罢！" → 陈宫"和你论天下，我还不如听听我的蛐蛐儿叫呢。" → 陈宫"死到临头，竟还如此猖狂！来人，押下去，明日一早，押去京城！"
  - 玩家认出曹操（知情者_曹操身份）——"那夜我看着他喊国贼董卓，今天他跪在堂上装皇甫章"
- **夜牢戏（深夜·参与点）**：
  - 玩家跟进半公开的大牢（世界对无名者无预案），陈宫捧蛐蛐罐入牢
  - 夜审锁定台词：曹操"燕雀安知鸿之志！" → 陈宫"我这只燕雀，倒还真想知道一下鸿之志！" → 曹操"你的父母妻子孩子，他们该怎么办？" → 陈宫"事到如今，我也顾不得许多了。只当陈宫从来就没有这些。"
  - **陈宫摔罐清场**，瞥见角落里的玩家，与曹操对视一眼，照旧行事（乐子戏：闲人退避，独你未退）
- **必然结果**：玩家成为放曹见证者 → `flags_add: ["见证者_陈宫放曹"]`（flags_on_enter 锚定）
- **参与自由**：玩家选——望风搭手（参与）/ 远观（目睹）/ 不声张离开

## 三、开放情境（自由游走 + 可选互动）

### 可交互人物

| 人物 | 位置 | 互动点 |
|------|------|--------|
| 曹操（化名皇甫章）| 公堂 / 牢房 | 面瘫自信，被审仍硬气；夜牢中认出玩家"宫道口那看热闹的" |
| 陈宫 | 公堂 / 牢房 | 逗蛐蛐审案（虫系宝可梦大师），小本本记仇数落曹操 |
| 城卫/衙役 | 城门 / 县衙 | 盘查、呼喝（世界侧正常）|
| 围观众人 | 公堂外 | 议论"抓了钦犯""这县令审案还逗蛐蛐" |
| 狱卒 | 牢房 | 轮值，被陈宫摔罐清场调走 |
| 通缉令 | 城门告示栏 | 画像+文字（"骁骑校尉曹操身高六尺"），玩家读之（大师兄梗）|

### 可触发事件（玩家接触才发生）

1. **城门盘查 + 通缉令** → 玩家读告示，认出画像/名字（关键节点铺垫）
2. **公堂审案** → 玩家围观全程（皇甫章/记仇/蛐蛐儿/押下去）
3. **夜探大牢** → 玩家跟进，目睹夜审与放曹（关键节点）
4. **出城目送** → 次日破晓，二人一人一骑北上（"新三国国道"伏笔，留 P2_s4）

### 骨架选项（夜牢·参与点）

1. 凑上前去——替他们望风，搭把手（tension 30，major）→ 参与放曹；曹操认出你；你是放走钦犯的从犯
2. 远远看着——看这县令怎么放人（tension 10，minor）→ 目睹放曹（关键节点亲历）；"碎声一响闲人退避"，只有你没走
3. 不声张——记下这一夜，转身离开（tension 5，minor）→ 目睹放曹后默默退场（看破不说破）
