# P5_s11 刘备入川·此宴不是鸿门宴

> P5_s11（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第60-61回（张永年反难杨修 / 庞士元议取西蜀）
> 字幕锚点：折棒 194/198 期（反客为主 / 大声密谋）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P7）：**同宗接风 vs 刀斧手埋伏**。刘璋率三万川军迎出三百六十里为皇叔接风。刘备嘴上"季玉是我同宗，我岂能刀剑相报"，帐内庞统法正却早已备好一场刀光剑影——"于酒宴之侧埋伏一百甲士，席间主公掷杯为号"。魏延拔剑"舞剑为戏"、张任挺身对舞、两边部将纷纷拔剑加入群舞，直到刘备把酒樽重重一顿："此宴不是鸿门宴，魏延掷剑！"。玩家是偷听大声密谋、下场群舞递剑，还是偷走出卖张松的密信？

**设计原则**：
- **名场面开场即现场**：玩家入场即在涪城接风宴，亲历"三百六十里接风 → 大声密谋 → 群舞 → 掷杯立誓"全链。这是 `见证者_刘备入川` 的触发点，非可选。
- **字幕锚定**：刘璋"吾弟刘玄德果然是仁义之君"、刘备"益州距此三百六十里刘璋盛情可感"、庞统"于酒宴之侧埋伏一百甲士席间主公掷杯为号"、法正"趁机劫下以刘璋为质兵不血刃坐收西川"、刘备"此宴不是鸿门宴魏延掷剑"、刘备"人不负我我不负人，如果我对你家主公做出不义之事你们谁都可以杀我"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是刀光，是"刘备从荆州光速赶到、反客为主替刘璋接风——也不知道到底是谁在迎接谁"；最讽刺的是"刘备刚叮嘱明面上不要再讨论取益州，庞统法正当着面大声密谋"。
- **时间边界**：211 年冬，涪城。接风 → 立誓（一场内）。落凤坡留 P5_s12。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：刘璋三百六十里接风，帐内刀光剑影。

- **场景**：益州·涪城。接风宴、大声密谋、群舞、掷杯立誓。
- **锁定台词（必须逐字出现）**：刘璋"吾弟刘玄德果然是仁义之君，我着法正一请他就立刻带兵入川了"；刘备"益州距此三百六十里，刘璋盛情可感哪"；庞统"我意先下手为强，于酒宴之侧埋伏一百甲士，席间主公可掷杯为号"；法正"皇叔如果趁机劫下便能以刘璋为质令蜀军归降兵不血刃坐收西川"；刘备"此宴不是鸿门宴魏延掷剑！荆州来的将领有不弃剑者立斩"；刘备"我和季玉同宗骨血荣辱同舟，人不负我我不负人，如果我对你家主公做出不义之事你们谁都可以杀我"。
- **世界侧**：涪城乃川东门户重地，城门大开到处是益州荆州士兵。接风宴上刘璋举樽感慨玄德助拒张鲁，刘备先举樽敬天子再赞蜀中之酒甘美。席间魏延拔剑起舞剑锋逼近刘璋，张任或挑或挡"铮铮有声"，两边部将一齐拔剑"群舞以助一笑"。
- **玩家视角（乐子人）**："演义里本有两次宴会，新三国把两场并成一场，刘备反客为主替刘璋接风——也不知道到底是谁在迎接谁。"
- **必然结果**：`flags_add: ["见证者_刘备入川"]`（flags_on_enter 锚定）

## 六、文风落点（乐子人版）

- **世界侧**：正常演出——刘璋正常接风、庞统正常密谋、刘备正常立誓
- **玩家视角**：折棒式吐槽——"反客为主不知道谁迎接谁"、"大声密谋埋伏甲士"、"恩信未立只有真想娶西川才说"、"人不负我我不负人是甘露寺翻版"
- **选项 effect**：微带梗味——"拿到鸿门宴剧本提前"
- **不出现**：落凤坡（P5_s12）、益州易主（P5_s13）等后续
