# P4_s5 辕门射戟

> 场景开发协议五步流程 · P4_s5（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第16回（吕奉先射戟辕门）
> 字幕锚点：折棒 44 期（辕门射戟还能射偏？无敌了！）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P4）：**拆穿 vs 装瞎**。刘备守徐州三军令张飞醉酒失城，借住小沛；袁术派纪灵五万兵攻小沛，吕布居中设宴"杯酒释兵戈"——一百二十步一箭射戟上小枝，射中吊穗儿也算命中，满营集体失明。玩家是围观假天意、报离谱弓力吹牛，还是站出指着吊穗喊"射偏了"？

**设计原则**：
- **名场面开场即现场**：玩家入场即在五里坡酒宴，亲历"杯酒释兵戈 → 弓力比拼 → 射戟 → 退兵"全链。这是 `见证者_辕门射戟` 的触发点，非可选。
- **字幕锚定**：吕布"杯酒释兵戈"、吕布"开多少斤弓"、张飞"八百斤弓八十步"、吕布"此去辕门不下一百二十步"、吕布"替天行道"、纪灵"在下退兵"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是箭，是"射中吊穗儿"全靠世界意志硬掰；最讽刺的是"小沛是徐州的卫星，可环绕做圆周运动"。
- **时间边界**：196 年秋，小沛五里坡。设宴 → 退兵（一场内）。袁术称帝留 P4_s6。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：纪灵五万精兵围小沛，吕布请刘备赴五里坡酒宴。

- **场景**：小沛·五里坡酒宴。方天画戟插辕门下，宝雕弓在手。
- **锁定台词（必须逐字出现）**：
  - 吕布："我吕布虽然杀人无数，但我平生不好斗。今日我请二位来，就是想杯酒释兵戈！"
  - 吕布："敢问足下，你可以开多少斤弓？可射多少步？"
  - 张飞："俺可以开八百斤弓，八十步内，箭头穿甲而过！"
  - 吕布："此去辕门，不下一百二十步。如果我一箭射中戟上小枝，你二人则罢兵言和。如果我射不中，你们只管厮杀！是战是和，俱凭天意。"
  - 吕布："看见了吧，这是上天令你们罢兵言和啊。谁敢违抗天意，我吕布只好替天行道，再射一支金翎箭，将他穿胸而过！"
  - 纪灵："在下退兵！"
- **世界侧**：五里坡大营旌旗如林，兵士把方天画戟插在辕门之下；吕布把玩宝雕弓，貂蝉在侧低唱；小沛城内刘备与关羽赵云巡营，城外纪灵大军距城不足十里；徐州城里陈宫执印陪侍、盘算两头收粮的账目，兖州曹操厉兵秣马静待时机。
- **玩家视角（乐子人）**："辕门射戟射偏了也能算命中——特写镜头明明白白射中吊穗儿，满营集体失明。"
- **必然结果**：玩家成为名场面亲历者 → `flags_add: ["见证者_辕门射戟"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **张飞醉酒失城** → 三条军令挂梁上先喝通宵，曹豹投吕布夜开南门（过渡铺垫）
2. **刘备借住小沛** → "兄弟如手足，妻子如衣服"（关键节点）
3. **纪灵围城** → 袁术五万精兵攻小沛，刘备求援
4. **杯酒释兵戈** → 吕布设宴居中调解，问弓力比吹牛（乐子人高潮）
5. **一箭定徐州** → 一百二十步射中戟上小枝（吊穗），纪灵退兵

## 五、骨架选项（自由行动方向，非剧情分支）

1. **围观辕门射戟，看满营集体失明、无人戳穿"射中吊穗儿"**（tension 5）→ 亲历名场面（observe）
2. **吕布问弓力，报离谱数字吹牛撑排面**（tension 20）→ 被当场要求开弓则射偏社死（participate）
3. **站出指着吊穗喊"这箭射偏了"当面拆穿天意**（tension 45）→ 世界意志改剧本让你被当眼瞎（influence）
4. **吕布收了袁术二十万粮饷却两头答应，替两家算账敲一笔保密费**（tension 25）→ 拿账本换赏钱（trade）
5. **纪灵张飞宴上拔剑相向，趁乱帮一边开打缴走战马将旗**（tension 40）→ 搅局抢功（conflict）

## 六、文风落点（乐子人版）

- **世界侧**（NPC/环境）：正常演出，不调侃——吕布正常射戟、纪灵正常退兵、张飞正常吹牛
- **玩家视角**（内心/差异笔记）：折棒式吐槽——"500斤/800斤串台到隋唐演义了"、"小沛是徐州的卫星可环绕做圆周运动"、"情报系统对外不对内，陈宫蒙在鼓里"
- **选项 effect**：微带梗味——"被当场要求开弓则射偏社死"
- **不出现**：袁术称帝（P4_s6）、吕布之命（P4_s7）、白门楼等后续
