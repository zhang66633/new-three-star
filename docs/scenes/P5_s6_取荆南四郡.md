# P5_s6 取荆南四郡

> 场景开发协议五步流程 · P5_s6（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第52-53回（取零陵 / 赵子龙拒亲 / 关云长义释黄忠）
> 字幕锚点：折棒 147/151 期（邢道荣艳福不浅 / 孙乾一人出演两位五虎）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P5）：**仁义攻心 vs 投机小人**。马良献计南取武陵、长沙、桂阳、零陵四郡，大军首战零陵——城头开山大斧一吼"说出吾名，吓汝一跳！我乃是零陵上将军邢道荣！"，吼出了"艳福不浅"名场面。张飞瓮城七进、赵云拒樊氏"天下大定再娶妻"、黄忠拖刀计、魏延献长沙被诸葛亮判"食其禄而杀其主，不忠也"。玩家是随张飞冲瓮城、拆穿赵范仙人跳，还是帮魏延作证"脑后就差一根反骨"？

**设计原则**：
- **名场面开场即现场**：玩家入场即在荆南四郡，亲历"零陵上将 → 抓阄 → 樊氏拒婚 → 长沙黄忠魏延"全链。这是 `见证者_取荆南四郡` 的触发点，非可选。
- **字幕锚定**：邢道荣"说出吾名吓汝一跳，我乃是零陵上将军邢道荣"、刘备"将这厮拉出去砍了"、邢道荣"硬要把女儿嫁给末将，你艳福不浅呐"、诸葛亮"你抽着了不去说明子龙出战是天意"、赵云"为将者要行得正做得端，天下大定再娶妻"、诸葛亮"食其禄而杀其主不忠也，居其土而献其地不义也"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是开山斧，是邢道荣"艳福不浅"；最讽刺的是"黄忠一人出演两位五虎上将，黄忠临刑替身是孙权"。
- **时间边界**：209 年秋，荆南四郡。零陵 → 长沙（一场内）。甘露寺留 P5_s7。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：大军首战零陵，城头一声"艳福不浅"。

- **场景**：南郡·荆南四郡。零陵、桂阳、武陵、长沙。
- **锁定台词（必须逐字出现）**：邢道荣"说出吾名吓汝一跳，我乃是零陵上将军邢道荣"；刘备"你现在才想起和翼德叙旧了！左右，将这厮拉出去砍了"；邢道荣"硬要把女儿嫁给末将邢道荣，你艳福不浅呐"；诸葛亮"翼德可不能反悔哟，你抽着了不去说明子龙出战是天意"；赵云"为将者要行得正做得端，等天下大定我再娶妻吧"；诸葛亮"食其禄而杀其主不忠也，居其土而献其地不义也，这样的投机小人必须杀"。
- **世界侧**：四郡久离战乱府库充盈、百姓安居；太守刘度赵范金旋韩玄各自守印绶，手下既有邢道荣"无双上将"，也有黄忠年逾六旬百步穿杨。刘备以关羽守荆州，亲率张飞赵云诸葛亮分路南下。
- **玩家视角（乐子人）**："黄忠一人就出演两位五虎上将，我孙权天下无敌啊——黄忠临刑替身是孙权。"

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **零陵首战** → 邢道荣"艳福不浅"（过渡铺垫）
2. **抓阄出兵** → 诸葛亮"子龙出战是天意"
3. **赵云拒亲** → "天下大定再娶妻"，赵范仙人跳
4. **黄忠拖刀计** → 马失前蹄、射盔缨，被韩玄判通贼
5. **魏延献长沙** → "食其禄而杀其主不忠也"，诸葛亮要斩魏延

## 五、骨架选项（自由行动方向，非剧情分支）

1. **随张飞领兵夜袭零陵，冲进瓮城再顶着万箭杀出**（tension 30）→ 看破计策和没看破没区别（participate）
2. **赵范灌醉赵云仙人跳，点醒赵云或拆穿劝降局**（tension 25）→ 成就"新三国的酒是至高无上的存在"（influence）
3. **魏延手刃韩玄献降，替魏延作证"脑后就差一根反骨"**（tension 20）→ 成就"食其禄而杀其主不忠也"（trade）
4. **围观黄忠中拖刀计、被韩玄判通贼问斩**（tension 10）→ 看孙权替身黄忠（observe）
5. **韩玄斩黄忠魏延举义，帮韩玄守城还是随魏延献降**（tension 40）→ 成就"拖刀计·锁定技一绝"（conflict）

## 六、文风落点（乐子人版）

- **世界侧**：正常演出——四郡正常守城、刘备正常仁义攻心
- **玩家视角**：折棒式吐槽——"邢道荣艳福不浅"、"黄忠临刑替身是孙权"、"料事如神料了个寂寞"、"许昌豪宅劝赵云反水"
- **选项 effect**：微带梗味——"替魏延作证脑后就差一根反骨"
- **不出现**：甘露寺（P5_s7）、合肥大战（P5_s8）等后续
