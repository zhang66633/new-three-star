# P5_s3 赤壁之战

> P5_s3（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第43-50回（舌战群儒 / 草船借箭 / 火烧赤壁）
> 字幕锚点：折棒 112/120-122 期（舌战群儒复读课文 / 草船借箭没草人 / 双人Solo）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P6）：**以少胜多 vs 天意东风**。诸葛亮舌战群儒、草船借箭（草垛都没铺）、万事俱备只欠东风；黄盖苦肉计、于禁献铁索连船、借东风火烧赤壁——声势浩大的百万之战实为黄盖对线于禁的双人solo。玩家是围观"备课文式"舌战群儒、白嫖二十万支箭，还是搭黄盖火龙船冲进水寨？

**设计原则**：
- **名场面开场即现场**：玩家入场即在长江水寨，亲历"舌战群儒 → 草船借箭 → 连环计 → 借东风 → 火烧赤壁 → 横槊赋诗"全链。这是 `见证者_赤壁之战` 的触发点，非可选。
- **字幕锚定**：张昭"弃新野失樊城败当阳走夏口竟无一寸立身之地"、诸葛亮"鹏飞万里燕雀不识其志"、周瑜"孔明啊军中无戏言"、诸葛亮"三日之内交不出十万支箭甘受军法"、诸葛亮"欲破曹公须用火攻，万事俱备只欠东风"、曹操"对酒当歌人生几何"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是东风，是"草人？草垛我都没看见"；最讽刺的是舌战群儒"全员人机复读课文，张昭发言其余群儒像木桩钉在原地"。
- **时间边界**：208 年秋，赤壁。舌战群儒 → 火烧赤壁（一场内）。华容道留 P5_s4。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：曹军百万南下，诸葛亮出使东吴。

- **场景**：赤壁·长江水寨。舌战群儒、草船借箭、借东风。
- **锁定台词（必须逐字出现）**：张昭"半年不到弃新野失樊城败当阳走夏口，仓皇南北碌碌东西竟无一寸立身之地"；诸葛亮"鹏飞万里，燕雀不识其志。曹操收袁绍蚁聚之兵，劫刘表乌合之众，哪怕号称百万千万我也不惧"；周瑜"孔明啊，军中无戏言"；诸葛亮"我三日之后如不能交出十万支箭，甘受军法"；诸葛亮"欲破曹公须用火攻。万事俱备，只欠东风"；曹操"对酒当歌，人生几何。譬如朝露，去日苦多……山不厌高，水不厌深。周公吐哺，天下归心"。
- **世界侧**：长江北岸曹操水寨战船相连、桅杆如林；南岸夏口周瑜水师演练阵型，哨船穿梭；江心渔火点点却无渔船敢入，两岸商路断绝——大战前的紧张如常，只待东南风。
- **玩家视角（乐子人）**："草船借箭的精髓草人在哪里呢？你别说草人了，草垛我都没看见——就是单纯在船舱上铺了层茅草。"
- **必然结果**：`flags_add: ["见证者_赤壁之战"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **舌战群儒** → "备课文式"人机复读（过渡铺垫）
2. **草船借箭** → 20条快船趁大雾擂鼓收箭，白嫖二十万支（乐子人高潮）
3. **苦肉计** → 黄盖挨100军杖，伤口从后背"转移"到双腿锯断
4. **铁索连船** → 于禁献连环计，曹操把船全连起来
5. **借东风·火烧赤壁** → 七星坛绕圈，黄盖火龙船，曹操"大笑报警"

## 五、骨架选项（自由行动方向，非剧情分支）

1. **混进孙权府长廊围观"备课文式"舌战群儒，挂机装人机**（tension 5）→ 成就"观战不插嘴大师"（observe）

3. **黄盖挨军杖时学诸葛亮"飘然而过"或上前苦劝**（tension 15）→ 开口被鲁肃怀疑看破苦肉计（observe）
4. **于禁献铁索连船时附议把船全连起来或当场戳穿**（tension 35）→ 成就"铁索连船推手"（influence）
5. **混进七星坛120人白袍扛旗队伍，搭黄盖火龙船冲进水寨**（tension 45）→ 成就"火烧赤壁幸存观众"、称号"赤壁亲历者"（conflict）
