# P4_s3 三让徐州

> P4_s3（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第11-12回（陶恭祖三让徐州）
> 字幕锚点：折棒 29-31 期（恭喜主公，你爹殡天了 / 屠城经济学）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P4）：**屠城 vs 让城**。曹嵩借道徐州被张闿杀害，曹操借报父仇之名五万大军兵临城下、扬言"军民老幼斩尽杀绝"；陶谦披麻戴孝单骑谈判、病榻三让徐州；刘备借赵云驰援、"哭丧白捡一座城"。玩家是围观曹操的屠城经济学、替陶谦传信求援，还是抢在刘备前接这方大印？

**设计原则**：
- **名场面开场即现场**：玩家入场即在徐州城头/州府，亲历"屠城令 → 一让 → 推辞 → 三让 → 托印"全链。这是 `见证者_三让徐州` 的触发点，非可选。
- **字幕锚定**：曹操"军民老幼全部斩尽杀绝"、陶谦"五十万百姓托付给你"、刘备"我不是曹操，我是刘备"、陶谦"你比任何人都想得到徐州"、陶谦"请收下它吧"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是屠城，是曹操"我爹殡天了"的嘴角上扬；最讽刺的是"屠城经济学"——老百姓被算成战俘。
- **时间边界**：194 年秋，徐州。屠城令 → 三让托印（一场内）。曹操迎献帝留 P4_s4。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：曹操借报父仇之名五万大军兵临城下。

- **场景**：徐州·州府至城头。陶谦单骑谈判、病榻托印。
- **锁定台词（必须逐字出现）**：
  - 曹操："传令各部，破城之后，徐州城里的军民老幼，全部斩尽杀绝，以慰我父在天之灵！"
  - 曹操："我是要为父报仇，怒火满墙，我已经乱了方寸了！……所以我的五万大军全都是先锋！"
  - 陶谦："我就把徐州五十万百姓托付给你了，明日我即上奏朝廷，敕命你为徐州太守。"
  - 刘备："我不是曹操，我是刘备！此番前来，我是为了救徐州而不是图谋徐州，陶公万万不要陷我于不义！"
  - 陶谦："你还知道，你刘备不是不想得到徐州……你视名节重于性命，不愿意趁我之危罢了。"
  - 陶谦："请收下它吧，徐州太守除了托付于你之外，别无它人啊！我给朝廷的奏章已经写在遗书里了，我死后即发……"
- **世界侧**：徐州城门紧闭、城头白旗，陶谦披麻戴孝枯坐府中（袖口甩出一块现代手表）；兖州大营荀彧批阅文书、曹操秉烛看错误百出的牛皮地图；冀州袁绍把求援信搁在案角，南阳袁术讨价还价要割两郡。各州诸侯各忙各的，没有一家真为徐州动兵。
- **玩家视角（乐子人）**："曹操死个爹乐得嘴角压不住——老登好死，给我爆金币喽。"
- **必然结果**：玩家成为名场面亲历者 → `flags_add: ["见证者_三让徐州"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **曹嵩被杀** → 张闿见财起意，陶谦吐血病倒（世界侧祸根）
2. **曹操屠城令** → "军民老幼斩尽杀绝"，五万大军全是先锋（乐子人高潮）
3. **陶谦单骑谈判** → 披麻戴孝出城，数曹操笑了几回、露了几次表
4. **刘备驰援** → 借赵云单骑冲阵，曹操惊退暂缓攻城
5. **病榻三让** → "你比任何人都想得到徐州"，临终托印刘备哭丧白捡一座城

## 五、骨架选项（自由行动方向，非剧情分支）

1. **围观陶谦单骑出城"送死式谈判"**（tension 5）→ 亲历谈判名场面（observe）
2. **站曹操方执行屠城令，或守城方修城防逼曹操退兵**（tension 35）→ 决定徐州军民命运（conflict）
3. **替陶谦星夜传信撮合"每年二十万粮饷"求援生意**（tension 20）→ 赚战争财（trade）
4. **学刘备写前卑后亢书信退曹军**（tension 30）→ 措辞决定退兵还是屠城（influence）
5. **抢在刘备前接陶谦的印**（tension 40）→ 要么被"三气"，要么围观刘备白捡徐州（influence）

## 六、文风落点（乐子人版）

- **世界侧**（NPC/环境）：正常演出，不调侃——曹操正常报父仇、陶谦正常让城、刘备正常仁义
- **玩家视角**（内心/差异笔记）：折棒式吐槽——"屠城经济学：老百姓=战俘"、"承诺文学前后不超过一集"、"陶谦谈判顺带甩现代手表"
- **选项 effect**：微带梗味——"想接徐州？要么被'三气'，要么围观刘备哭丧白捡一座城"
- **不出现**：曹操迎献帝（P4_s4）、辕门射戟（P4_s5）、吕布夺徐州等后续
