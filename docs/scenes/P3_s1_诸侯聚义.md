# P3_s1 诸侯聚义

> 场景开发协议五步流程 · P3_s1（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第5回（发矫诏诸镇应曹公）
> 字幕锚点：折棒 08 期（会盟 + 华雄）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P3）：**站队 vs 中立**。玩家作为联军外围游侠，撞上十八镇诸侯会盟讨董——投靠哪一路（曹操/袁绍/刘备），还是先当个旁观者看这场"大半个天下"的聚会怎么开场。

**设计原则**：
- **会盟核心即现场**：玩家入场就在联军大营，亲历袁绍被推盟主、曹操献矫诏、刘关张被嘲——这是 `见证者_诸侯聚义` 的触发点，非可选。
- **字幕锚定**：袁绍"十八镇诸侯往这儿一坐，大半个天下就在咱们脚底下了"、曹操"此诏虽假，句句却是天意"、张飞"你们没瞧见我哥哥吗"、刘备"救国兴亡，忠义为先，岂在人多"——锁定台词逐字出现。
- **乐子人基调**：十八路诸侯凑一块儿论"大半个天下"，玩家眼里全是"这就要开分赃大会了"。
- **时间边界**：190 年春，会盟讨董初起（华雄叫阵在即，首战将至）。温酒斩华雄/三英战吕布留 P3_s2/P3_s3。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：玩家随难民涌进陈留，辕门插满各镇旗号，帅台上十八把交椅——袁绍正被孙坚推举当盟主。

- **场景**：陈留·诸侯联军大营。旌旗蔽日，各镇兵马安营扎寨。
- **锁定台词（必须逐字出现）**：
  - 袁绍："十八镇诸侯往这儿一坐，大半个天下就在咱们脚底下了！"
  - 袁绍："既然诸公有令，袁某只好奉命了。"
  - 曹操："此诏虽假，句句却是天意！曹某手中诏书虽然假，但它却比真的更真！"
  - 华雄（关外叫阵）："谁能将曹操狗贼的头颅给我踢上来，我将免你们不死！"
  - 张飞："你们没瞧见我哥哥吗？"
  - 刘备："救国兴亡，忠义为先，岂在人多？"
- **世界侧**：诸侯正常会盟、正常论兵，袁绍盘点"四十五万步军、九万骑兵"；各镇互相提防，暗流涌动。世界照常运转。
- **玩家视角（乐子人）**："十八路诸侯个个人模狗样，往帅台一坐就说大半个天下在脚底下了——感情天下就剩这十八家人。"
- **必然结果**：玩家成为会盟亲历者 → `flags_add: ["见证者_诸侯聚义"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **会盟仪式** → 玩家围观袁绍被推盟主，听各路诸侯互吹"探囊取物"
2. **曹操献矫诏** → 袁术当众揭穿"原来是矫诏"，曹操"比真的更真"辩解（关键节点，可亲历可旁观）
3. **刘关张被嘲** → 刘备报"织席贩履"出身，满堂哄笑；张飞炸雷（锁定台词）
4. **华雄叫阵** → 关外战鼓，首战将至——会盟的高潮由一场"免你们不死"的叫骂开场

## 五、骨架选项（自由行动方向，非剧情分支）

1. **混进营盘，打探各镇诸侯底细**（tension 10）→ 摸清十八路人马与矛盾，得会盟情报（信息线）
2. **挤进帅台前，围观会盟仪式**（tension 20）→ 亲历袁绍当盟主、曹操献矫诏、刘关张被嘲（主线）
3. **上前投靠曹操，报上名号**（tension 40）→ 入曹操幕府线，正式入盟（后续可随军出征）
4. **凑近刘、关、张三兄弟套近乎**（tension 30）→ 结识桃园兄弟——织席贩履的皇叔，看着能傍（刘备线）

## 六、文风落点（乐子人版）

- **世界侧**（NPC/环境）：正常演出，不调侃——诸侯正常会盟、袁绍正常当盟主、华雄正常叫阵
- **玩家视角**（内心/差异笔记）：折棒式吐槽——"大半个天下在脚底下了，感情天下就剩这十八家人"、"地图是不是长在台词上"（当阳 vs 陈留）
- **选项 effect**：微带梗味——"入曹操幕府线，看着像要干大事"
- **不出现**：三英战吕布（P3_s3）、温酒斩华雄细节（P3_s2）、董卓正面出场、十八路诸侯的分赃内幕提前揭穿
