# P4_s9 煮酒论英雄

> P4_s9（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第21回（曹操煮酒论英雄 / 关公赚城斩车胄）
> 字幕锚点：折棒 62 期（梅花煮酒论英雄 / 望梅止渴时光倒流）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P5）：**藏拙 vs 试探**。许田围猎关羽怒欲拔剑被刘备拦下，董承夜访出示指血衣带诏，刘备咬指签名、从此种菜抹土韬光养晦。曹操派许褚请刘备入梅园青梅煮酒（其实是梅花）——"天下英雄，只有你刘备和我曹操！"刘备闻雷失箸。玩家是陪刘备种菜藏拙、评"谁算当世英雄"，还是帮董承传衣带诏？

**设计原则**：
- **名场面开场即现场**：玩家入场即在许都梅园，亲历"衣带诏 → 种菜藏拙 → 煮酒论英雄 → 闻雷失箸"全链。这是 `见证者_煮酒论英雄` 的触发点，非可选。
- **字幕锚定**：曹操"看，前面有一片梅林！"、刘备"望梅止渴定能成为传世名典"、曹操"败军之将家中枯骨"、曹操"袁绍色厉胆薄绝非英雄"、曹操"天下英雄只有你刘备和我曹操"、刘备"迅雷乃是天意"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是"天下英雄"，是"这不梅花吗，青梅煮酒改名梅花煮酒"；最讽刺的是刘备"往脸上抹土——纯物理面如土色"。
- **时间边界**：199 年冬，许都梅园。衣带诏 → 闻雷失箸（一场内）。官渡之战留后续批次。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：曹操请刘备入梅园煮酒。

- **场景**：许都·梅园凉亭。梅花满园、惊雷骤至、闻雷失箸。
- **锁定台词（必须逐字出现）**：
  - 曹操："贤弟，看见那些梅子了吧。记得前年征战袁术时，烈日炎炎，将士们干渴难耐……我忽然心生一计，举鞭指着远处说道：看，前面有一片梅林！"
  - 刘备："丞相智谋超人，在下钦佩！望梅止渴一事，定能成为传世名典。"
  - 曹操："败军之将，家中枯骨了，他早晚要被我擒！"
  - 曹操："袁绍色厉胆薄，优柔寡断，做大事而惜身，见小利而忘命，绝非英雄！"
  - 曹操："天下英雄，只有你刘备和我曹操！"
  - 刘备："迅雷乃是天意，世上人谁敢不畏？"
- **世界侧**：许都梅园果实累累（观赏梅结不出梅子），凉亭酒席已备、下人往来布菜，曹操与刘备分宾主坐定举杯畅饮；园外浓云密布、凉风拂面。刘备的菜园里韭菜长得旺盛，头一刀韭菜刚收割；梅园门口刚抬出一具被"梦中杀人"斩了的侍从尸体。
- **玩家视角（乐子人）**："这不梅花吗，青梅煮酒改名梅花煮酒——满园开着花、结不出梅子的观赏梅，你跟我说梅子熟了？"
- **必然结果**：玩家成为名场面亲历者 → `flags_add: ["见证者_煮酒论英雄"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **许田围猎** → 曹操夺宝雕弓受"万岁"之呼，关羽欲拔剑被拦（过渡铺垫）
2. **衣带诏** → 董承出示指血诏书，刘备咬指签"左将军刘备"
3. **种菜藏拙** → 皇叔院中种菜、往脸上抹土（乐子人高潮）
4. **煮酒论英雄** → "天下英雄，只有你刘备和我曹操"，望梅止渴时光倒流
5. **闻雷失箸** → "迅雷乃是天意，世上人谁敢不畏"，刘备抹土圆场

## 五、骨架选项（自由行动方向，非剧情分支）

1. **混进梅园当小吏，听曹操念"今日梅子又熟了"**（tension 5）→ 成就"梅花煮酒鉴定师"（observe）
2. **陪刘备种菜藏拙，围观他往脸上抹土的行为艺术**（tension 20）→ 亲历韬光养晦（participate）
3. **曹操让你评"谁算当世英雄"——替刘备圆场或当场拆台**（tension 40）→ 评好了得另眼相看，评炸了一起被架出梅园（influence，成就"英雄评审员"）
4. **拎一筐结得出果的真青梅混进宴席，给刘备挽回颜面顺便向曹操收高价**（tension 20）→ 在梅花宴上卖真青梅（trade）
5. **帮董承布衣斗笠变装传递衣带诏，或向曹操告密**（tension 50）→ 但吉平撞柱、董承被诛是写死的结局（conflict，成就"皇叔同款血手印"）

## 六、文风落点（乐子人版）

- **世界侧**（NPC/环境）：正常演出，不调侃——曹操正常论英雄、刘备正常藏拙、园工正常种梅
- **玩家视角**（内心/差异笔记）：折棒式吐槽——"梅花煮酒，青梅没有梅花来凑"、"刘备往脸上抹土，纯物理面如土色"、"'前年征袁术'可征袁术是刚打完的事，永远找不到哪能时间跳跃"、"刘备照标准答案念'定可成为传世名典'"
- **选项 effect**：微带梗味——"评炸了跟刘备一起被架出梅园"
