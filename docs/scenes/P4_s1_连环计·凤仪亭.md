# P4_s1 连环计·凤仪亭

> P4_s1（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第8-9回（王司徒巧使连环计 / 董太师大闹凤仪亭）
> 字幕锚点：折棒 25 期（王司徒，我是你的破壁人 / 一夜进化成谋貂蝉）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P4）：**旁观 vs 掺和**。王允借貂蝉设连环计——先许嫁吕布、再献董卓，眉坞宴上董卓纳之；凤仪亭上貂蝉哭诉"已不洁"要跳湖明志，吕布撞见，董卓提画戟掷打，父子反目；王允激将"将军姓吕，老贼姓董"，正阳宫外吕布一戟穿胸。玩家是蹲街口听八卦、躲假山看掷戟，还是点破离间计、给一方通风报信？

**设计原则**：
- **名场面开场即现场**：玩家入场即在长安街市/王允府一带，亲历"献貂蝉 → 凤仪亭 → 掷戟反目 → 正阳宫伏诛"全链条。这是 `见证者_董卓伏诛` 的触发点，非可选。
- **字幕锚定**：王允"在下欲将此女献给尚父"、董卓"竟然调戏咱家的爱姬"、貂蝉"只愿死在将军面前"、吕布"今生不娶你为妻"、王允"掷戟之时他可曾念及父子之情"、吕布"奉旨杀贼"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是吕布的戟，是"咱家"的父子情当场崩塌；最讽刺的是董卓拉拢吕布"立你为太子"——吕布差点改名董布。
- **时间边界**：192 年春，长安。献貂蝉 → 董卓伏诛（一场内）。李傕郭汜乱长安留 P4_s2（192-06）。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：董卓在眉坞宴请百官，王允借献貂蝉设局，凤仪亭已埋下。

- **场景**：长安·王允府至正阳宫。眉坞宴、后花园凤仪亭、正阳宫门。
- **锁定台词（必须逐字出现）**：
  - 王允："在下欲将此女献给尚父，不知是否高攀了？"
  - 董卓："吕布，你太过无理，竟然调戏咱家的爱姬。来人，把吕布轰出去！"
  - 貂蝉："妾身已不洁，仍忍辱偷生……只愿死在将军面前，以明妾意！"
  - 吕布："今生不娶你为妻，不敢再以英雄自居。"
  - 王允："将军姓吕，老贼姓董，掷戟之时，他可曾念及父子之情？"
  - 吕布："奉旨杀贼！"
- **世界侧**：长安街市如常——吕布拎着米面粮油出入王允府接济，三公府门"公共厕所"想来就来；董卓眉坞宴百官、张温劝进被斩首立威；"董卓和吕布争貂蝉"的八卦传遍全城。世界照常运转。
- **玩家视角（乐子人）**："貂蝉前一夜还宁死不从，一夜过后180度大转弯——纯情小女生一夜进化成谋貂蝉。"
- **必然结果**：玩家成为名场面亲历者 → `flags_add: ["见证者_董卓伏诛"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **眉坞献貂蝉** → 董卓"真乃神仙中人"，"还选什么，就在今夜"（世界侧纳之）
2. **凤仪亭撞破** → 吕布貂蝉私会，董卓提画戟掷打，"竖子竟敢如此"（关键节点，可旁观可通风报信）
3. **貂蝉跳湖明志** → "只愿死在将军面前"，吕布"今生不娶你为妻"（离间推进）
4. **王允激将** → "将军姓吕，老贼姓董"，吕布立誓"不杀董贼，誓不为人"
5. **正阳宫诛卓** → 吕布"奉旨杀贼"一戟穿胸，王允宣诏"国贼董卓伏诛"（收尾）

## 五、骨架选项（自由行动方向，非剧情分支）

1. **蹲在长安街口看戏，听"董卓和吕布争貂蝉"的八卦传遍全城**（tension 5）→ 收集情报：连环计进度与满城风言（observe）
2. **凤仪亭下撞见吕布貂蝉私会，躲进假山吃瓜，等董卓提画戟来追**（tension 25）→ 亲历"董卓掷戟"名场面，可旁观或冒险通风报信（participate）
3. **上前点破王允"离间计"有诈**（tension 40）→ 天意修正：董卓哈哈一笑不当回事，反被灌三大盆血酒（influence）
4. **学吕布给貂蝉送"生日礼物"，借机混进王允府探连环计进度**（tension 20）→ 蹭三公家的饭，打探离间进度（trade）

## 六、文风落点（乐子人版）

- **世界侧**（NPC/环境）：正常演出，不调侃——王允正常献女、董卓正常好色、吕布正常恋爱脑
- **玩家视角**（内心/差异笔记）：折棒式吐槽——"咱家膝下无子你就是我的亲儿子，立你为太子，吕布改名董布吧"、"连环计带追更：上半部只告诉貂蝉'喜欢吕布就行'"
- **选项 effect**：微带梗味——"天意修正：董卓哈哈一笑不当回事，反被灌三大盆血酒"
- **不出现**：李傕郭汜乱长安（P4_s2）、三让徐州（P5）、董卓死后吕布貂蝉成婚等后续，留到后续场景
