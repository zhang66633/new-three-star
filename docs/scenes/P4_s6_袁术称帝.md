# P4_s6 袁术称帝·玉玺降智

> 场景开发协议五步流程 · P4_s6（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第17回（袁公路大起七军 / 玉玺登基）
> 字幕锚点：折棒 46-49 期（玉玺降智 / 骷髅王登基 / 割发代首）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P5）：**劝阻 vs 围观**。孙策以传国玉玺为质从袁术处换兵脱身，袁术得玺被降智蛊惑，三百五十五名文武联名逼宫，寿春金殿上骷髅王登基；许都这边曹操闻讯大笑"分而取之"。玩家是摸去寿春宫劝袁术别称帝（小心被降智光环带偏），还是围观曹操"乘天子座驾"割发代首？

**设计原则**：
- **名场面开场即现场**：玩家入场即在许都长乐宫（曹操定计视角），亲历"玉玺到手 → 355人逼宫 → 登基 → 曹操定计"全链。这是 `见证者_袁术称帝` 的触发点，非可选。
- **字幕锚定**：荀彧"没想到袁术抢先称帝"、曹操"二袁貌合神离，我可分而取之"、郭嘉"个个奉诏一个都不发兵"、群臣"三百五十五名联名上表"、袁术"上承天命继皇帝位"、袁术"你看我人已年过花甲"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是龙座，是"玉玺降智蛊惑，谁摸谁傻"；最讽刺的是袁术对着镜子说自己"年过花甲"（史实才四十出头）。
- **时间边界**：197 年春，许都（玩家视角）至寿春。玉玺到手 → 定计（一场内）。吕布之命留 P4_s7。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：寿春金殿上骷髅王登基，许都曹操闻讯大笑。

- **场景**：许都·长乐宫（曹操定计）至寿春伪朝金殿。
- **锁定台词（必须逐字出现）**：
  - 荀彧："主公原以为率先称帝的应该是袁绍，却没想到袁术抢先称帝了。"
  - 曹操："我早看出二袁皆有帝王之心，但没想到抢先称帝的却是袁术！袁绍定会大怒，这两兄弟貌合神离，我可分而取之！"
  - 郭嘉："不用估计，诸侯们肯定是个个奉诏，但一个都不会发兵！"
  - 群臣："臣等三百五十五名文武官员联名向主公上表，请主公顺天承命，即皇帝位，改元开国！"
  - 袁术："诸位爱卿，事已至此，我只好上承天命，继皇帝位。"
  - 袁术："你看我人已年过花甲，满面沧桑。"
- **世界侧**：寿春伪朝金殿夕阳下金碧辉煌，龙座上袁术双手捧玉玺颤抖，文武群臣一片惊慌，外有曹操二十万大军围城、南门告急；许都曹操祭天出师、乘天子座驾、执天子剑，随军主簿高喝"割下主公发髻以代其首"。
- **玩家视角（乐子人）**："玉玺就是个降智蛊惑道具，谁摸谁傻——袁术摸了连数都不会算，还对着镜子说自己年过花甲。"
- **必然结果**：玩家成为名场面亲历者 → `flags_add: ["见证者_袁术称帝"]`（flags_on_enter 锚定）

## 六、文风落点（乐子人版）

- **世界侧**（NPC/环境）：正常演出，不调侃——袁术正常称帝、曹操正常定计、群臣正常逼宫
- **玩家视角**（内心/差异笔记）：折棒式吐槽——"拿完玉玺一眨眼就变淮南了，世界意志一键搬家"、"大臣嘴里蹦出来的声线居然是关羽的"、"袁绍一周过去就沧桑20岁"
- **选项 effect**：微带梗味——"小心被降智光环带偏，当场被安排国师职位"
- **不出现**：吕布之命（P4_s7）、袁术败亡（P4_s8）、煮酒论英雄（P4_s9）等后续
