# P5_s13 益州易主

> P5_s13（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第65回（马超大战葭萌关 / 刘玄德自领益州牧）
> 字幕锚点：折棒 202 期（主公你喜欢马超吗 / 微马超拔河夜战）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P7）：**劝降马超 vs 刘璋开城**。马超领兵攻葭萌关，与张飞日战夜战——诸葛亮一句"主公，你喜欢马超吗？"点破杀机，早已派孙乾载数车金银贿赂杨松、挑拨张鲁猜忌马超，诸葛亮轻车入营劝降。马超归降后成都城下横枪，刘璋奉印绶出降——"从此以后，西川尽归于你了"。玩家是旁观拔河夜战、递"伏刀斧手"情报，还是假扮杨松家仆散流言？

**设计原则**：
- **名场面开场即现场**：玩家入场即在成都城下，亲历"马超攻葭萌关 → 诸葛亮劝降 → 马超归降 → 刘璋开城"全链。这是 `见证者_益州易主` 的触发点，非可选。
- **字幕锚定**：诸葛亮"马超与曹操有杀父之恨可堪大用，主公你喜欢马超吗"、刘备"这等猛将谁人不爱"、刘备"人言锦马超果然名不虚传"、诸葛亮"将军大祸不远矣，但恐新磨之剑不能试我头颅将军却将自试"、马超"我已归降刘皇叔今日奉命来取益州，阁下快快开城"、刘璋"这是益州的印绶册籍，从此以后西川尽归于你了"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是成都城门，是"劝降马超原著本由李恢出面，新三改成诸葛亮亲自入营当说客——派你去劝降这都是给你长面子"；最讽刺的是"刘璋开城前后先被敷衍非吾心所愿，转头被骂沉溺美酒佳人，回怼记恨天接着奏乐接着舞——人在极度无语的情况下真的会笑"。
- **时间边界**：214 年夏，成都。马超归降 → 刘璋开城（一场内）。单刀赴会留 P5_s14。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：马超攻葭萌关，诸葛亮点破杀机。

- **场景**：成都·城下至葭萌关。拔河夜战、入营劝降、开城易主。
- **锁定台词（必须逐字出现）**：诸葛亮"马超与曹操有杀父之恨可堪大用。主公，你喜欢马超吗"；刘备"这等猛将谁人不爱？包括他那西凉骑兵也是罕有其敌"；刘备"人言锦马超，果然名不虚传"；诸葛亮"将军大祸不远矣！但恐新磨之剑不能试我头颅，将军却将自试"；马超"我已归降刘皇叔，今日奉命来取益州。阁下快快开城以免生灵涂炭"；刘璋"这是益州的印绶册籍，从此以后西川尽归于你了，请仁兄善待蜀中百姓"。
- **世界侧**：成都城门外荆州军列阵以待，刘备策马注视缓缓打开的城门；刘璋目光呆滞领众官手捧印绶文籍出城，奉上印绶"请仁兄善待蜀中百姓"。刘备接过印绶转递诸葛亮，再紧紧握住刘璋的手仿佛他丢了江山般哽咽"季玉非我不义"。
- **玩家视角（乐子人）**："劝降马超在原著本由李恢出面，新三改成诸葛亮亲自入马超营当说客——派你去劝降，这都是给你长面子。"
- **必然结果**：`flags_add: ["见证者_益州易主"]`（flags_on_enter 锚定）

## 六、文风落点（乐子人版）
