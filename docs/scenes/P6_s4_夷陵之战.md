# P6_s4 夷陵之战

> 场景开发协议五步流程 · P6_s4（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第83回（战猇亭先主得仇人 / 守江口书生拜大将）· 第84回（陆逊营烧七百里 / 孔明巧布八阵图）
> 字幕锚点：折棒 243-248 期（赛博坦空间结界 / 三十万雄兵 / 700里连营700里火喷）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P6）：**七百里连营 vs 赛博坦结界**。关羽张飞相继被杀后刘备称帝，不顾诸葛亮赵云苦谏倾国东征——"步军三十万，马军十五万，水师二十五万，共计七十万大军"。张飞在阆中被范疆张达割首投吴。孙权拜陆逊为大都督，陆逊当众立誓"死战不退，打败刘备"，私下放话"两个月后，我自有三十万雄兵，从天而降"。刘备扎七百里连营于山林，酷暑疫病丛生；诸葛亮看马良画回的本图面色剧变、双手隐然颤抖。陆逊火烧连营四十座，刘备败退白帝城。玩家是在白盔白甲督造现场做手脚、混入火攻队，还是夜探"剧本发布会"？

**设计原则**：
- **名场面开场即现场**：玩家入场即在夷陵连营，亲历"称帝东征 → 张飞之死 → 拜帅立誓 → 七百里连营 → 看图剧变 → 火烧连营"全链。这是 `见证者_夷陵之战` 的触发点，非可选。
- **字幕锚定**：诸葛亮"岂有连营七百里而可拒敌的吗？一旦火起，七百里连营就是七百里火海！"、陆逊"两个月后，我自有三十万雄兵，从天而降！"、陆逊"它就是上天降下来的酷暑、疫病、瘴气！"、陆逊"追杀，追杀！直到擒下刘备方准止步！"、刘备"苍天啊，你为何现在才开眼？"、刘备"朕老了，没有机会了。而陆逊，他才三十岁呀…"——锁定台词逐字出现。
- **乐子人基调**：最响亮的是"陆逊施展连营是没有CD是吗？怎么感觉建营寨的速度比攻营寨的速度还快啊——五天撤50里、两个月撤600里"；最讽刺的是"我还以为这30万天兵天将指的是夷陵之火呢，原来指的是酷暑、疫病和瘴气"。
- **时间边界**：222 年夏，夷陵。称帝东征 → 火烧连营（一场内）。白帝托孤留 P6_s5。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：刘备七百里连营扎于山林，陆逊火烧连营四十座。

- **场景**：南郡·夷陵连营。称帝东征、张飞之死、拜帅立誓、七百里连营、看图剧变、火烧连营。
- **锁定台词（必须逐字出现）**：诸葛亮"岂有连营七百里而可拒敌的吗？一旦火起，七百里连营就是七百里火海！"；陆逊"两个月后，我自有三十万雄兵，从天而降！"；陆逊"这三十万大军近在眼前——它就是上天降下来的酷暑、疫病、瘴气！"；陆逊"追杀，追杀！直到擒下刘备方准止步！"；刘备"苍天啊，你为何现在才开眼？这雨如果早来一日，我岂有如此大败！"；刘备"朕老了，没有机会了。而陆逊，他才三十岁呀…"。
- **世界侧**：东吴江边将坛高筑，"吴"字王旗冲天，孙权登坛拜帅授剑印虎符；陆逊升帐议事、以王剑滴血立誓，诸将同饮血酒。蜀军连营数百里灯火通明，士兵连夜磨砺兵器、试刀试枪；刘备巡营而过，看军容鼎盛满意折回龙帐。成都丞相府烛火昏黄，诸葛亮抚琴低鸣，马谡执公文来报前线捷讯。两军在山林间对峙数月，酷暑之下疫病流行、军士取污水为食——世界按各自的"正常军务"运转，只有看懂剧本的两个人知道，这正常运转本身就是倒计时。
- **玩家视角（乐子人）**："陆逊施展连营是没有CD是吗？怎么感觉建营寨的速度比攻营寨的速度还快啊——五天撤50里、两个月撤600里。"
- **必然结果**：`flags_add: ["见证者_夷陵之战"]`（flags_on_enter 锚定）

## 五、骨架选项（自由行动方向，非剧情分支）

1. **在张飞"命范疆张达打造白盔白甲"督造现场做手脚，把"200鞭一鞭不能少"暗中改回原著"各鞭50"，救两人性命换投名状**（tension 35）→ 成就"白盔白甲搅局者"（influence）
2. **混进陆逊"便携式基地车"运输队偷运粮草营寨图纸，把"两个月撤600里"空间结界布防情报倒卖给刘备军**（tension 30）→ 成就"连营图纸贩"（trade）
3. **夜探陆逊营帐偷听"剧本发布会"，记下天意"30万雄兵从天而降"的战机节点**（tension 15）→ 成就"30万雄兵情报员"（observe）
4. **混入吴军火攻队亲手浇硫磺火油烧刘备扎在林间的四十座连营——"700里连营就是700里的火喷"**（tension 40）→ 成就"火烧连营亲历者"（participate）
5. **在白帝城生死局截住诸葛瑾"杀人诛心"计划——把"你是来羞辱我的吗"原话抄给病危刘备，或把陆逊"大败70万蜀军"战报提前塞给诸葛亮，替谁传话谁先结算**（tension 45）→ 成就"借刀杀人截胡"（conflict）
