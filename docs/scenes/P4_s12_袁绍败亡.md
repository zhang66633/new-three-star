# P4_s12 袁绍败亡

> P4_s12（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第30-31回（袁绍吐血 / 曹操收冀州）
> 字幕锚点：折棒 70-72 期（僵尸袁绍 / 许攸作死三连）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P5）：**霸主易位 vs 功臣作死**。官渡大败后袁绍"所剩不足百骑"退回冀州，神智被天意侵蚀日渐浑噩，"苍天助曹不助袁"吐血暴亡；许攸自恃功高当街喊"曹阿瞒"抖黑历史，作死三连把自己脖子伸到许褚刀下。玩家是围观僵尸袁绍、推波助澜让许攸死得更快，还是拦一拦这位功臣？

**设计原则**：
- **名场面开场即现场**：玩家入场即在冀州邺城，亲历"兵败自责 → 吐血暴亡 → 许攸作死 → 曹操烧信"全链。这是 `见证者_袁绍败亡` 的触发点，非可选。
- **字幕锚定**：袁绍"皆因我迟疑"、袁绍"我和你不共戴天"、袁绍"苍天助曹不助袁"、许攸"曹阿瞒"、曹操"此战非我一人之功"、旁白"吐血暴亡"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是英雄迟暮，是"僵尸袁绍，骷髅王的兄弟"；最讽刺的是袁绍死亡时间线"200 年和 206 年各死一次"。
- **时间边界**：200 年秋，冀州邺城。兵败 → 暴亡（一场内）。刘备投荆州留 P4_s13。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：官渡大败，袁绍退回冀州。

- **场景**：冀州·邺城。兵败自责、许攸作死、曹操收冀州。
- **锁定台词（必须逐字出现）**：
  - 袁绍："此事皆因我迟疑，而与列位断然无关。是我过失，是我糊涂啊……此战错在于我，连累三军呐！"
  - 袁绍："曹操，我和你不共戴天！"
  - 袁绍："苍天助曹不助袁！"
  - 许攸："曹阿瞒！"
  - 曹操："此战非我一人之功。"
  - 旁白："袁绍于悲愤中吐血暴亡。至此，曹操取代袁绍成为大汉天地间最强盛的霸主。"
- **世界侧**：冀州衙署照常运转，账册刑狱、军民杂务有条不紊；曹操班师入冀，封赏降臣、烧信安民，仿若一切胜利皆是按部就班的必然；许攸自恃功高，满城招摇，仿佛自己真是再造之功的座上宾。
- **玩家视角（乐子人）**："现在站在你面前的已经不是活人袁绍了，而是僵尸袁绍，骷髅王的兄弟——官方台词'死而不僵'，残兵二三十万雄踞四州。"
- **必然结果**：玩家成为名场面亲历者 → `flags_add: ["见证者_袁绍败亡"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **兵败自责** → "皆因我迟疑……连累三军"（过渡铺垫）
2. **天意顶号** → 袁绍想起田丰要重用又听谗立斩，"传令取乌巢不攻"
3. **许攸作死三连** → 当街"曹阿瞒"、抖黑历史、自己伸脖子到许褚刀下（乐子人高潮）
4. **曹操烧信** → "此战非我一人之功"，一把火烧了袁绍私通书信
5. **吐血暴亡** → "苍天助曹不助袁"，曹操取代袁绍成最强霸主
