# P5_s8 合肥大战

> P5_s8（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第53回（孙仲谋大战张文远）
> 字幕锚点：折棒 144/152 期（诈败把太史慈演死 / 坟前变脸）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P7）：**诈败演大戏 vs 假戏成真**。孙刘联姻刚落幕，孙权却号令不动手握重兵的周瑜。鲁肃酒席献计"提兵佯攻合肥、诈败几阵、即令公瑾驰援"——说白了用一场败仗把周瑜从荆州骗回来。孙权兴冲冲北上跟张辽演大戏，演着演着连中埋伏，四千余将士阵亡、太史慈身死名灭——假戏成了真。玩家是加入诈败团当群众演员、保住太史慈，还是蹲坟前看孙权变脸？

**设计原则**：
- **名场面开场即现场**：玩家入场即在合肥城下，亲历"献计诈败 → 周瑜拒赴 → 合肥败 → 坟前变脸"全链。这是 `见证者_合肥大战` 的触发点，非可选。
- **字幕锚定**：鲁肃"主公何不提兵佯攻合肥然后再诈败几阵即令公瑾驰援"、周瑜"张辽没有水师他的兵马再强对我江东也无多大威胁"、孙权"此次合肥大战我连败于张辽耻我耻，四千多将士阵亡还折了太史慈将军"、孙权"反思赤壁之战周瑜仅用五万精兵烧掉曹操八十三万大军，而我身为人主何颜自立"、鲁肃"现在不仅在主公面前有一座坟，江北也新添了一座孤坟"、张辽"孙权在合肥屡败于我"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是合肥城，是"你这个诈败，诈着诈着就把太史慈给炸死了"；最讽刺的是"太史慈终于出场了，以墓碑的形式出场"。
- **时间边界**：209 年冬，合肥。献计 → 坟前变脸（一场内）。周瑜之死留 P5_s9。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：孙权佯攻合肥，跟张辽演大戏。

- **场景**：合肥·城下。诈败、连中埋伏、坟前变脸。
- **锁定台词（必须逐字出现）**：鲁肃"主公何不提兵佯攻合肥然后再诈败几阵即令公瑾驰援"；周瑜"张辽没有水师他的兵马再强对我江东也无多大威胁，倒是荆襄之地若不夺回来终使我江东祸患"；孙权"此次合肥大战我连败于张辽耻我耻，四千多将士阵亡还折了太史慈将军"；孙权"反思赤壁之战周瑜仅用五万精兵烧掉曹操八十三万大军势惊天下气吞山河，而我身为人主何颜自立"；鲁肃"现在不仅在主公面前有一座坟，此时此刻在江北也新添了一座孤坟"；张辽"孙权在合肥屡败于我"。
- **世界侧**：合肥城下，张辽镇守曹操北方门户没有水师、以守为要；孙权打着"立威"旗号佯攻诈败，本意骗周瑜回师夺回兵权。大战未起戏先开演——这本该是场全身而退的假败，偏偏连中埋伏，假戏成了真。
- **玩家视角（乐子人）**："你这个诈败，诈着诈着就把太史慈给炸死了是吧？你这去当演员把太史慈演死了。"
- **必然结果**：`flags_add: ["见证者_合肥大战"]`（flags_on_enter 锚定）
