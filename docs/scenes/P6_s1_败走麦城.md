# P6_s1 败走麦城

> 场景开发协议五步流程 · P6_s1（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第76回（徐公明大战沔水 / 关云长败走麦城）
> 字幕锚点：折棒 216/217/220/221 期（他过江我也过江 / 两栖蜘蛛侠 / 自刎归天 / 我二弟天下无敌）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P6）：**白衣渡江 vs 一夫当关**。关羽北伐襄樊后荆州空虚，东吴水师白衣渡江扮作客商，三更时杀尽烽火台守卒奇袭荆州，南郡、公安相继易手。关羽撤樊城之围回救，败走麦城——刘封、孟达拒不发兵，三里小郭只剩几百残兵。吕蒙料定关羽必走麦城小路突围，火光中策马立于半箭开外。赤兔马拒饮河水长嘶示警，关羽抚髯提剑一夫当关，零人头自刎，吕蒙补刀斩首。玩家是混进突围夜护青龙刀、假扮信使诱临沮，还是截孙权送曹操的"关羽首级寿礼"？

**设计原则**：
- **名场面开场即现场**：玩家入场即在麦城突围夜，亲历"白衣渡江 → 麦城被围 → 赤兔拒水 → 一夫当关 → 自刎斩首 → 孙权送首级"全链。这是 `见证者_败走麦城` 的触发点，非可选。
- **字幕锚定**：关羽"他过江我也过江！他过江攻荆州，我过江直杀到吴都建业"、关羽"我关羽一世英雄，竟坏于奸小之手"、关羽"如果我想逃生，昨日就可以去上庸了。听令，接战！"、吕蒙"关将军，我在此恭候多时了！"、孙权"现在，才能真正做一回主公了！"——锁定台词逐字出现。
- **乐子人基调**：最响亮的是"零人头自刎——一代武圣这么挂机下线，最后一战连人头都没给观众看到"；最讽刺的是"孙权嘴上派陆逊传令'不可杀关羽'，转头就送首级给曹操当寿礼，还毒死了抗命追杀的吕蒙——这口径对不上啊"。
- **时间边界**：220 年正月，麦城。白衣渡江 → 斩首送寿礼（一场内）。曹操之死留 P6_s2。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：吕蒙料定关羽必走麦城小路突围，火光中策马而立。

- **场景**：麦城·麦城至临沮小路。白衣渡江、麦城被围、赤兔拒水、一夫当关、自刎斩首、送首级。
- **锁定台词（必须逐字出现）**：关羽"他过江我也过江！他过江攻荆州，我过江直杀到吴都建业，连孙权也一块擒下！"；关羽"这个吴下阿蒙，居然背后捅我一刀！"；关羽"我关羽一世英雄，竟坏于奸小之手。兄长把荆州托付给我，我有何面目见兄长呀"；关羽"如果我想逃生，昨日就可以去上庸了。听令，接战！"；吕蒙"关将军，我在此恭候多时了！"；孙权"孤即位十多年了，一直受各种各样的大都督制约。现在，才能真正做一回主公了！"。
- **世界侧**：东吴白衣渡江一夜之间烽火台尽熄、全城换旗。麦城被围，城中残兵拆屋为柴、宰马充饥；关平周仓死战不退。吕蒙分兵两路追杀，自己南追、贾华打着他将旗西追。关羽退至河边树下，赤兔马拒水长嘶，四周火把渐近——世界按军务正常运转，只是这一夜注定要结算关云长的一生。
- **玩家视角（乐子人）**："零人头自刎：数十支长矛齐刺，关羽横剑自刎，吕蒙补刀斩首——一代武圣这么挂机下线，最后一战连人头都没给观众看到。"
- **必然结果**：`flags_add: ["见证者_败走麦城"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **白衣渡江** → 扮客商三更杀尽烽火台，全城换旗（过渡铺垫）
2. **麦城被围** → 刘封孟达拒发兵，拆屋宰马充饥
3. **赤兔拒水** → 千里驹拒饮河水长嘶，比人先知道今晚要出事（乐子人高潮）
4. **一夫当关** → "如果我想逃生昨日就去上庸了。听令，接战！"
5. **自刎斩首** → 数十支长矛齐刺，横剑自刎，吕蒙补刀
6. **送首级** → 孙权送曹操当六五寿礼，毒杀吕蒙"真正做一回主公"

## 五、骨架选项（自由行动方向，非剧情分支）

1. **混进麦城突围夜，护着周仓抢回青龙偃月刀，火中抬关羽尸身冲出重围**（tension 40）→ 成就"麦城突围亲历者"、称号"武圣送葬人"（participate）
2. **白衣渡江后混在吴军船队里围观烽火台一夜易手，抄走吕蒙水陆两栖作战部署**（tension 10）→ 成就"水陆两栖蜘蛛侠"（observe）
3. **假扮信使潜入麦城递假情报"刘封孟达已发兵"，诱关羽往临沮小路突围，换吕蒙赏钱**（tension 30）→ 成就"临沮引路人"（influence）
4. **关羽退至河边时抢先设伏拦下，夺赤兔马或青龙刀，搏一把武圣遗产**（tension 45）→ 成就"武圣遗产猎人"（conflict）
5. **孙权送曹操的"关羽首级寿礼"出发前截胡，掉包木匣或中途倒卖"敌酋首级贺礼"奇货**（tension 25）→ 成就"寿礼截胡王"（trade）

## 六、文风落点（乐子人版）

- **世界侧**：正常演出——关羽正常吹牛、吕蒙正常埋伏、孙权正常送人头
- **玩家视角**：折棒式吐槽——"他过江我也过江"、"水陆两栖蜘蛛侠"、"零人头自刎挂机下线"、"自刎便是懦夫自刎归天"、"不可能我二弟天下无敌"
- **选项 effect**：微带梗味——"寿礼截胡""武圣遗产猎人"
- **不出现**：曹操之死（P6_s2）、曹丕篡汉（P6_s3）、夷陵之战（P6_s4）、白帝托孤（P6_s5）等后续
