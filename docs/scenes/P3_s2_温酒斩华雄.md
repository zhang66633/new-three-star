# P3_s2 温酒斩华雄

> P3_s2（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第5回（温酒斩华雄）
> 字幕锚点：折棒 08 期（华雄人马兽 / 关羽拒绝酒驾）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P3）：**围观 vs 参与**。华雄在汜水关前叫阵，俞涉五合被斩、潘凤三合被斩（百斤开山斧飞得比人都快），满营诸侯无人敢战——玩家是挤到前排看这场"马弓手扬名"，还是起哄、打探、甚至不知死活地抢功？

**设计原则**：
- **名场面开场即现场**：玩家入场就在联军大营，亲历俞涉/潘凤送头 → 关羽请战 → 温酒斩华雄。这是 `见证者_温酒斩华雄` 的触发点，非可选。
- **字幕锚定**：袁术"叉出去！"、曹操"此人卧眉龙眼，满面英雄气"、袁绍"颜良文丑没到"、关羽"无需借酒壮行"、曹操"温酒斩华雄，真英雄也"、袁绍"增设第十九镇"——锁定台词逐字出现。
- **乐子人基调**：名场面最响亮的不是关羽的刀，是潘凤飞出去的斧头；最讽刺的是"温酒"——关羽根本没喝酒（拒绝酒驾）。
- **时间边界**：190 年春，汜水关前。华雄叫阵 → 斩华雄（一场内）。三英战吕布留 P3_s3（虎牢关）。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：华雄在关前叫阵，第一颗人头（俞涉）已经落地。

- **场景**：汜水关前·联军大营。关外战鼓，各路诸侯齐聚帅台。
- **锁定台词（必须逐字出现）**：
  - 袁术："你一个小小的弓手，岂敢口出狂言！以为我等诸侯没有大将吗？叉出去！"
  - 曹操："此人卧眉龙眼，满面英雄气，华雄又怎么会知道他是一个弓手呢？"
  - 袁绍："只可惜我的上将颜良、文丑没到。如有一人在此，岂容华雄如斯嚣张！"
  - 关羽："不必。关某战一个小小的华雄，无需借酒壮行。诸公稍候，关某去去便来！"
  - 曹操："温酒斩华雄，真英雄也！"
  - 袁绍："听令：增设第十九镇讨贼兵马，统兵将军为刘备！"
- **世界侧**：诸侯正常应对——袁术看不上弓手、曹操力劝、袁绍叹将；关外战鼓一起一停，一颗人头落地。世界照常运转。
- **玩家视角（乐子人）**："俞涉五合、潘凤三合——报信的每回都是'斩于马下'，你听着都耳熟。"
- **必然结果**：玩家成为名场面亲历者 → `flags_add: ["见证者_温酒斩华雄"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **俞涉请战送头** → 五合被斩（世界侧首战）
2. **潘凤请战送头** → 三合被斩，百斤开山斧飞出去（乐子人高潮）
3. **关羽请战** → 袁术"叉出去"、曹操力劝、刘备担保（关键节点，可亲历可旁观）
4. **温酒斩华雄** → 关羽拒绝酒驾，一刀斩华雄，满营震动
5. **增设第十九镇** → 袁绍颁令刘备领兵（会盟的收尾）

## 六、文风落点（乐子人版）

- **世界侧**（NPC/环境）：正常演出，不调侃——诸侯正常怕死、正常推脱、正常惊叹
- **玩家视角**（内心/差异笔记）：折棒式吐槽——"报信的每回都是'斩于马下'"、"华雄半人马一刀就完事"、"关羽拒绝酒驾"
- **选项 effect**：微带梗味——"抢功？'哪儿来的闲杂人等'"
- **不出现**：三英战吕布（P3_s3）、董卓正面出场、关羽之歌在斩将时抢戏（世界侧正常）
