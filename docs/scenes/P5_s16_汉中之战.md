# P5_s16 汉中之战·鸡肋还是鸡翅尖

> 场景开发协议五步流程 · P5_s16（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第71-72回（黄忠定军山斩夏侯渊 / 杨修之死）
> 字幕锚点：折棒 211-213 期（鸡肋鸡翅尖 / 弃将喂哀兵）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P5）：**弃将喂哀兵 vs 鸡肋班师**。曹操弃夏侯渊喂哀兵——"既然定军山败势已定，那就让它败得更有价值些"，明派徐晃许褚相援、暗里让宗亲送死。黄忠百万大军平推定军山、阵斩夏侯渊。曹操举箸夹鸡肋随口定口令"鸡肋"，杨修解读"食之无味弃之可惜，主公定会班师"，曹操大怒斩杨修。赵云奇袭中军，曹操头风发作昏迷。玩家是混进求援信使队、煽动鸡肋军心，还是随赵云奇袭中军？

**设计原则**：
- **名场面开场即现场**：玩家入场即在定军山，亲历"求援 → 弃将 → 斩妙才 → 鸡肋 → 赵云奇袭"全链。这是 `见证者_汉中之战` 的触发点，非可选。
- **字幕锚定**：曹操"夏侯渊英勇不愧为吾弟，我这就派徐晃许褚率三万大军相援令他再死守一天"、司马懿"既然定军山败势已定那就让它败得更有价值些"、曹操"妙才是我兄弟他绝不会做俘虏的"、曹操"鸡肋"、曹操"刘备连胜四阵已成骄兵，此役是我与刘备的最终决战，败了我就是第二个袁绍"、司马懿"如果赵云始终不出现就意味着他可能在我们最薄弱的地方突然出现"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是定军山，是"鸡肋鸡肋个锤子啊，这是鸡肋吗，这不鸡翅尖吗"；最讽刺的是"法正都不需要用计，黄忠做进攻方就能把夏侯渊打得满地找牙——百万大军平推"。
- **时间边界**：219 年冬，定军山。求援 → 鸡肋 → 赵云奇袭（一场内）。水淹七军留 P5_s17。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：夏侯渊求援血书一封封送到曹操大营。

- **场景**：汉中·定军山。求援、弃将、斩妙才、鸡肋、赵云奇袭。
- **锁定台词（必须逐字出现）**：曹操"夏侯渊英勇不愧为吾弟！我这就派徐晃许褚率三万大军前去相援，令他再死守一天待援兵到里应外合聚歼黄忠"；司马懿"既然定军山败势已定，那就让它败得更有价值些"；曹操"不用说了我知道什么结果！妙才是我兄弟，他绝不会做俘虏的"；曹操"鸡肋"；曹操"刘备连胜四阵已成骄兵，此役是我与刘备的最终决战，胜了刘备死无葬身之地，败了我就是第二个袁绍"；司马懿"如果赵云始终不出现的话，就意味着他可能在我们最薄弱的地方突然出现"。
- **世界侧**：汉水之滨五界山前荒原无边枯草秋风。汉水畔涌来刘备蜀军浩大军阵，两阵相距两箭之地鼓声戛然而止，曹操与刘备几乎同时拔剑直刺苍穹朝前劈下大吼"开战！"——大战三日汉水整条河被染成鲜红。战后法正率众请刘备进位汉中王。
- **玩家视角（乐子人）**："鸡肋鸡肋个锤子啊，这是鸡肋吗，这不鸡翅尖吗。鸡翅尖多少还是有点肉的吧。"
- **必然结果**：`flags_add: ["见证者_汉中之战"]`（flags_on_enter 锚定）

## 六、文风落点（乐子人版）

- **世界侧**：正常演出——曹操正常弃将、黄忠正常平推、杨修正常作死
- **玩家视角**：折棒式吐槽——"鸡肋鸡翅尖个锤子"、"法正不用计黄忠平推夏侯渊满地找牙"、"刘备心想放肆又不能表现出来"、"赵云奇袭曹操头风昏迷"
- **选项 effect**：微带梗味——"鸡肋=食之无肉弃之有味"
- **不出现**：水淹七军（P5_s17）、败走麦城（P6）等后续
