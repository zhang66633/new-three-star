# P4_s4 曹操迎献帝·奉天子以令不臣

> 场景开发协议五步流程 · P4_s4（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第13-14回（曹操奉迎天子迁都许昌）
> 字幕锚点：折棒 36-37 期（大汉反贼荀文若 / 鸡汤来喽）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P4）：**迎驾 vs 弃驾**。李傕郭汜劫掠后献帝落难，袁绍拒诏（田丰"天子是累赘"），曹操大笑"如此良机，千古难觅"、骑兵一天一夜奔袭五百里迎驾——奉天子迁都许昌，"挟天子以令诸侯"。玩家是围观鸡汤猜谜、跟曹操赛马争迎驾，还是当面夸他"比董卓英雄十倍"？

**设计原则**：
- **名场面开场即现场**：玩家入场即在洛阳长乐宫废墟/许都，亲历"拒诏 → 奔袭 → 献帝落难 → 鸡汤 → 落虎穴"全链。这是 `见证者_曹操迎帝` 的触发点，非可选。
- **字幕锚定**：许攸"活生生的皇帝怎会没人要"、曹操"如此良机千古难觅"、献帝"朕渴了朕饿了"、曹操"这是刚刚烹熟的鸡汤"、献帝"逃出狼窝又落虎穴"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是迎驾，是"鸡汤端脸上了还猜不出来"、曹操"只给勺子不给筷子"。
- **时间边界**：196 年秋，洛阳至许都。拒诏 → 迁都（一场内）。辕门射戟留 P4_s5。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：献帝与百官以粗糠腐肉为食、奄奄待毙。

- **场景**：许都·长乐宫废墟。董承密诏、曹操奔袭、鸡汤名场面。
- **锁定台词（必须逐字出现）**：
  - 许攸："主公短视，庸臣误国！一只小小的传国玉玺，众诸侯还争来抢去，一个活生生的皇帝怎会没人要呢！"
  - 曹操："如此良机，千古难觅！"
  - 汉献帝："爱卿，朕渴了，朕饿了！"
  - 曹操："请吾皇猜一猜。……天子，这是刚刚烹熟的鸡汤。"
  - 汉献帝："爱卿啊，朕半年多不识肉味了……"
  - 汉献帝："爱卿，朕刚刚逃出狼窝，却又落入虎穴，这可怎生是好？"
- **世界侧**：长乐宫一片废墟、龙座布满厚尘，献帝刚落座龙椅"嘎吱"塌了；百官衣衫褴褛，董承从怀里掏出半块面饼；曹操骑兵边奔袭边实时收到冀州探报（哨记快递）；袁绍在冀州整军备战盘算攻幽州，许攸下殿独自摇头"主是庸主，臣是佞臣"。
- **玩家视角（乐子人）**："鸡汤都端脸上了还猜不出来，且曹操只给勺子不给筷子。"
- **必然结果**：玩家成为名场面亲历者 → `flags_add: ["见证者_曹操迎帝"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **李傕郭汜劫掠** → 献帝百官粗糠腐肉为食（世界侧背景）
2. **袁绍拒诏** → 田丰"天子是累赘"，许攸独叹（关键节点）
3. **曹操奔袭** → "追到上天入地也要把天子追到手"，一天一夜五百里
4. **鸡汤猜谜** → 曹操端刚烹熟的鸡汤让饿半年的献帝猜（乐子人高潮）
5. **迁都许昌** → "逃出狼窝又落虎穴"，曹操拔剑阅兵，献帝封其大将军

## 五、骨架选项（自由行动方向，非剧情分支）

1. **围观曹操端鸡汤让饿半年的献帝猜谜**（tension 5）→ 亲历"鸡汤来喽"名场面（observe）
2. **天子东归时率兵赶去"护驾"，跟曹操比赛谁先追到天子**（tension 30）→ 赛马争迎驾之功（participate）
3. **迁都后曹操大封诸侯，劝曹操把自家地盘写进诏书**（tension 25）→ 借天子诏书谋封赏（influence）
4. **当面夸曹操"你比董卓英雄十倍"，赌他拔剑还是眉开眼笑**（tension 40）→ 一句夸奖测出曹操底色（conflict）

## 六、文风落点（乐子人版）

- **世界侧**（NPC/环境）：正常演出，不调侃——曹操正常迎驾、献帝正常落难、袁绍正常弃驾
- **玩家视角**（内心/差异笔记）：折棒式吐槽——"曹操名言'猜猜看呐'虞姬附体"、"先三叩九拜送菜后脚拔剑阅兵，这是准备直接篡位啊"、"'你比董卓英雄十倍'是最奇妙的夸人方式"
- **选项 effect**：微带梗味——"跟曹操比赛谁先追到天子"
- **不出现**：辕门射戟（P4_s5）、袁术称帝（P4_s6）、官渡之战等后续
