# P6_s2 曹操之死

> 场景开发协议五步流程 · P6_s2（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第78回（治风疾神医身死 / 传遗命奸雄数终）
> 字幕锚点：折棒 223 期（死是凉爽的夏夜，可供人无忧的安眠！）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P6）：**神医开颅 vs 奸雄疑心**。东吴送关羽首级当曹操六五寿礼，曹操一眼看穿孙权嫁祸之意——"他是要让刘备迁怒于我"。厚葬关羽后头风骤发，华佗诊病根在脑、须开颅取风涎，曹操疑华佗与关羽有交欲借机杀他，怒拿下狱，华佗冷哂"我死，曹操也无生路"。病榻上孙权劝进、百官跪劝顺天即位，曹操连声斥"我都快死了，还当什么皇帝"。遗命三件：立曹丕、设疑冢七十二处、准妻妾改嫁——话毕气绝。玩家是掉包利斧救华佗、灵堂替献帝出头，还是抄遗命倒卖"死忠粉周边"？

**设计原则**：
- **名场面开场即现场**：玩家入场即在魏王府病榻前，亲历"送首级 → 头风骤发 → 开颅被疑 → 劝进被斥 → 遗命三件 → 气绝"全链。这是 `见证者_曹操之死` 的触发点，非可选。
- **字幕锚定**：曹操"我头好痛，像有针扎剑绞…"、华佗"用利斧砍开魏王头颅，取出风涎"、曹操"拿斧头劈开我的脑袋？你想杀我吗！"、华佗"我死，曹操也无生路"、曹操"他拥立我，是要把我捧到炉火上烤呀"、遗命"设立疑冢七十二处……愿意改嫁者，准她们改嫁"——锁定台词逐字出现。
- **乐子人基调**：最响亮的是"曹操临死前的遗言像念海涅的'死是凉爽的夏夜'——两千年前怎么就有了德国现代诗"；最讽刺的是"疑冢七十二处还'愿意改嫁者准她们改嫁'——连遗命都这么宠粉"。
- **时间边界**：220 年正月，许都。送首级 → 遗命气绝（一场内）。曹丕篡汉留 P6_s3。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：曹操厚葬关羽后头风骤发，抚额而叫。

- **场景**：许都·魏王府病榻。送首级、头风骤发、开颅被疑、劝进被斥、遗命气绝。
- **锁定台词（必须逐字出现）**：曹操"我头好痛，像有针扎剑绞…"；华佗"先饮麻沸汤，然后用利斧砍开魏王头颅，取出风涎，如此便可除去病根。"；曹操"什么？拿斧头劈开我的脑袋？你想杀我吗！"；华佗"我死，曹操也无生路。"；曹操"你以为孙权是真心？他拥立我，是要把我捧到炉火上烤呀！"；曹操"孤纵横天下三十余年，群雄皆灭，只有江东孙权、西蜀刘备未曾剿除……孤此生杀人甚多，死后，你们在彰德府武城外，设立疑冢七十二处，断不能让世人知道吾葬处……还有，孤所遗妻妾，愿走则走，愿意改嫁者，准她们改嫁……"。
- **世界侧**：许都大雪，洛阳南门外程昱与百官素服送葬关羽，曹操披斗篷坐孤坟前泪流满面、头风骤发。太医束手，曹丕飞骑请华佗。榻前百官跪劝进，曹操闭目不语、命程昱让百官散了。灵堂上献帝以天子之尊来吊，华歆逼他跪叩先王；太庙里献帝哭诉"大汉四百年基业就要毁于臣手里"。曹丕入主先王书房，司马懿去劳曹彰十万奔丧大军——世界照常运转，只是老天子发现自己已跪过一回。
- **玩家视角（乐子人）**："华佗给曹操开颅的处方是'用利斧砍开魏王头颅取出风涎'——这不是治病，这是拆机啊。"
- **必然结果**：`flags_add: ["见证者_曹操之死"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **送首级** → 孙权献关羽首级当寿礼，曹操看穿嫁祸（过渡铺垫）
2. **头风骤发** → "我头好痛，像有针扎剑绞…"，飞骑请华佗
3. **开颅被疑** → "拿斧头劈开我的脑袋？"，华佗下狱"我死曹操也无生路"（乐子人高潮）
4. **劝进被斥** → "他拥立我，是要把我捧到炉火上烤呀"，"我都快死了还当什么皇帝"
5. **遗命气绝** → 立曹丕、疑冢七十二处、准妻妾改嫁
6. **灵堂逼跪** → 华歆逼献帝跪叩先王，太庙哭诉

## 五、骨架选项（自由行动方向，非剧情分支）

1. **混在百官跪劝进队伍里听"顺天即位"全流程，抄录孙权劝进书和百官进表**（tension 10）→ 成就"炉火烤曹见证人"（observe）
2. **在华佗被押走前掉包利斧、塞解药救下华佗，结一段神医善缘**（tension 35）→ 成就"华佗救命恩人"（participate）
3. **扮作曹彰信使向司马懿递假消息，挑动十万奔丧军vs许都，把"曹彰交兵权"搅成火并**（tension 40）→ 成就"兄弟阋墙点火人"（influence）
4. **闯灵堂替汉献帝出头，当众顶华歆"陛下是皇帝"——被许褚虎卫按住也骂爽了**（tension 45）→ 成就"灵堂出头鸟"（conflict）
5. **抄录"疑冢七十二处+准改嫁"遗命原文，刻竹简倒卖曹操"死忠粉周边"**（tension 20）→ 成就"遗命周边贩子"（trade）

## 六、文风落点（乐子人版）

- **世界侧**：正常演出——曹操正常头痛、华佗正常开颅、百官正常劝进
- **玩家视角**：折棒式吐槽——"死是凉爽的夏夜可供人无忧的安眠"（海涅现代诗）、"利斧砍开魏王头颅是拆机"、"疑冢七十二处准媳妇改嫁"、"忽悠你接着忽悠"
- **选项 effect**：微带梗味——"遗命周边贩子""炉火烤曹"
- **不出现**：曹丕篡汉（P6_s3）、夷陵之战（P6_s4）、白帝托孤（P6_s5）等后续
