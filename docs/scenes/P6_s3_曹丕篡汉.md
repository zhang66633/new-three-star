# P6_s3 曹丕篡汉

> 场景开发协议五步流程 · P6_s3（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第80回（曹丕废帝篡炎刘 / 汉王正位续大统）
> 字幕锚点：折棒 224-233 期（一辞再辞三辞 / 王椅比龙座还大 / 退朝自己喊 / 图谶自己解）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P8）：**禅让表演 vs 四百年汉室**。曹操死后曹丕继位魏王，追尊曹操为武皇帝——汉献帝还坐在龙座上，侧畔一尊"比龙座还大"的王椅已备好。司马懿借回赠孙权"传国夜明珠"的礼单点破"只有天子才能册封王位"，劝进"正因为主公不及先王，主公才更需要进位称帝"。曹丕定下禅让台本：一辞、再辞、三辞。华歆逼献帝交出图谶、百官齐呼"万岁万岁万万岁"后太监自作主张高喊"退朝"——满朝只有献帝一人颤颤巍巍走下大殿。受禅坛三层高坛在霞光下仿佛抹上一层鲜血，四百年汉室就此禅没。玩家是混进仪仗队记"退朝见证"、讨《七步诗》孤本，还是华歆逼玺时救祖弼？

**设计原则**：
- **名场面开场即现场**：玩家入场即在受禅大典，亲历"追尊武皇帝 → 司马懿劝进 → 一辞再辞三辞 → 图谶自解 → 退朝只有献帝下殿 → 受禅坛如血"全链。这是 `见证者_曹丕篡汉` 的触发点，非可选。
- **字幕锚定**：曹丕"这我知道，我会一辞，再辞，三辞"、司马懿"正因为主公不及先王，主公才更需要进位称帝！"、华歆"陛下可带着这本图谶去见祖宗！"、汉献帝"天啊，你杀我两次不够，还要杀第三次吗！"、汉献帝"做皇帝时，是人家逼我的；不做皇帝时，也是人家逼我的。"——锁定台词逐字出现。
- **乐子人基调**：最响亮的是"太监高喊退朝，满朝无一人动，只有刘协自己颤颤巍巍走下去——感情是命令刘协退朝是吧"；最讽刺的是"华歆说'文王禅于武王'——哪条世界线的历史；图谶流程都被砍了，让刘协自己解读"。
- **时间边界**：220 年十一月，许都。追尊 → 受禅（一场内）。夷陵之战留 P6_s4。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：献帝坐龙座，侧畔王椅"比龙座还大"。

- **场景**：许都·受禅坛。追尊武皇帝、司马懿劝进、一辞再辞三辞、图谶自解、退朝独下殿、受禅如血。
- **锁定台词（必须逐字出现）**：曹丕"这我知道，我会一辞，再辞，三辞。"；司马懿"正因为主公不及先王，主公才更需要进位称帝！"；华歆"陛下可带着这本图谶去见祖宗！哪怕是九泉之下，也定能含笑心安了！"；汉献帝"天啊，你杀我两次不够，还要杀第三次吗！"；汉献帝"做皇帝时，是人家逼我的；不做皇帝时，也是人家逼我的。"；老宦官"这尊王椅比您的龙座还大。陛下，曹丕只怕比他父亲更奸险可怕啊。"。
- **世界侧**：许都朝会照常运转：承旨官宣诏"改建安二十五年为延康元年"，百官齐呼万岁，东吴孙权特遣使臣不远千里朝贺。曹丕书房研读礼单、斟酌回赠轻重；献帝按例早朝，臣工照常奏事。太庙里香烛缭绕，献帝跪在历代先皇灵位前哀号。受禅坛筑起，坛下旌旗蔽空、百官跪叩——一切礼仪的"形"都在，只是"神"已经不在了。
- **玩家视角（乐子人）**："这尊王椅比你的龙座还大呀——太监都比刘协先看清了局势。"
- **必然结果**：`flags_add: ["见证者_曹丕篡汉"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **追尊武皇帝** → 曹丕继位魏王，献帝还坐龙座（过渡铺垫）
2. **司马懿劝进** → 回赠孙权夜明珠点破"只有天子才能册封王位"（乐子人高潮）
3. **一辞再辞三辞** → 禅让台本，"你杀我两次不够还要杀第三次"
4. **图谶自解** → 华歆摔图谶，流程被砍让刘协自己解读
5. **退朝独下殿** → 太监高喊退朝，只有献帝一人走下大殿
6. **受禅如血** → 三层高坛霞光如抹血，四百年汉室禅没

## 五、骨架选项（自由行动方向，非剧情分支）

1. **混进受禅大典仪仗队，记下太监高喊"退朝"、只有献帝一人走下大殿的散朝全程**（tension 10）→ 成就"退朝见证人"（observe）
2. **给曹植随从递酒壶，趁乱讨到《七步诗》真稿——手上这份成了孤本**（tension 20）→ 成就"七步诗孤本"（participate）
3. **抢在司马懿开口前递上"一辞再辞三辞"禅让台本换传旨差事，借传话把曹节"请鞭笞我吧陛下"丑闻传遍许都**（tension 35）→ 成就"禅让导演"（influence）
4. **在华歆逼玉玺官祖弼交玺时抢先把人拽出大殿藏进民居，换"臣宁断头不交玺"效忠，代价上许褚搜捕名单**（tension 40）→ 成就"宁断头不交玺"（conflict）
5. **在山阳公船队用一坛美酒从船夫手里换汉献帝批过的旧诏残卷，转卖富商两头吃差价**（tension 15）→ 成就"汉室遗物贩子"（trade）

## 六、文风落点（乐子人版）

- **世界侧**：正常演出——曹丕正常禅让、百官正常万岁、汉室正常禅没
