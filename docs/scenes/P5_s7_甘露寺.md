# P5_s7 甘露寺招亲

> P5_s7（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第54回（吴国太佛寺看新郎 / 刘皇叔洞房续佳偶）
> 字幕锚点：折棒 156-164 期（龙可是帝王之征 / 江东之主轮流做 / 问天劈石）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P7）：**美人计 vs 将计就计**。甘夫人一死，周瑜计上心头——以孙尚香为饵诱刘备入吴扣人换荆州。刘备将计就计揣着三条锦囊带赵云赴吴。甘露寺里吴国太相女婿正欢喜，吕蒙却拔剑要斩——"吕蒙疯了，拉下去斩了！"。孙权化身刀斧手、简雍演孙权，刘备问天劈石、洞房"相敬如宾"一夜拉满孙尚香好感。玩家是围观江东之主轮流做、送情报保刘备，还是两头赚差价？

**设计原则**：
- **名场面开场即现场**：玩家入场即在甘露寺，亲历"美人计 → 刀斧手 → 问天劈石 → 洞房好感"全链。这是 `见证者_甘露寺` 的触发点，非可选。
- **字幕锚定**：关羽"诸葛亮在投效大哥之前已有卧龙之称，龙可是帝王之征"、孙权"公瑾，这江东到底你是主还是我是主"、刘备"廊下这些刀斧手不是为我刘备而来吗"、孙权"吕蒙疯了，拉下去斩了"、刘备"如能破曹兴汉一剑下去便能砍断此石"、刘备"从现在起你我相敬如宾，在你喜欢上我之前我绝不会玷污你一根手指头"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是洞房，是"让孙权演刀斧手、简雍演孙权，难道是孙权也想体验被人替身"；最讽刺的是"这不是恨石，是神识啊——刘备劈完石头自动复原供孙权再劈"。
- **时间边界**：209 年秋，甘露寺。招亲 → 洞房（一场内）。合肥大战留 P5_s8。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：甘露寺相亲，孙权化身刀斧手。

- **场景**：南郡·甘露寺。相亲宴、刀斧手、问天劈石、洞房。
- **锁定台词（必须逐字出现）**：关羽"诸葛亮在投效大哥之前已有卧龙之称，龙可是帝王之征"；孙权"公瑾，这江东到底你是主还是我是主"；刘备"廊下这些刀斧手不是为我刘备而来吗？你也算是一方诸侯，这是待客之道吗"；孙权"吕蒙疯了，拉下去斩了"；刘备"如能破曹兴汉，一剑下去便能砍断此石"；刘备"从现在起你我相敬如宾，在你喜欢上我之前，我绝不会玷污你一根手指头"。
- **世界侧**：甘露寺相亲宴，刘备赵云孙权国太依次落座酒过三巡其乐融融；廊下刀斧手屏息待命，孙尚香隔珠帘相看四十八岁皇叔。这本该是场和亲过场戏，偏偏江东权柄这几日"轮流做了主"。
- **玩家视角（乐子人）**："为什么要让简雍来演孙权，让孙权演刀斧手呢？难道是孙权也想体验一下被人替身的感觉。"
- **必然结果**：`flags_add: ["见证者_甘露寺"]`（flags_on_enter 锚定）
