# P4_s11 官渡之战

> P4_s11（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第30回（战官渡本初败绩）
> 字幕锚点：折棒 68-70 期（7万高达反向包围70万 / 夜袭变明袭）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P5）：**以少胜多 vs 骄兵必败**。袁绍七十万大军南下，曹操七万精兵据守官渡——"我军足足有七万精兵，对面只有七十万，优势在我"。许攸献计夜袭乌巢烧粮，曹操五千精骑奔袭（"估计会在黎明时分到达"），一把火扭转乾坤。玩家是围观阵前"请和之茶"、加入乌巢纵火队，还是抓住粮草信息差倒卖军粮？

**设计原则**：
- **名场面开场即现场**：玩家入场即在官渡河岸大营，亲历"对峙 → 献计 → 夜袭乌巢 → 大胜"全链。这是 `见证者_官渡之战` 的触发点，非可选。
- **字幕锚定**：曹操"兵不在多在精"、曹操"七万精兵对面七十万优势在我"、许攸"乌巢守将淳于琼酒囊饭袋"、曹操"五千精骑奔袭黎明到达"、荀彧"田亩生长出无尽兵马"、袁绍"苍天助曹不助袁"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是乌巢大火，是"七万是高达"；最讽刺的是曹操请袁绍阵前喝茶、亮出宫女和天子当"请和之物"。
- **时间边界**：200 年秋，官渡。对峙 → 大胜（一场内）。袁绍败亡留 P4_s12。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：两军隔河对峙，袁绍七十万大军连营百里。

- **场景**：官渡·河岸大营。阵前对峙、夜袭乌巢。
- **锁定台词（必须逐字出现）**：
  - 曹操："兵不在多在精，将不在勇在谋。如果要比将士多寡，我永远也比不上袁绍；可是要比起精悍和智谋，三个袁本初绑一块也比不上我一个曹操。"
  - 曹操："我军足足有七万精兵，而对面只有七十万，优势在我。"
  - 许攸："那袁绍所有的辎重粮草全部屯于乌巢，守将淳于琼，那是个酒囊饭袋……如果孟德兄亲率一支铁骑连夜杀奔乌巢，一把火烧了他的辎重，援军势必大乱！"
  - 曹操："我这就出发，率猛将精骑五千奔袭乌巢，估计会在黎明时分到达。"
  - 荀彧："袁绍虽大败，但他仍然拥有四州富裕之地，万千田亩，不但能够生长出无尽的粮食，也能生长出无尽的兵马。"
  - 袁绍："苍天助曹不助袁！"
- **世界侧**：袁绍七十万大军连营百里、水陆绵延，粮草辎重如山；曹操据守官渡要冲，七万精兵日夜操练、布三重防御，两军隔河对峙，探马往来、军报如飞——世界本该按"兵力悬殊、旷日持久"的常识运转。
- **玩家视角（乐子人）**："七万是高达——七万大军反向包围袁绍七十万，正面一波'火焰流星雨'打崩。"
- **必然结果**：玩家成为名场面亲历者 → `flags_add: ["见证者_官渡之战"]`（flags_on_enter 锚定）

5. **混进冀州大牢见证田丰在星光下自刎**（tension 25）→ 留遗书，成就"最后的星象"（participate）

## 六、文风落点（乐子人版）

- **世界侧**（NPC/环境）：正常演出，不调侃——曹操正常布阵、袁绍正常骄兵、许攸正常献计
