# P4_s13 刘备投荆州

> 场景开发协议五步流程 · P4_s13（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第34-35回（刘皇叔跃马檀溪 / 玄德用计袭樊城）
> 字幕锚点：折棒 97-99 期（见面就送城 / 关张职场霸凌 / 回马荐诸葛）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P4）：**寄人篱下 vs 求贤若渴**。曹操击败袁绍挥师南下，刘备惶惶而退投奔荆州刘表——刘表见面先拿"锦匣装人头"下马威、转头却拨新野城给刘备驻军；徐庶破曹仁八门金锁阵入职新野，却被曹操"火烤徐母"之计逼走。玩家是随赵云破阵蹭助攻、替徐庶鸣不平，还是劝刘备"把树林伐尽"目送军师？

**设计原则**：
- **名场面开场即现场**：玩家入场即在新野城，亲历"投荆州 → 送城 → 徐庶入职 → 火烤徐母 → 伐林目送"全链。这是 `见证者_刘备投荆州` 的触发点，非可选。
- **字幕锚定**：刘表"锦匣装人头"、刘表"拨出新野城"、徐庶"刘景升徒具虚名"、张飞"我要是曹操明天就攻来"、刘备"恨不能把树林伐尽"、徐庶"与其寻找主公不如创造主公"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是八门金锁阵，是刘表"刚见面就送城，到底是忌惮还是器重都看迷糊"；最讽刺的是徐庶入职当天遭关张职场霸凌。
- **时间边界**：201 年夏，新野。投荆 → 送徐庶（一场内）。三顾茅庐留 P4_s14。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：刘备投荆州，刘表见面送城。

- **场景**：荆州·新野城。投荆、送城、徐庶入职与离开。
- **锁定台词（必须逐字出现）**：
  - 刘表："孙乾，这只锦匣原本是装春茶用的，现有人建议，让我斩下你的头颅，装在这匣子里送给曹操……你觉得这个主意怎么样啊？"
  - 刘表："我想拨出新野城，供你驻军，帮助我共拒曹操。凭你那关、张、赵三将，足可令曹军丧胆！"
  - 徐庶："刘景升此公虽有善心，却无大志，徒具虚名而已。"
  - 张飞："干吗非三十天以后？我要是曹操，明天就攻来了！"
  - 刘备："恨不能把那片树林全部伐尽！它们遮住了先生的身影。"
  - 徐庶："与其寻找主公，不如为自己创造一个主公。"
- **世界侧**：荆州是当世最大的清平之地：襄阳城百业兴旺、稻麦大熟，甲士三十万、战船五千艘；刘表年过六旬自诩"一山一水一村一镇都是我苦心栽培的"，全无称霸之志；新野城池虽小易守难攻，刘备驻军一年轻徭薄赋，乡间传起民谣"新野牧，刘皇叔，自到此，民丰足"。
- **玩家视角（乐子人）**："这刚见面就送城的剧情跳跃，到底是忌惮还是器重，都看迷糊了。"
- **必然结果**：玩家成为名场面亲历者 → `flags_add: ["见证者_刘备投荆州"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **投奔荆州** → 孙乾"汉贼不两立"，刘表见面送城（过渡铺垫）
2. **徐庶破阵** → 曹仁八门金锁阵，赵云带五百金甲从生门杀入（乐子人高潮）
3. **职场霸凌** → 关张赵开庆功宴把徐庶晾外面，只提"关张赵之勇"
4. **火烤徐母** → 曹操假传徐母书信扬言火烤，徐庶连夜要走
5. **伐林目送** → "恨不能把树林全部伐尽"，徐庶"与其寻找主公不如创造主公"

## 五、骨架选项（自由行动方向，非剧情分支）

1. **随赵云带五百金甲从东南生门杀入，抢在关羽前面把曹仁干下台**（tension 30）→ 成就"破阵蹭助攻"（participate）
2. **破阵后关张赵开庆功宴把徐庶晾外面，替徐庶说句公道话或加入嘲讽团**（tension 15）→ 成就"军师之友"（observe）
3. **徐庶连夜要走，劝刘备"把前面那片树林全部伐尽"目送**（tension 35）→ 成就"目送大师"（influence）
4. **抢先摘樊城"蒲扇大的灵芝"换军粮，或反手卖给曹操阵营**（tension 20）→ 成就"灵芝大盗"（trade）
5. **一顾茅庐围观刘备把诸葛均/崔州平认成孔明**（tension 10）→ 成就"龟壳占卜师"（observe）

## 六、文风落点（乐子人版）

- **世界侧**（NPC/环境）：正常演出，不调侃——刘表正常送城、徐庶正常跑路、关张正常霸凌
- **玩家视角**（内心/差异笔记）：折棒式吐槽——"刚见面就送城看迷糊"、"关张职场霸凌，当天晚上就跑路了"、"徐母乞讨，想起王允也乞讨"、"与其寻找主公不如创造主公像创业导师"
- **选项 effect**：微带梗味——"抢在关羽前面把曹仁干下台"
- **不出现**：三顾茅庐（P4_s14）、隆中对策、火烧博望坡等后续
