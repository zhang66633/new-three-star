# P5_s17 水淹七军

> 场景开发协议五步流程 · P5_s17（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第74回（庞令明抬榇决死战 / 关云长放水淹七军）
> 字幕锚点：折棒 216/218 期（法师关羽 / 登高一望大水自天来）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P5）：**法师关羽 vs 骄兵必败**。关羽北伐围樊城，曹操遣于禁统七路救兵、庞德为先锋救援。庞德青袍银铠抬棺叫阵，回身暗放一箭正中关羽左臂，得意放话"关羽中我这一箭，三天之后此仗就无需打了"。关羽策马冒雨巡视山岭，望着谷地里的于禁营盘冷笑："于禁居然把营寨安在这么低洼的山谷里……只要在西边筑一道堤坝，放水一淹，曹军就成瓮口里的王八了！"曾口川掘堤放襄水，水淹七军，擒于禁斩庞德。玩家是混进筑坝工兵队、端庞德庆功酒，还是薅走那张"冰暗附魔弓"？

**设计原则**：
- **名场面开场即现场**：玩家入场即在樊城至曾口川，亲历"庞德抬棺叫阵 → 射伤关羽 → 七军庆功 → 登高一望大水来 → 擒于禁斩庞德"全链。这是 `见证者_水淹七军` 的触发点，非可选。
- **字幕锚定**：庞德"吾奉魏王旨特来取你首级，棺木已为你备好"、关羽"天下英雄闻我名无不丧胆，可惜我这把青龙刀今日竟要斩你这个鼠贼"、关羽"于禁居然把营寨安在这么低洼的山谷里，只要在西边筑一道堤坝放水一淹曹军就成瓮口里的王八了"、庞德"关羽中我这一箭三天之后此仗就无需打了"、军士"大水了四面八方都是水"、关羽"杀你如屠一猪狗，把于禁押回荆州待我擒了曹操一并交主公发落"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是襄水，是"我原本以为关羽就是单纯的武将，没想到还能做法师……关羽啥也没干，这登高一望，曹军就被淹了"；最讽刺的是"酒都没喝完，水就淹过来了——庞德庆功酒还没凉"。
- **时间边界**：219 年秋，樊城。抬棺叫阵 → 水淹七军（一场内）。败走麦城留 P6。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：庞德抬棺叫阵，回身暗放一箭。

- **场景**：麦城·樊城至曾口川。抬棺叫阵、射伤关羽、登高一望、水淹七军。
- **锁定台词（必须逐字出现）**：庞德"关羽听着！吾奉魏王旨特来取你首级，棺木已为你备好"；关羽"狂徒！天下英雄闻我名无不丧胆，可惜我这把青龙刀今日竟要斩你这个鼠贼"；关羽"奇怪，于禁居然把营寨安在这么低洼的山谷里！方今秋雨连绵数日之后襄水就要暴涨，只要在西边筑一道堤坝放水一淹曹军就成瓮口里的王八了"；庞德"我西凉人自小善用弓箭，关羽中我这一箭三天之后此仗就无需打了"；军士"大水了，四面八方都是水"；关羽"杀你如屠一猪狗只能脏了我的刀斧！把于禁押回荆州待我擒了曹操一并交主公发落"。
- **世界侧**：曹军七路连营扎在低洼山谷连日秋雨连绵。关羽在曾口川悄悄筑起堤坝趁雨掘堤放襄水——大水铺天而来，七军连营被冲得稀里哗啦数万曹军尽成俘虏。时值天晴雨止红日高挂，阳光照在关羽身上仿佛天神，关平在旁笑道"父亲借来天上大水"。
- **玩家视角（乐子人）**："我原本以为关羽就是单纯的武将，没想到还能做法师……关羽啥也没干，这登高一望，曹军就被淹了。"
- **必然结果**：`flags_add: ["见证者_水淹七军"]`（flags_on_enter 锚定）
