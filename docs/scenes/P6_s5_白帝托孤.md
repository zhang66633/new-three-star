# P6_s5 白帝托孤

> P6_s5（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第85回（刘先主遗诏托孤儿 / 诸葛亮安居平五路）
> 字幕锚点：折棒 249-253 期（诸葛瑾压血线 / 阿斗补刀绝杀 / 神仙断句沛丰易中阳里）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P8）：**托孤遗言 vs 接力送终**。夷陵大败后刘备病倒白帝城，孙权遣诸葛瑾送还战俘赔罪求和——刘备一听"赔罪"当场喷血昏厥。病榻前刘备先拉刘禅试探，问"你能够承继大业中兴汉室吗"，刘禅答"儿臣只想一辈子做儿臣"，刘备重重叹气"你要是生在平民百姓家该有多好"。临终召诸葛亮入永安宫托孤，遗言逐级加码——"如你觉得他不成器，你可取而代之，自领川蜀，承继帝位！"又命刘禅叩拜孔明为亚父，"你事先生，要如君如父啊"。临终前诸葛亮还当面夸马谡"当世英才，不次于江东陆逊"——压血线最后一击，先帝这口气终于咽下了。玩家是伏屏风偷听托孤实录、递参汤续命，还是盗五路方略泄题？

**设计原则**：
- **名场面开场即现场**：玩家入场即在永安宫病榻前，亲历"赔罪喷血 → 阿斗试探 → 托孤加码 → 夸马谡压血线 → 有此一拜 → 气绝归天"全链。这是 `见证者_白帝托孤` 的触发点，非可选。
- **字幕锚定**：刘备"如你觉得他不成器，你可取而代之，自领川蜀，承继帝位！"、刘备"孔明，你休要疑虑，这是我的真心话"、刘备"给先生叩首。即日起，孔明先生便是你的亚父。你事先生，要如君如父啊！"、诸葛亮"当世英才，不次于江东陆逊"、刘禅"儿臣……只想一辈子做儿臣"、刘备"有此一拜，朕死也安心了"——锁定台词逐字出现。
- **乐子人基调**：最响亮的是"诸葛瑾和诸葛亮先压血线，最后由刘禅打出致命一击，才把刘备活活气死归天——接力棒赛式送终"；最讽刺的是"刘备确实没有埋伏下500刀斧手，不然就凭诸葛亮夸马谡这句话，这500刀斧手早就一拥而上把诸葛亮剁成肉泥了"。
- **时间边界**：223 年四月，白帝城永安宫。赔罪喷血 → 气绝归天（一场内）。此为止点，全流程 P6 完结。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：诸葛瑾奉孙权之命进永安宫赔罪求和，刘备一听"赔罪"当场喷血昏厥。

- **场景**：益州·白帝城永安宫。赔罪喷血、阿斗试探、托孤加码、夸马谡压血线、有此一拜、气绝归天。
- **锁定台词（必须逐字出现）**：刘备"至于孺子阿斗，你愿意辅佐就辅佐他，如你觉得他不成器，你可取而代之，自领川蜀，承继帝位！"；刘备"孔明，你休要疑虑，这是我的真心话。"；刘备"给先生叩首。即日起，孔明先生便是你的亚父。你事先生，要如君如父啊！"；诸葛亮"当世英才，不次于江东陆逊。"；刘禅"儿臣……只想一辈子做儿臣。"；刘备"有此一拜，朕死也安心了。"。
- **世界侧**：永安宫烛火摇动，刘禅呆呆跪守在病榻前，刘备一醒便心疼地抚着他脸颊"这地潮，跪久了会腿疼"；李严解剑入宫、步步谨慎，在阴森烛影里受"太子太傅加封益侯"之命；诸葛亮赶到时刘备已气息奄奄，君臣凝目良久，从白发聊到隆中策。宫外文武大臣候旨，马谡在门外犹豫侍立。成都宫门外的书摊照常开张，川蜀书生仍在买《高祖本纪》抄本——世界的政务军务礼法都在照常运转，只有病榻上的先帝知道，一切都在走向结算。
- **玩家视角（乐子人）**："刘禅背《高祖本纪》：沛丰易中阳里人——神仙断句。你不能说他有问题，因为他这个智商理解不了句子意思，能死记硬背记住几句就不错了。"
- **必然结果**：`flags_add: ["见证者_白帝托孤"]`（flags_on_enter 锚定）

1. **趁夜翻进永安宫伏在屏风后偷听托孤，亲耳听到"孔明你休要疑虑这是我的真心话""你事先生要如君如父"，把升级版"承继帝位"遗言记在木牍上**（tension 10）→ 成就"托孤实录"（observe）
