# P5_s15 逍遥津之战

> P5_s15（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第67回（张辽威震逍遥津）｜注：本场景剧版零镜头，为"名场面重建"
> 字幕锚点：折棒 144 期（张800大破孙10万 / 剧里连提都不带提）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P7）：**八百敢死 vs 十万吴兵**。曹操西征汉中、后方空虚，孙权亲率十万众围攻合肥。守将张辽趁夜募八百敢死队、白布缠臂为号直捣孙权中军——一夜之间十万吴军溃逃。孙权退至逍遥津北，桥板已被拆断，身后追兵将至，唯有跃马飞渡一途。这一战史书称"张八百大破孙十万"、江东小儿闻名不敢夜啼，却在《新三国》镜头里一个字都没演——它成了本世界"凭空蒸发"的头号名场面，只能由玩家亲临其境补上。玩家是围观剧版没拍的夜袭、混进八百敢死队，还是桥头拦路讹一笔桥费？

**设计原则**：
- **名场面开场即现场**：玩家入场即在逍遥津桥北，亲历"八百夜袭 → 十万溃逃 → 跃马断桥"全链（剧版空白由本场景重建）。这是 `见证者_逍遥津` 的触发点，非可选。
- **字幕锚定**（重建口径）：张辽"孙权在合肥屡败于我"、鲁肃"既留下孙权合肥失败的结果欺骗世界又不至于败得那么狠"、孙权"此次合肥大战我连败于张辽耻我耻"、张辽"八百敢死白布缠臂随我直捣孙权中军"、孙权"桥板已断追兵在后——驾"、旁白"张八百大破孙十万，江东小儿闻名不敢夜啼"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是逍遥津，是"这更是重量级，在剧里没有丝毫的表现，连提都不带提——逍遥津镜头为零"；最讽刺的是"孙权跃马过逍遥津桥的镜头反而根本没被拍"。
- **时间边界**：215 年秋，逍遥津。八百夜袭 → 跃马脱身（一场内）。汉中之战留 P5_s16。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：张辽趁夜募八百敢死队夜袭孙权中军。

- **场景**：合肥·逍遥津。八百夜袭、十万溃逃、跃马断桥。
- **锁定台词（必须逐字出现）**：张辽"孙权在合肥屡败于我"；鲁肃"既留下孙权合肥失败的结果欺骗世界，又不至于败得那么狠，还可以顺便搞点收益"；孙权"此次合肥大战我连败于张辽耻我耻"；张辽"八百敢死，白布缠臂，随我直捣孙权中军"；孙权"桥板已断，追兵在后——驾"；旁白"张八百大破孙十万，江东小儿闻名不敢夜啼"。
- **世界侧**：逍遥津桥北芦苇丛暮色压城。桥板被拆断大半只余一丈宽断口；吴军仓皇撤军甲胄令箭粮袋遗落一地。下游水面漂浮着孙权仓皇跃马时坠落的令旗——这一夜合肥城头火起，八百骑踏破十万营。
- **玩家视角（乐子人）**："这更是重量级，在剧里没有丝毫的表现，连提都不带提——逍遥津镜头为零。"
- **必然结果**：`flags_add: ["见证者_逍遥津"]`（flags_on_enter 锚定）
