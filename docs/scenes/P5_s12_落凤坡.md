# P5_s12 落凤坡·凤雏归西

> 场景开发协议五步流程 · P5_s12（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第63回（落凤坡庞统中箭）
> 字幕锚点：折棒 200-201 期（黑暗兵法·公子献头）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P7）：**送死权 vs 天意葬身**。张松被出卖、刘璋斩张松命张任攻葭萌关，刘备庞统弃关取雒城，行至三岔口——庞统"主公引大军行大路，我引偏师行小路"将送死权揽到自己身上，还特意借来刘备那匹白马"迪卢马"。落凤坡上他勒马一问"此处是何地"，兵士答"此处地名落凤坡"——"我道号凤雏，此地偏偏叫落凤坡，看来这是上天赐我的葬身之地呀！"乱箭穿身，凤雏坠马。玩家是混进伏兵队补上一箭、偷听争夺送死权，还是质疑孤身归来的魏延？

**设计原则**：
- **名场面开场即现场**：玩家入场即在落凤坡，亲历"分兵 → 借马 → 问地名 → 乱箭穿身"全链。这是 `见证者_落凤坡` 的触发点，非可选。
- **字幕锚定**：庞统"主公引大军行大路我引偏师行小路"、刘备"军师我看我们不要分兵了"、庞统"请主公借我坐骑一用，迪卢马性情虽暴却能救主"、张任"放他们过去等刘备的大队人马过来再打"、庞统"此处是何地"、庞统"落凤坡，我道号凤雏，看来这是上天赐我的葬身之地"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是乱箭，是"黑暗兵法之公子献头——因为天意规定了庞统必须死在落凤坡"；最讽刺的是"张任半分钟前刚下令放他们过去，转头却对单骑前出的庞统放箭——张任也精神分裂呀"。
- **时间边界**：214 年夏，落凤坡。分兵 → 乱箭（一场内）。益州易主留 P5_s13。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：三岔口，庞统将送死权揽到自己身上。

- **场景**：益州·落凤坡。分兵、借马、问地名、乱箭。
- **锁定台词（必须逐字出现）**：庞统"大路可能有伏军，主公善战，还是主公引大军行大路，我引偏师行小路"；刘备"军师我看我们不要分兵了，一起顺小路前进"；庞统"请主公借我坐骑一用，迪卢马性情虽暴却能救主"；张任"放他们过去，等刘备的大队人马过来再打"；庞统"此处是何地"；庞统"落凤坡，我道号凤雏，而此地偏偏叫落凤坡，看来这是上天赐我的葬身之地呀"。
- **世界侧**：落凤坡山谷两山逼窄树木丛杂。庞统率偏师入谷，抬头见山势阴沉勒马问地名，兵士答"落凤坡"，庞统心头一凛——他道号凤雏此地偏偏叫落凤坡，分明是上天选好的葬身之地。策马当先，山坡前一声炮响，乱箭如飞蝗般尽数向骑白马者射来，四十余箭贯穿躯体。
- **玩家视角（乐子人）**："本世界庞统不是急功近利中伏而死，而是'黑暗兵法之公子献头'——因为天意规定了庞统必须死在落凤坡。"
- **必然结果**：`flags_add: ["见证者_落凤坡"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

## 五、骨架选项（自由行动方向，非剧情分支）

1. **混进张任伏兵队，被裹挟着对单骑进谷的庞统放箭**（tension 40）→ 亲手补上"身中40余箭"中一支，成就"补上一箭"、称号"落凤坡射手"（participate）
2. **分兵前夜偷听争夺送死权，卖情报给张任换蜀锦或保持沉默**（tension 35）→ 成就"送死权裁决者"（influence）
3. **扮西川樵夫蹲山巅围观，画成绢画卖到成都茶馆**（tension 10）→ 成就"落凤坡画师"（observe）
4. **堵住"两日奔驰800多里"送信的关平，用金创药换急信抄本**（tension 20）→ 成就"急信倒卖商"（trade）
5. **质疑孤身归来的魏延"前军全灭你怎么毫发无伤"**（tension 30）→ 成就"异次元质疑者"（conflict）

## 六、文风落点（乐子人版）

- **世界侧**：正常演出——庞统正常请命、张任正常伏兵、诸葛亮正常观星
- **玩家视角**：折棒式吐槽——"黑暗兵法公子献头"、"张任精神分裂放行转瞬放箭"、"借迪卢马触发房主机制"、"诸葛亮哀哉痛哉毫无悲色我又不能摆烂了"
- **选项 effect**：微带梗味——"亲手补上身中40余箭中的一支"
- **不出现**：益州易主（P5_s13）、单刀赴会（P5_s14）等后续
