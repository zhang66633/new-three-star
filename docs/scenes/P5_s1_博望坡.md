# P5_s1 博望坡

> 场景开发协议五步流程 · P5_s1（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第39回（博望坡军师初用兵）
> 字幕锚点：折棒 104 期（初出茅庐第一功·点不着的火）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P5）：**军师立威 vs 关张不服**。三顾茅庐刚请回孔明，夏侯惇十万军马来攻；关羽张飞不服"三请诸葛亮"，坐看军师调兵。诸葛亮借剑印部署博望坡伏兵、博望城纵火——"请主公弃营而逃，待看到南面火起，便可回军掩杀"。然而火怎么都点不着（关平等张飞、张飞等火起的死循环），初出茅庐第一功打成"点不着的火"。玩家是围观关平原地挂机、改部署成原著版，还是随关张截击夏侯惇抢真刀真枪的胜仗？

**设计原则**：
- **名场面开场即现场**：玩家入场即在新野博望坡，亲历"调兵 → 部署死循环 → 弃营 → 火烧不燃 → 关羽叹服"全链。这是 `见证者_博望坡` 的触发点，非可选。
- **字幕锚定**：诸葛亮"博望之左有山名曰豫山"、张飞"你才说过曹军在博望坡"、诸葛亮"令你纵火焚烧"、诸葛亮"待看到南面火起便可回军掩杀"、张飞"你在外拼命我坐地喝茶好自在"、关羽"先生真乃天人用兵如神"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是火，是"关平等张飞、张飞等火起"的部署死循环；最讽刺的是"神仙谋略啊，你这辈子也等不到南面火起"。
- **时间边界**：208 年冬，新野博望坡。调兵 → 火不燃（一场内）。长坂坡留 P5_s2。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：夏侯惇十万军马来攻，孔明借剑印调兵。

- **场景**：荆州·新野博望坡。伏兵部署、纵火焚烧、弃营掩杀。
- **锁定台词（必须逐字出现）**：诸葛亮"曹军进兵必须路经博望坡，博望之左有山名曰豫山，其右有林名曰安林"；张飞"你才说过曹军在博望坡，叫我跑到城里干吗"；诸葛亮"博望坡是曹军进军之途，博望城则是曹军驻军之所，其粮草军械必囤于城中，令你纵火焚烧"；诸葛亮"请主公弃营而逃，待看到南面火起，便可回军掩杀"；张飞"我们在外拼命，你却坐地喝茶，好自在啊"；关羽"先生真乃天人，用兵如神啊"。
- **世界侧**：新野小县，刘备驻军不过数千。曹军压境的消息传到后，百姓往城外搬送粮草、加固城防，探马频繁进出城门。
- **玩家视角（乐子人）**："关平等张飞军至才纵火，张飞等南面火起才杀出——你这不是直接就卡死了吗？神仙谋略啊。"
- **必然结果**：`flags_add: ["见证者_博望坡"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **关张不服** → "三请诸葛亮"坐看军师调兵（过渡铺垫）
2. **借剑印** → 诸葛亮"请主公把佩剑兵符借我十天，否则使不动两位将军"
3. **部署死循环** → 关平等张飞、张飞等火起（乐子人高潮）
4. **弃营掩杀** → "弃营而逃逃得越慌乱越好，待南面火起回军掩杀"
5. **火烧不燃** → 博望坡火点不起来，关羽"先生真乃天人用兵如神"

## 五、骨架选项（自由行动方向，非剧情分支）

1. **蹲博望城外看关平原地挂机**（tension 5）→ 见证点不起来的火（observe）
2. **把部署改成原著版或反向给夏侯惇通风报信**（tension 35）→ 成就"真·初出茅庐第一功"（influence）
3. **随关张截击夏侯惇抢真刀真枪的胜仗**（tension 40）→ 成就"比结算画面先赢一步"（conflict）
4. **跟瞬移的诸葛亮蹭去襄阳刘琦家**（tension 20）→ 看军师两边瞬移（participate）

## 六、文风落点（乐子人版）

- **世界侧**：正常演出——诸葛亮正常调兵、张飞正常顶嘴
- **玩家视角**：折棒式吐槽——"部署死循环卡死"、"火烧博望坡不拍全靠移花接木"、"才薄智弱人设当场丢掉"
- **选项 effect**：微带梗味——"抢在天意结算画面前先赢一步"
- **不出现**：长坂坡（P5_s2）、赤壁之战（P5_s3）等后续
