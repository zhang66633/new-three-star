# P5_s5 南郡之战·借荆州

> 场景开发协议五步流程 · P5_s5（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第51-52回（吴侯拒借荆州 / 诸葛亮智辞鲁肃）
> 字幕锚点：折棒 154-155 期（鲁肃讨债 / 借据文案）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P7）：**借不借 vs 还不还**。赤壁硝烟未散，周瑜与曹仁鏖战南郡——偏偏一根毒火双属性箭穿甲，大都督栽下马来，南郡荆襄被刘备兵不血刃捡走。鲁肃渡江讨债："皇叔有言，公子不在即还荆州。"诸葛亮摇着羽扇"普天之下莫非王土，荆州是朝廷的"——荆州这场口水官司就此开场。玩家是按住周瑜怒气、围观借据文案，还是按张飞逻辑把讨债的捅死？

**设计原则**：
- **名场面开场即现场**：玩家入场即在南郡至柴桑，亲历"周瑜战曹仁 → 箭伤 → 鲁肃讨债 → 话术打发"全链。这是 `见证者_南郡借荆州` 的触发点，非可选。
- **字幕锚定**：曹仁"大乔归我，小乔留给丞相"、鲁肃"皇叔有言公子不在即还荆州"、诸葛亮"普天之下莫非王土，荆州是朝廷的"、诸葛亮"曹操百万之众不足一道何况一周郎"、周瑜"子敬你被骗了，刘备是枭雄诸葛亮狡猾无比"、鲁肃"取下西川请务必归还荆州"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是南郡，是"你们东吴失去的只是荆州，而我们刘皇叔失去的可是仁义啊"；最讽刺的是借据"立字人为啥是鲁肃，荆州是他们鲁肃借的吗"。
- **时间边界**：209 年夏，南郡。借道偷袭 → 讨债（一场内）。取荆南四郡留 P5_s6。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：周瑜箭伤难愈，鲁肃渡江讨债。

- **场景**：南郡·江陵至柴桑。周瑜战曹仁、鲁肃讨债。
- **锁定台词（必须逐字出现）**：曹仁"大乔归我，小乔留给丞相"；鲁肃"前者皇叔有言公子不在即还荆州，现今公子已经去世，皇叔应该兑现诺言了"；诸葛亮"普天之下莫非王土率土之滨莫非王臣，荆州是朝廷的"；诸葛亮"曹操百万之众在我们眼中都不足一道，何况一周郎"；周瑜"子敬你被骗了，刘备是个枭雄，诸葛亮更是狡猾无比"；鲁肃"你们一旦取下西川请务必归还荆州，否则我家主公必然用兵……死无葬身之所"。
- **世界侧**：刘备初得荆州立足未稳，关羽练出一万劲卒守城；周瑜躺在柴桑病榻上南郡箭伤未愈；曹操退回北方修铜雀台、暗派细作挑动孙刘相争——三国鼎立雏形已定，荆州是悬在孙刘心口的糊涂账。
- **玩家视角（乐子人）**："你们东吴失去的只是荆州，而我们刘皇叔失去的可是仁义啊。"
- **必然结果**：`flags_add: ["见证者_南郡借荆州"]`（flags_on_enter 锚定）

## 五、骨架选项（自由行动方向，非剧情分支）

1. **围观曹仁被曹操"异地登录代打"**（tension 5）→ 看哀兵必胜（observe）
2. **报名当刘备军群演，参演"造十副云梯又藏起来"的虚空博弈**（tension 20）→ 看周瑜信不信刘琦在油江口（participate）
3. **按住周瑜怒气——医言"百日之内不可动怒"**（tension 30）→ 成就"劝住周瑜不动怒"（influence）
4. **从南郡战场淘"毒火双属性附魔箭"**（tension 20）→ 成就"淘到毒火双属性箭"（trade）
5. **按张飞逻辑把来讨债的周瑜捅死，或真把荆州让出去当冤大头**（tension 40）→ 成就"平息借荆州风波"（conflict）

## 六、文风落点（乐子人版）

- **世界侧**：正常演出——周瑜正常受伤、鲁肃正常讨债、诸葛亮正常耍赖
- **玩家视角**：折棒式吐槽——"失去的只是荆州失去的可是仁义"、"鲁肃摁在地上摩擦枉为你诸葛亮"、"立字人为啥是鲁肃"
- **选项 effect**：微带梗味——"按张飞逻辑把讨债的捅死就不欠债了"
- **不出现**：取荆南四郡（P5_s6）、甘露寺（P5_s7）等后续
