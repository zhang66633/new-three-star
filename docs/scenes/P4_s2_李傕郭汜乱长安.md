# P4_s2 李傕郭汜乱长安

> P4_s2（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第9-10回（李傕郭汜犯长安 / 谋汉祚董卓伏诛后的乱局）
> 字幕锚点：折棒 28 期（贾诩神隐，王允献城，我们都有光明的未来）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P4）：**围观 vs 改写**。董卓死后王允把持朝政，拒赦李傕郭汜西凉旧部，逼反十余万兵围长安——王允城头一声"住手"，十万兵马说停就停；一句"会善待天子"，他转身开城跳楼殉国，汉献帝被擒。玩家是挤城头吃瓜、劝王允收降、混进吕布突围队，还是乱军里试着拦下汉献帝？

**设计原则**：
- **名场面开场即现场**：玩家入场即在长安城中，亲历"拒赦 → 聚义 → 围城 → 住手 → 逼宫 → 献城跳楼"全程。这是 `见证者_李傕郭汜乱长安` 的触发点，非可选。
- **字幕锚定**：王允"唯独不赦李傕郭汜二贼"、野人武将"大家只有聚在一起才有生路"、李傕"拼个鱼死网破，日夜兼程攻下长安"、王允"住手！都给我停住！"、郭汜"陛下身边出了个奸贼——就是你，王允"、王允"臣王允，以死报国了"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是十万兵，是王允一声"住手"全城真停；最讽刺的是"贾诩神隐"——文和乱武的起点被个管郭汜叫"二哥"的野人武将说了。
- **时间边界**：192 年 6 月，长安。围城 → 献城（一场内）。王允死后献帝东归、曹操迎帝是后续伏笔，本场只埋钩子。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：李傕郭汜十万西凉军围城，城内守军据城待援。

- **场景**：长安·城头至宫阙。李傕郭汜围城、王允献城跳楼、吕布陈宫突围。
- **锁定台词（必须逐字出现）**：
  - 王允："我谁都可以赦免，唯独不赦李傕、郭汜二贼！"
  - 野人武将："大家只有聚在一起，才会有生路啊！"
  - 李傕："现在我们手上握有十二万重兵，不如拼个鱼死网破，日夜兼程攻下长安！"
  - 王允："住手！住手！都给我停住！"
  - 郭汜："我等并不想谋反，只是陛下身边出了个奸贼——就是你，王允！"
  - 王允："苍天呐，先帝啊——臣王允，以死报国了！"
- **世界侧**：长安如常（表面）——李傕郭汜十万西凉军围城，守军据城待援；王允拒不赦免西凉旧部，吕布被派去"全歼西凉残部"却迟迟未出发；陈宫奔走传信，建议挟天子出城。世界照常运转。
- **玩家视角（乐子人）**："王允一声'住手'，十万兵马说停就停——你叫住手就住手啊。"
- **必然结果**：玩家成为名场面亲历者 → `flags_add: ["见证者_李傕郭汜乱长安"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **王允拒赦** → "唯独不赦李傕郭汜二贼"，逼反西凉（世界侧祸根）
2. **野人聚义** → "大家只有聚在一起才有生路"，十万军围长安（文和乱武被删的贾诩戏）
3. **"住手"名场面** → 王允城头大喊"住手"，十万兵马说停就停（乐子人高潮）
4. **逼宫要王允** → 郭汜"奸贼就是你，王允"，"交出王允，我等绝不会伤害于你"
5. **献城跳楼** → 王允一句"会善待天子"就开城，跳楼殉国；汉献帝被擒（收尾+救驾钩子）

## 五、骨架选项（自由行动方向，非剧情分支）

1. **挤上城头，围观王允一声"住手"，十万兵马说停就停**（tension 5）→ 亲历"住手"名场面，看清围城虚实（observe）
2. **趁李傕郭汜喊话，劝王允接受十万西凉军乞降，别把路堵死**（tension 40）→ 试改写"王允献城跳楼"结局（influence，王允存活线）
3. **混进吕布陈宫突围队，体验"顶着十二万大军杀出长安"**（tension 30）→ 随陈宫南下去荆襄创业（participate）
4. **乱军之中冲向城头，试着从李傕郭汜手里拦下汉献帝**（tension 50）→ 救驾钩子：为日后献帝东归、曹操迎帝埋线（conflict）

## 六、文风落点（乐子人版）

- **世界侧**（NPC/环境）：正常演出，不调侃——李傕郭汜正常围城、王允正常跳楼、吕布正常没出发
- **玩家视角**（内心/差异笔记）：折棒式吐槽——"十万骑兵还要'溃退'乞降，他跑个屁呀，直接把长安平推了嘛"、"文和乱武的'聚在一起才有生路'被野人武将说了，贾诩从新三国被删了"
- **选项 effect**：微带梗味——"试改写'王允献城跳楼'结局（王允存活线）"
- **不出现**：献帝东归、曹操迎帝、三让徐州等后续，本场只埋救驾钩子
