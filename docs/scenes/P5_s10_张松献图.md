# P5_s10 张松献图

> 场景开发协议五步流程 · P5_s10（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第60回（张永年反难杨修 / 张松献图）
> 字幕锚点：折棒 191 期（绑匪式迎客 / 三天三夜灌酒）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P5）：**献图 vs 矫情拒看**。张松出使许昌被曹操乱棒打出，空手而归——忽闻树下有人扬声长笑，原来是庞统领着关羽张飞在此等候多时。张松一路惴惴到荆州，刘备以近乎国礼相迎，一请就是三天三夜——连喝三天三夜酒、张飞"你饮一杯我饮三杯"、刘备深夜坐床边等醒酒。张松终于捧出画了三年的西川详图：'得此图者，等于得到半个西川。'玩家是围观绑匪式迎客、混进连喝三天酒局，还是抄录西川详图？

**设计原则**：
- **名场面开场即现场**：玩家入场即在荆州，亲历"许昌被逐 → 拦路迎接 → 三天三夜酒 → 献图"全链。这是 `见证者_张松献图` 的触发点，非可选。
- **字幕锚定**：张松"此图我画了整整三年，蜀中地理行程山川险要尽在图上，得此图者等于得到半个西川"、刘备"我不看，邻家的美玉君子岂能窥视"、张松"你若再推辞西川百姓不答应大汉百姓也不答应"、刘备"仁义二字是我立身之本行事之命，我就是饿死也不能取刘季玉的西川"、张飞"先生饮一杯咱家饮三杯"、张松"刘皇叔啊，你已经连续陪了我三天了"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是西川地图，是"一提刘备就触发关键词，庞统关羽张飞全刷新出来拦路——绑匪团伙既视感拉满"；最讽刺的是"地图都献到眼前了，刘备还搁那儿矫情拒看"。
- **时间边界**：210 年冬，荆州。许昌被逐 → 献图（一场内）。刘备入川留 P5_s11。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：张松空手而归，忽闻树下有人扬声长笑。

- **场景**：益州·许昌至荆州。拦路迎接、三天三夜酒、献图。
- **锁定台词（必须逐字出现）**：张松"此图我画了整整三年，蜀中地理行程山川险要兵营军镇府库钱粮尽在图上，得此图者等于得到半个西川，皇叔请过目"；刘备"我不看，邻家的美玉君子岂能窥视，更何况这美玉是自家皇兄的"；张松"请皇叔不要推辞了，你若再推辞西川百姓不答应大汉百姓也不答应"；刘备"仁义二字是我立身之本行事之命，我就是饿死也不能取刘季玉的西川"；张飞"先生饮一杯咱家饮三杯"；张松"刘皇叔啊，你已经连续陪了我三天了"。
- **世界侧**：荆州署衙灯火通明。张松入席头一日起刘备便带众文武作陪，张飞端起酒碗当桌劝酒；酒席撤了又摆，张松醉倒被扶去睡，睁眼却见刘备一身布衣靴上沾黄泥坐在床边等他醒酒。
- **玩家视角（乐子人）**："一提刘备就触发关键词，庞统关羽张飞全刷新出来拦路——这年头不要二人密谋，你看看这刷新出来多少个窃听角色。"
- **必然结果**：`flags_add: ["见证者_张松献图"]`（flags_on_enter 锚定）

## 六、文风落点（乐子人版）

- **世界侧**：正常演出——曹操正常逐客、刘备正常以礼相迎、张松正常献图
- **玩家视角**：折棒式吐槽——"绑匪式迎客触发关键词刷新"、"三天三夜酒菜盘不换"、"矫情拒看仁之剑义之剑"、"国道传送门刷许昌"
- **选项 effect**：微带梗味——"抄录一版西川详图半个西川包邮"
- **不出现**：刘备入川（P5_s11）、落凤坡（P5_s12）等后续
