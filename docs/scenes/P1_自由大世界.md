# P1 自由大世界（184-189 · 原创区试验场）

> 区域类型：**原创区试验场**——验证"自由大世界"引擎（角色性格驱动 + 世界自主运转 + 玩家自由行动），跑通后再推广到 P2/P3
> 风格参照：新三国梗宇宙 | 铁律：世界侧零提示，差异只在玩家视角
> 状态：✅ **现行权威**——已随自由沙盒重构落地（《P1_黄金风起.md》为历史稿，仅作素材参考）

## 〇、设计决策（已与用户逐项确认）

| # | 决策点 | 结论 |
|---|--------|------|
| 1 | 重构范围 | **先 P1 试验场**，验证引擎后推广 P2/P3 |
| 2 | 驱动模型 | **世界自主运转为主**（历史事件到点自动发生，角色按性格自主行动） |

## 一、引擎三层架构

替换现有"场景骨架"（director 的 choose_scene → 世界推演 + 视野生成）：

### 世界层（自主运转）
- **单时钟**：world_date 单调向前，行动耗时驱动（复用 `action_days`：赶路按距离、休息按天）
- **历史事件到点触发**：`history_timeline_1~4.json`（date→event→5 种交互角度 observe/participate/influence/trade/conflict）
  - 玩家在场 → 亲历（writer 演给玩家看）
  - 玩家不在场 → 进 `world_events` 队列 → 世界公告/小报播报
- **阶段常态**：`world_normal_1~6.json` 提供每阶段阵营/地点/日常场景，作为"世界正在发生什么"的底色
- **物理规则**：`mechanisms.json`（A1-A8）约束世界运转规律（天意/时空/军事/社会/角色机制）

### 角色层（性格驱动）
- **角色世界状态档案**：每个角色一份「位置 / 当前在做什么 / 目标 / 对玩家态度（好感-敌意 / 知晓度）」
  - 事实（谁在哪/谁死了/谁入京）→ **引擎**按 timeline 事件更新
  - 软状态（当下心情/对玩家的态度变化）→ **LLM** 互动后更新
- **按性格演出**：玩家进入某地视野，该地角色从 `characters/*.json` 取 personality/desires/behavior_rules 实时演出
- **在场即呈现**：进入地点 → writer 注入该地角色与其当下状态，玩家可主动接触

### 玩家层（自由行动）
- **当前位置 + 阶段可达地图**：颍川/冀州/洛阳/中牟/成皋/陈留等（复用 LOCATIONS + action_days 距离）
- **自由输入 + LLM 引导**：writer 按当下世界状态生成 3-4 个"此刻此地可做的事"引导，玩家可点选或自由输入
- **失败不真死**：作死→乐子人式脱困 + 代价（丢物/受伤/关系/声望），活着才有故事

## 二、时间模型

- 184 年春颍川醒来（保留 P1_s1 雨夜醒来作世界入口）
- 玩家自由活动 184-188：赶路耗天、驻留办事、遇人互动
- 历史事件按 date 到点触发（黄金军起义/官军围剿/黄金军第八个月平息…），玩家在场亲历或经公告得知
- **玩家随时可"前往洛阳"** → 进入 189 年 P2（董卓入京前），P1 自由阶段结束
- 无强制时代快进全屏（删除 P1_s3 骨架）

## 三、世界公告/小报面板（常驻菜单）

面板收进一个菜单，点按钮查看（自由世界的"世界在自我转动"证据）：

| 栏目 | 内容来源 |
|------|---------|
| **今日头条** | 近段时间最重要 1-2 条历史事件（`history_timeline` 到点触发的 major 事件） |
| **街头传闻** | 各地点传闻（`LOCATION_RUMORS` 的 hint）→ 玩家可"打听"解锁新地点 |
| **与你有关** | 涉及玩家的世界动态（world_events 中 related_to_player=strong 的条目） |
| **世界公告** | `synthesize_briefing` 合成简报（时间跨度+事件，折棒口吻） |

新动态 → 面板红点亮起。

## 四、P1 三条暗线（收益保留，获取方式自由化）

原来骨架"选项触发暗线"，自由世界里改为"自由行动获取"：

| 暗线 | 获取方式（自由） | 收益 |
|------|-----------------|------|
| 流亡线 | 追上黑影/随流民队伍 | 同路人进 P2 同行 |
| 黄金线 | 混入黄金军/应"大吉" | P3 情报/信物 |
| 许家线 | 救下被追杀乡绅 | 许子将推荐信，P3 见曹操 |

**世界观锚点不变**："黄金军吞噬黄巾军"——玩家记忆"黄巾"，世界是"黄金"，差异只在玩家视角。

## 五、实施要点（引擎改动清单）

1. **director 改写**：`choose_scene`（骨架导航）→ `advance_world`（推演世界）+ `view_scene`（生成玩家视野）
2. **角色状态档案**：新建 `knowledge/character_states.json`（14 角色位置/状态/对玩家态度），引擎按 timeline 更新事实、LLM 更新软状态
3. **事件触发器**：world_date 推进后检查 `history_timeline`，到点事件 → 在场注入 writer / 不在场入 world_events
4. **引导生成**：writer 按当前世界状态+位置生成 3-4 引导选项（LLM 生成，非预写）
5. **失败脱困**：玩家作死 → writer 按"乐子人脱困+代价"处理
6. **面板菜单**：前端菜单收纳世界公告/今日头条/街头传闻/与你有关，红点亮起
7. **保留**：单时钟/action_days/LOCATIONS/world_events/synthesize_briefing 底座复用
8. **P1 出口**：玩家"前往洛阳"→ 189 年 P2（董卓入京前）

## 六、待验证项（P1 试验场目标）

- [ ] 世界自主运转是否真实可感（事件到点发生、公告播报）
- [ ] 角色性格是否立得住（曹操谋位/吕布率真/张角残党，按档案演）
- [ ] 玩家自由行动是否有意义（三条暗线自由获取）
- [ ] LLM 引导 + 自由输入是否流畅（无骨架仍不空洞）
- [ ] 引擎性能（角色状态更新、事件触发、简报合成）
