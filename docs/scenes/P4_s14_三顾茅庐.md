# P4_s14 三顾茅庐

> 场景开发协议五步流程 · P4_s14（字幕锚定区，以原剧为准）
> 原著锚点：三国演义 第37-38回（司马徽再荐名士 / 定三分隆中决策）
> 字幕锚点：折棒 100-101 期（孔明在火中安睡 / 一破卧龙出山）

## 一、场景设计总述

**核心矛盾**（剧情骨架 P6）：**求贤若渴 vs 高卧隆中**。徐庶走前回马荐诸葛，刘备一顾不遇、二顾冒雪扑空、三顾龟板占卜"上上大吉"方见卧龙——诸葛亮"大梦谁先觉"隆中对策"取荆襄、西川，天下已居其半"，刘备三拜"必终生奉你为师"，卧龙出山。玩家是冲进草堂把卧龙从火里捞出来、当"隆中对质检员"补课，还是质问天意"巨变前的历史呢"？

**设计原则**：
- **名场面开场即现场**：玩家入场即在隆中卧龙岗，亲历"一顾不遇 → 二顾扑空 → 三顾方见 → 隆中对策 → 卧龙出山"全链。这是 `见证者_三顾茅庐` 的触发点，非可选。
- **字幕锚定**：童子"先生出门远游了"、刘备"昨夜梦中相会"、诸葛亮"大梦谁先觉"、诸葛亮"取荆襄西川天下已居其半"、刘备"必终生奉你为师"、诸葛亮"愿一展胸中所学"——锁定台词逐字出现。
- **乐子人基调**：最响亮的不是隆中对，是"你再不救火，先生就不是奇人了，该成熟人了"；最讽刺的是"一破，卧龙出山"。
- **时间边界**：207 年秋，隆中卧龙岗。三顾 → 出山（一场内）。火烧博望坡等留 P5 批。

## 二、开场即触发

无论玩家想做什么，第一段叙事就发生在此：刘备三顾茅庐，求见卧龙。

- **场景**：荆州·隆中卧龙岗。一顾二顾三顾、隆中对策、卧龙出山。
- **锁定台词（必须逐字出现）**：
  - 童子："我家先生知道近日会有贵客到访，所以出门远游了。"
  - 刘备："昨夜我与她梦中相会，彼此大发豪情，纵论天下。"
  - 诸葛亮："大梦谁先觉，平生我自知。草堂春睡足，窗外日迟迟。"
  - 诸葛亮："将军得荆襄、西川两地之后，天下已居其半，继之就该南抚彝越，西和诸戎，外结孙氏，内修军政民生，待天下有变，便可率雄师出秦川，取许昌，灭曹贼！"
  - 刘备："孔明先生，刘备斗胆请你出山相助，我必终生奉你为师！"
  - 诸葛亮："诸葛孔明高卧多年，得遇明主，愿一展胸中所学。"
- **世界侧**：隆中卧龙岗与世隔绝：山间春色正浓、流水淙淙，草庐建在瀑布边、四面透风；诸葛亮躬耕陇亩、抱膝长吟，晨起抚琴、闲时云游西川绘制地图。山民传唱卧龙先生作的歌谣"苍天如圆盖，陆地似棋局"，樵夫照常砍柴、童子应门读书——只有刘关张三番五次打破这份平静。
- **玩家视角（乐子人）**："你再不救火，先生就不是奇人了，该成熟人了——张飞要烧草堂，刘备拦着喊'不可惊扰'。"
- **必然结果**：玩家成为名场面亲历者 → `flags_add: ["见证者_三顾茅庐"]`（flags_on_enter 锚定）

## 四、可触发事件（玩家接触才发生，可自由挑选/跳过）

1. **徐庶荐贤** → "无异于周公得吕望、汉王得张良"，回马荐诸葛（过渡铺垫）
2. **一顾不遇** → 童子"先生知道贵客到访所以出门远游"
3. **二顾扑空** → 只见诸葛均/崔州平，孔明访友云游避而不见
4. **三顾方见** → 龟板占卜"上上大吉"，"大梦谁先觉"，隆中对策（乐子人高潮）
5. **卧龙出山** → 刘备三拜"必终生奉你为师"，"历史发生了巨变"

## 五、骨架选项（自由行动方向，非剧情分支）

1. **张飞要放火烧草堂、刘备拦着喊"不可惊扰"的当口，冲进去把卧龙从火里捞出来**（tension 30）→ 触发"先生真乃奇人也"，孔明请你喝瀑布茶，成就"草堂一消防"（participate）
2. **诸葛亮背隆中对漏了"刘璋暗弱"关键论点，插嘴补课**（tension 35）→ 补对刮目相看，补错听折棒吐槽，成就"隆中对质检员"（influence）
3. **蹲书房屏风后围观刘备三拜+孔明"夫妻对拜"，数数刘备跪了几次**（tension 10）→ 成就"卧龙登记处"（observe）
4. **诸葛亮掏出常年铺地上的西川 54 郡地图，吐槽"这是地图还是地毯"，或拿情报换战略剧透**（tension 20）→ 成就"徐霞客同行"（trade）
5. **出山瞬间画外音宣布"历史发生了巨变"，当场质问"巨变前的历史呢"**（tension 40）→ 天意含糊其辞只肯透露世界线已改，称号"卧龙见证人"（influence）

## 六、文风落点（乐子人版）

- **世界侧**（NPC/环境）：正常演出，不调侃——孔明正常高卧、刘备正常三顾、张飞正常要烧草堂
- **玩家视角**（内心/差异笔记）：折棒式吐槽——"不救火先生就成熟人了"、"一破，卧龙出山"、"上赶着应聘怕被架在火上烤"、"历史发生了巨变，那巨变前的历史呢"
- **选项 effect**：微带梗味——"孔明醒来请你喝瀑布茶"
- **不出现**：火烧博望坡（208）、长坂坡、赤壁之战等 P5 批后续
