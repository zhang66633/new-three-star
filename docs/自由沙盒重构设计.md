# 新三国 星空 · 自由沙盒重构设计

> 版本: v1.0 ｜ 日期: 2026-08-09
> 依据: 与用户逐项确认的决策树（21 项机制决策 + 玩家数据 4 项 + 存档 6 项）
> 定位: 从"名场面目标机制"（线性场景链 + 门禁）转向"事件驱动活世界 + 自由沙盒"

---

## 〇、设计总纲

**一句话**：世界按真实历史时间线独立推进（事件驱动），玩家是洪流中的自由参与者——场景变为世界中的地点、玩家自由来去、背景人物剧情不断推动，玩家的资产/关系/声誉/成就持久留存。

### 三个原则（贯穿全部设计）
1. **世界是活的**：世界不管玩家在不在都在推进，NPC/势力有自己的节拍
2. **玩家是参与者不是主角**：可改局部细节，不可改历史大势
3. **数据即记忆**：玩家的每一次作为都沉淀为可追溯的持久数据

### 与旧框架的差别（速览）
| 维度 | 旧（名场面目标机制） | 新（自由沙盒） |
|---|---|---|
| 场景 | 线性推进的关卡 | 世界中的自由地点 |
| 名场面 | 门禁判失败 | 自由参与，得成就 |
| 玩家行动 | 选项推进剧情 | 选项=地点行动+自由输入 |
| 世界时间 | turns_left 回合数 | 具体日期（年月日） |
| 世界动态 | world_rumors 传闻 | 传闻层+事实层（world_events） |
| 存档 | 名场面前自动 | 每回合后全量快照 |
| 玩家数据 | reputation/relations | 资产/属性/关系/声誉/成就 |

## 一、世界层（活世界 · 事件驱动）

### 1.1 推进模型
- **模型**：事件驱动型活世界——玩家参与时实时演出，玩家不在时以事件时间线推进
- **驱动源**：历史时间线（真实三国大事为骨架），NPC 是历史洪流中的角色
- **时间表示**：具体日期 `{year, month, day}` + 事件锚点（该日附近有何大事）

### 1.2 时间推进节奏
| 行动类型 | 耗时 | 说明 |
|---|---|---|
| 对话/打听/观察 | 不计或半天 | 原地互动 |
| 打探/办事 | 半天~1 天 | 中等行动 |
| 赶路（地图移动） | 数天 | 耗时=距离（邻近半天/跨州数天）|
| 休息/等待 | 可自定义 | 恢复体力/等事件 |

### 1.3 历史压缩
- 两次历史大事件之间可**自动跳时**：日常 1天/拍，大事件间自动跳过，以简报带过（"几年过去，谁干成了什么"）
- 玩家到一个新事件点才重新实时

### 1.4 历史事件数据源
- 由**另一个 AI**（折棒吐槽+新三国原著）整理世界观与历史事件时间线
- 产出：`历史事件表`（年份/月份 → 大事/人物动向/与玩家可交互点）
- 工具：见《世界观整理提示词》（docs/世界观整理提示词.md）

### 1.5 世界状态存储
- **世界档案**（独立于玩家）：`worlds_state` 表（服务端数据库）
  - 当前日期、当前地点（玩家所在）、事件队列、NPC 状态、各区域进展
- **推进时机**：仅游玩时推进（关游戏冻结），重进从快照继续

## 二、世界观层（日常底色 · 补时间线空档）

> 时间线（§一 历史事件）是"大事件骨架"，玩家在事件之间游荡时（空档最长 77 个月）需要"世界平时怎么运转"的内容。世界观层提供这个底色。

### 2.1 形态与分工
- **时间线** = 大事件骨架，触发既有场景叙事（已在 §一）
- **世界观层** = 势力/地点/人物**常态设定**，玩家日常撞见的底色，LLM 基于它即兴生成日常
- **来源**：另 AI 产出的《世界常态设定》（docs/世界常态设定提示词.md）

### 2.2 阶段演化（六阶段）
| 阶段 | 时间 | 大势 |
|---|---|---|
| 黄巾乱起 | 184-02~188 | 黄金军起义，颍川战区 |
| 董卓乱政 | 189-08~190 | 董卓入京，洛阳帝都 |
| 群雄割据 | 191-04~199 | 讨董解散，群雄割据 |
| 官渡定鼎 | 200-06~207 | 曹操胜袁绍，北方渐定 |
| 赤壁三足 | 208-01~219 | 赤壁三分，刘备得荆益 |
| 天下三分 | 220-01~223+ | 曹丕篡汉，三国鼎立 |

### 2.3 每阶段内容（五维）
| 维度 | 内容 |
|---|---|
| `world` | 天下大势一句话 + 朝廷处境 |
| `factions` | 各势力现状/目标（≥4 个）|
| `locations` | 各地点生态 + 日常场景（≥5 地，≥3 场景/地）|
| `characters` | 关键 NPC 状态/目标/性格（≥6 人）|
| `atmosphere` | 阶段氛围 tone + 传闻 + 日常样貌 |

### 2.4 日常生成与接入
- **生成**：常态作底色，LLM 即兴（玩家在某地 → 注入该阶段常态 → LLM 生成日常对话/闲事/机遇）
- **接入**：按阶段注入提示——玩家当前 `world_date` 判断所处阶段，把对应阶段五维注入 writer 提示（"当前世界背景"），与事件注入同机制
- **产出文件**：`backend/knowledge/world_normal/world_normal_1~6.json`，用 `docs/世界常态.schema.json` 校验

## 三、事件与简报

### 3.1 事件生成
- **时机**：玩家离开某区域时预生成（结构化事件，结果写死，可追溯）
- **成本控制**：按时间跨度触发——长跨度（数天/数月）才调 LLM 生成；短距离移动不生成（直达）
- **内容**：只记关键事件（历史大事件/关键 NPC 动向/与玩家有关的）
- **相关度标记**：生成时判断——涉及玩家认识的 NPC/所在地区/承诺相关的，标记"与玩家相关"
  - 分级+衰减：强相关（承诺/人情/高关系）逐条展示；弱相关（只认识）合并进世界概览；久未互动自然淡化
- **影响**：事件生成考虑玩家此前行为/关系/声誉（玩家帮过谁 → 事件里可能被提及/报答）
- **伏笔**：允许暗线（存 knowledge.hidden，玩家未知，日后触发寻仇/报恩）

### 3.2 事件存储
- 随**世界档案**持久化：`world_events` 字段（结构化事件列表：时间/地点/人物/结果/相关度）
- 只存关键事件，不膨胀

### 3.3 简报呈现
- **时机**：玩家到达新地点/重进时，先出简报，后进场景叙事
- **形式**：动态面板（世界动态/传闻），按事件逐条，可展开
- **生成**：结构化事件 → LLM 合成一段可读简报（含时间跨度+与玩家相关点）
- **与 world_rumors 关系**：双轨并存
  - `world_rumors` = 传闻层（NPC 传的、未证实的话）
  - `world_events` = 事实层（协调中枢确认的已发生事实）

### 3.4 事件与场景衔接
- **玩家在场**：相关事件**主动汇入**叙事（按时间触发，如曹操差人送信、仇家追到客栈），玩家可**现场应对**（躲/应/追/装不知）
- **事件注入场景上下文**：世界事件作为背景事实注入 writer 提示（world_normal/context 加"本地点近期事件"），场景数据主导当前发生
- **在场应对结果**：影响关系/声誉/后续（事件成为"活的选择点"）

## 四、玩家层（独立档案 · 持久化）

### 4.1 玩家档案
- **存储**：服务端数据库 `players` 表（独立于世界档案）
- **生命周期**：每次开局新档案，存档=玩家档案+世界档案组合
- **绑定**：与世界档案一一绑定

### 4.2 资产与属性
- **物品**：描述字符串列表 + 金钱字段（如 `["破布衣","半块干粮","生锈短刀"]`）
- **获得/失去**：叙事自然获得（拾取/赠予/买卖/被夺），LLM 经 state_updates 更新
- **属性**：体力/饥饿/伤势（数值 0-100）
  - 低值后果：叙事表现（"饿得走不动""伤重昏迷"）+ 行动受限（不能赶远路）
  - 恢复：行动恢复——休息耗时间回体力、进食耗食物回饥饿、治伤耗财回伤势

### 4.3 人际关系
- 扩展已有 `relations`（好感）/`trust`（信任）
- **演化**：事件驱动调整——帮助→好感涨、背叛→信任崩，LLM 经 state_updates 更新数值

### 4.4 身份与声誉
- 声誉值（已有 `reputation`）+ 动态称号列表
- **称号获取**：重大事件授予（参与刺董→"乱世见证者"、放曹→"钦犯同谋"）
- NPC 凭称号认出/议论你（叙事体现）

### 4.5 成就与里程碑
- 条件定义（亲历刺董/参与放曹/攒到 N 声望）+ **行动后自动检查**解锁
- 解锁时前端提示，随玩家档案持久化

## 五、场景层（自由地点 · 去框架）

### 5.1 场景定位
- 场景 = 世界中的**自由地点**（非线性关卡），玩家可自由来去
- **迁移**：保留现有 8 场景的叙事内容（setting/world_normal/锁定台词/文风），改造导航层（方式待定）

### 5.2 地图导航
- **地图选点赶路**：前端地点列表面板，选目标"赶路"（耗时=距离）
- **地点分层**（解决"地点很多"）：
  - 已知地点：去过/听说的，可赶路
  - 传闻地点：地图显示为"方向/传闻"（"北边传闻有大城"），需情报/打听解锁
- **移动呈现**：地点列表面板（非可视化地图）

### 5.3 名场面
- **自由参与**：不设门禁不判失败——到场则亲历（得成就/关系），错过则简报得知结果
- 发生仍锚定地点/时间（如 189 秋洛阳刺董）

### 5.4 玩家行动
- **选项 + 自由输入并行**：选项=地点行动引导（打探/赶路/停留/互动），自由输入可突破

## 六、存档机制

### 6.1 自动快照
- **时机**：每回合引擎跑完后自动快照（玩家档案+世界档案一起存）
- **恢复**：重进恢复到上次快照，简报"离开期间"事件

### 6.2 死亡/失败
- **无失败只有后果**：死亡读档到最近快照；错过事件简报得知；惹麻烦（追兵/仇敌/通缉）是后果不是结束

### 6.3 档案生命周期
- 每次开局新档案，保留新手序章（雨夜醒来进颍川），地图渐解锁
