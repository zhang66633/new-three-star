## ✨ 这是什么

以 2010 版电视剧《新三国》的荒诞世界观为底、基于**社区「蹩脚 AI」元理论**构建的互动叙事游戏：

> **苍天已死，黄天当立——但接管黄天的是一个蹩脚的生成器。** 三国正史与演义是一套“正确的历史”，新三国是一部“生成出来的历史”：时间戳记不齐、坐标算不准、上下文会遗忘、数值会失控——剧里的一切诡异，都是生成器的出厂痕迹。黄金军吞掉黄巾军、小沛绕徐州公转、刘表永远 64 岁、七万打崩七十万、关羽之歌全剧响了 63 次（只有 4 次有关羽）——那不是编剧的梗，是生成器在运行。

这个生成器，就是**天意**。祂手里捏着训练语料里的正确历史，疯狂地把世界拉回正轨：

- 🔁 **修正**：偏离主线的行为必被修正——该赢的人必须赢，该死的必须死；
- 🎵 **存档**：关羽之歌=存档音效，危险的历史要被“盖棺定论”时响起；
- 🕸️ **侵蚀**：窥探过天意的人被同化——运气 -90%、智力 -90%、野心 +100%、衰老 +250%；
- 👤 **接管**：角色失控就派“六大龙套”化身接管，极速衰老抹杀原角色；
- 🔄 **周目**：删剧情、试重开（静姝/晋书）、被司马懿反问“你凭什么”——直到时间变成周目循环。

而所有社区解读（克苏鲁外神 / 被污染的游戏 / 剧本杀 / 宝可梦 / ELO / 修仙 / TRPG…）都是对的——**因为它们观察到了同一台生成器的不同侧面**。这套理论就是那十一套框架之上的元框架。

## 🎯 特色

- 🏯 **46 个名场面**：雨夜醒来、温酒斩华雄、官渡赤壁、白帝托孤……覆盖 184–223 年，锁定台词逐字还原原剧
- 🌍 **事件驱动活世界**：48 个历史事件按真实日期独立推进，玩家缺席世界照常运转——错过得简报，没有失败只有后果
- 🗿 **天意修正**：干预历史按张力三档触发（对话转向 / 巧合堆叠 / 时间跳跃·记忆覆盖·事件重生成），修正必留痕、过程可改写
- 🧠 **分层记忆**：STM / LTM / PIN 钉选，跨回合追踪伏笔、承诺与关系轨迹
- 🎭 **8-PHASE 校验流水线**：每轮生成经确定性硬校验 + LLM 复核，超限自动重写，保证人物一致与信息迷雾
- 🏹 **自由沙盒**：21 地点自由来去、玩家档案（资产/属性/关系/声誉/成就）持久化、传闻解锁新地图
- 🖋 **折棒文风**：世界侧正常演出、玩家视角乐子人吐槽——“黄金”还是“黄巾”，只有你记得真相
- 📱 **全端适配**：桌面沉浸体验 + 移动端优化（安全区 / 触控 / 全宽面板）

## 🚀 快速开始

```bash
# 后端（Python 3.11+）
cd backend
pip install -r requirements.txt
python main.py                # uvicorn :8000

# 前端（Node 20+）
cd frontend
npm install
npm run dev                   # vite :5173（/api 代理到 :8000）
```

> 🔑 **BYOK**：在星图「设置」星球填入自己的 DeepSeek API Key（仅存浏览器本地），游戏文字由你自己的密钥生成——你的 Key，就是这台生成器的算力。
