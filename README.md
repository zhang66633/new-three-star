## ✨ 这是什么

以 2010 版电视剧《新三国》的荒诞世界观为底，构建的**克苏鲁式元叙事互动游戏**：

> **天意 = 崩溃的游戏管理员系统。** 它钉死历史关键节点，用“脚本修正”强行把剧情扳回正轨；角色会在关键节点被系统接管，说出前言不搭后语的话——而他们自己毫无察觉。只有玩家知道：历史大势不可改，但过程可以；修正必留痕，人心可改变。

## 🎯 特色

- 🏯 **46 个名场面**：从雨夜醒来、温酒斩华雄，到官渡赤壁、白帝托孤，覆盖 184–223 年，锁定台词逐字还原新三国原剧
- 🌍 **事件驱动活世界**：48 个历史事件按真实日期独立推进，玩家缺席时世界照常运转，错过了由简报得知结果——没有失败，只有后果
- 🗿 **天意修正**：干预历史按张力三档触发修正（对话转向 / 巧合堆叠 / 时间跳跃·记忆覆盖·事件重生成），修正必留痕
- 🧠 **分层记忆**：STM / LTM / PIN 钉选，跨回合追踪伏笔、承诺与关系轨迹
- 🎭 **8-PHASE 校验流水线**：每轮生成经确定性硬校验 + LLM 复核，超限自动重写，保证人物一致与信息迷雾
- 🏹 **自由沙盒**：21 地点自由来去、玩家档案（资产/属性/关系/声誉/成就）持久化、传闻解锁新地图
- 🖋 **文风**：世界侧正常演出、玩家视角吐槽——“黄金”还是“黄巾”，只有你记得真相
- 📱 **全端适配**：桌面沉浸体验 + 移动端优化（安全区 / 触控 / 全宽面板）

## 🚀 快速开始

```bash
# 后端（Python 3.11+）
cd backend
pip install -r requirements.txt
python main.py                # uvicorn :8000

# 前端（Node 20+）
cd frontend
npm install
npm run dev                   # vite :5173（/api 代理到 :8000）
```

> 🔑 **BYOK**：在星图「设置」星球填入自己的 DeepSeek API Key（仅存浏览器本地），游戏文字由你自己的密钥生成，服务端不兜底。
