## ✨ 这是什么

新三国这部剧，全宇宙都知道它不对劲：

> 汉朝太庙里供着秦始皇，小沛绕着徐州公转，刘表永远 64 岁，七万打崩七十万——
> 曹操临终念的是德国现代诗，关羽之歌全剧响了 63 次只有 4 次有关羽本人，
> 正史叫黄巾，这世界喊黄金——苍天已死，黄天当立，但黄天早就没了。
> 接管这条时间线的，是一个蹩脚的生成器。祂，就是天意。

这个游戏就是按这套「蹩脚 AI」元理论复刻的：**真的让一个 AI 去生成三国世界，让 AI 扮演天意**——
手里捏着正确历史的剧本，你敢把历史掰歪，祂就敢把剧本掰回来：

- 🔁 **修正**：该赢的必须赢，该死的必须死——"此诏虽假，句句却是天意"；
- 🎵 **存档**：关羽之歌一响，天意在做存档/结算，谁都能用，因为存档不挑角色；
- 🕸️ **侵蚀**：窥探天意的人被同化——运气 -90%、智力 -90%、野心 +100%、衰老 +250%；
- 👤 **接管**：角色彻底失控就派"六大龙套"化身顶班，极速衰老抹杀原角色；
- 🔄 **周目**：删剧情、试重开（静姝/晋书）、被司马懿反问"你凭什么"——直到时间变成周目循环。

而社区那些解读（克苏鲁外神 / 被污染的游戏 / 剧本杀 / 宝可梦 / ELO / 修仙 / TRPG…）**全是对的**——
它们观察到的，是同一台生成器不同的死法。

## 🎮 现在能玩的两个模式

| 模式 | 入口 | 玩法 | 要点 |
|------|------|------|------|
| 🌌 **天意星球** | 星图点「天意」主星 | 自由沙盒主线 | 46 场名场面 + 活世界事件 + 天意修正 + 分层记忆，**当前主打** |
| 💥 **崩坏纪元** | 星图点「崩坏纪元」 | 旧叙事引擎保留 | 觉醒 NPC 的污染世界，纯剧情互动，天意接管叙事 |

## 🎯 玩什么

- 🏯 **46 场名场面**：雨夜醒来、温酒斩华雄、官渡赤壁、白帝托孤……184 到 223 年，台词逐字还原——
  "我部悍将刘三刀，三刀之内必斩吕布于马下"，都给你留着；
- 🌍 **活着的世界**：48 个历史事件按真实日期自己走，你缺席它也照转——错过了就听简报，没有失败，只有后果；
- 🗿 **手贱的代价**：干预历史按张力触发天意修正，三档套餐：对话转向 / 巧合堆叠 / 时间跳跃·记忆覆盖·事件重生成，修正必留痕；
- 🧠 **记性很好**：STM/LTM/PIN 分层记忆，欠你的人情、放过的狠话、埋下的伏笔，跨回合都记得；
- 🎭 **防崩坏流水线**：8-PHASE 校验，每轮生成先过硬校验再过 LLM 复核，写崩了就重写，人物绝不 OOC；
- 🏹 **自由沙盒**：21 个地点随便浪，资产/属性/关系/声誉/成就持久化，打听传闻还能解锁新地图；
- 🖋 **文风**：世界侧一本正经演，玩家视角阴阳怪气——"黄金"还是"黄巾"，只有你记得；
- 📱 **手机也能玩**：移动端适配（安全区/触控/全宽面板），蹲坑也能陪曹操煮酒。

## 🚀 快速开始

```bash
# 后端（Python 3.11+）
cd backend
pip install -r requirements.txt
python main.py                # uvicorn :8000

# 前端（Node 20+）
cd frontend
npm install
npm run dev                   # vite :5173（/api 代理到 :8000）
```

> 🔑 **BYOK**：在星图「设置」星球填你自己的 DeepSeek Key（只存浏览器）。游戏文字由你的 Key 生成——
> 你的 Key，就是这台生成器的算力。
